> 이 글은 [tmux 로드맵](/posts/tmux/2026-06-16-tmux-roadmap/)의 **2단계(플러그인으로 확장)** 다. 입문·설정부터 세션 자동화까지 전체 경로는 로드맵에서. 플러그인을 *쓰는* 게 아니라 **직접 만드는** 법은 [tmux 플러그인은 어떻게 만드나](/posts/tmux/2026-07-09-tmux-plugin-authoring/)에서.
{: .prompt-tip }

## 📦 TPM (Tmux Plugin Manager)

```sh
set -g @plugin 'tmux-plugins/tpm'
```

### 👉 역할

Tmux 플러그인을 설치, 업데이트, 삭제할 수 있는 **플러그인 관리자**.
tmux 플러그인 생태계를 사용하려면 반드시 필요함.

---

## ⬇ 설치

```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

`.tmux.conf` 작성 후 tmux 안에서 `prefix + I`(`Ctrl+b` → `I`)로 플러그인을 설치한다.

---

## 📚 플러그인 목록

### 1. `tmux-plugins/tmux-sensible`

```sh
set -g @plugin 'tmux-plugins/tmux-sensible'
```

#### ✔ 역할

tmux의 기본값을 **더 합리적인 설정(sane defaults)** 로 변경해주는 플러그인.
기본 키 설정, 패널 동작, 기타 비직관적 설정들을 개선해 주기 때문에 필수 플러그인으로 널리 사용됨.

---

### 2. `tmux-plugins/tmux-resurrect`

```sh
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @resurrect-capture-pane-contents 'on'
```

#### ✔ 역할

tmux 세션을 "부활(resurrect)" 시켜주는 플러그인.
저장된 시점의 **세션, 윈도우, 패널 레이아웃, 실행 중 명령** 등을 복원해줌.

#### ✔ 기능

* `prefix + Ctrl-s` → 세션 상태 저장
* `prefix + Ctrl-r` → 세션 복원
* 패널 내용까지 저장하려면 `@resurrect-capture-pane-contents='on'` 필요

---

### 3. `tmux-plugins/tmux-continuum`

```sh
set -g @plugin 'tmux-plugins/tmux-continuum'
set -g @continuum-restore 'on'
```

#### ✔ 역할

`tmux-resurrect`를 기반으로 **자동 백업 + 자동 복원** 기능을 제공.

#### ✔ 기능

* 자동 저장 (기본 15분 간격)
* 시스템 재부팅 후 tmux 자동 복원
* 개발 환경 그대로 복구 가능

👉 `tmux-resurrect`의 상위 확장 플러그인

---

### 4. `jimeh/tmux-themepack`

```sh
set -g @plugin 'jimeh/tmux-themepack'
set -g @themepack 'powerline/default/cyan'
```

#### ✔ 역할

다양한 **상태바(theme)** 를 제공하는 테마 플러그인.

#### ✔ 효과

* Powerline 스타일 적용 가능
* 색상 조합을 쉽게 변경
* 테마 파일을 직접 수정할 필요 없음

---

### 5. `christoomey/vim-tmux-navigator`

```sh
set -g @plugin 'christoomey/vim-tmux-navigator'
```

#### ✔ 역할

Vim/Neovim 패널과 Tmux 패널 사이를 **Ctrl+h/j/k/l** 로 자연스럽게 이동할 수 있게 해줌.

#### ✔ 효과

* Vim 창 ↔ tmux pane 이동이 직관적
* Vim 사용자의 필수 플러그인

---

## ⚙ 기타 tmux 설정

### 기본 터미널 및 마우스 활성화

```sh
set -g default-terminal "tmux-256color"
set -g mouse on
```

#### 설명

* `tmux-256color`: tmux 내부 terminfo로, 256색·이탤릭·True Color를 제대로 알린다. 과거 흔히 쓰던 `screen-256color`는 더 보수적인 fallback일 뿐이라, terminfo만 있으면 `tmux-256color`가 권장값이다. ([tmux 유용한 설정 정리](/posts/tmux/2026-02-21-tmux-tips/)의 True Color 설정과 한 쌍)
* 만약 `tmux-256color` 적용 후 색이 깨지면 해당 terminfo가 없는 환경이다. `screen-256color`로 되돌리거나 terminfo를 설치한다.
* `mouse on`: 마우스로 패널 크기 조절, 선택, 스크롤 가능

---

## 🏁 TPM 초기화

```sh
run '~/.tmux/plugins/tpm/tpm'
```

tmux conf 맨 마지막 줄에 위치해야 함.

---

## 🧩 최종 `.tmux.conf` (플러그인 설명 포함)

```tmux
# --- TPM ---
set -g @plugin 'tmux-plugins/tpm'

# --- Plugin list ---
set -g @plugin 'tmux-plugins/tmux-sensible'       # sane tmux defaults
set -g @plugin 'tmux-plugins/tmux-resurrect'      # save & restore tmux sessions
set -g @plugin 'tmux-plugins/tmux-continuum'      # auto-save & auto-restore
set -g @plugin 'jimeh/tmux-themepack'             # tmux status bar themes
set -g @plugin 'christoomey/vim-tmux-navigator'   # navigate between vim <-> tmux with Ctrl-hjkl

# --- Theme config ---
set -g @themepack 'powerline/default/cyan'

# --- Resurrect settings ---
set -g @resurrect-capture-pane-contents 'on'
set -g @continuum-restore 'on'

# --- Tmux settings ---
set -g default-terminal "tmux-256color"   # 색 깨지면 screen-256color로 fallback
set -g mouse on

# --- Initialize TPM (must be last) ---
run '~/.tmux/plugins/tpm/tpm'
```
