## 📦 TPM (Tmux Plugin Manager)

```sh
set -g @plugin 'tmux-plugins/tpm'
```

### 👉 역할

Tmux 플러그인을 설치, 업데이트, 삭제할 수 있는 **플러그인 관리자**.
tmux 플러그인 생태계를 사용하려면 반드시 필요함.

---

## ⬇ 설치

```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

`.tmux.conf` 작성 후 tmux 안에서 `prefix + I`(`Ctrl+b` → `I`)로 플러그인을 설치한다.

---

## 📚 플러그인 목록

### 1. `tmux-plugins/tmux-sensible`

```sh
set -g @plugin 'tmux-plugins/tmux-sensible'
```

#### ✔ 역할

tmux의 기본값을 **더 합리적인 설정(sane defaults)** 로 변경해주는 플러그인.
기본 키 설정, 패널 동작, 기타 비직관적 설정들을 개선해 주기 때문에 필수 플러그인으로 널리 사용됨.

---

### 2. `tmux-plugins/tmux-resurrect`

```sh
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @resurrect-capture-pane-contents 'on'
```

#### ✔ 역할

tmux 세션을 "부활(resurrect)" 시켜주는 플러그인.
저장된 시점의 **세션, 윈도우, 패널 레이아웃, 실행 중 명령** 등을 복원해줌.

#### ✔ 기능

* `prefix + Ctrl-s` → 세션 상태 저장
* `prefix + Ctrl-r` → 세션 복원
* 패널 내용까지 저장하려면 `@resurrect-capture-pane-contents='on'` 필요

---

### 3. `tmux-plugins/tmux-continuum`

```sh
set -g @plugin 'tmux-plugins/tmux-continuum'
set -g @continuum-restore 'on'
```

#### ✔ 역할

`tmux-resurrect`를 기반으로 **자동 백업 + 자동 복원** 기능을 제공.

#### ✔ 기능

* 자동 저장 (기본 15분 간격)
* 시스템 재부팅 후 tmux 자동 복원
* 개발 환경 그대로 복구 가능

👉 `tmux-resurrect`의 상위 확장 플러그인

> **세션 매니저(tmuxinator·smug)는 여기 플러그인과 다른 축이다.** resurrect는 *떠 있던* 세션을 저장→복원하고, 세션 매니저는 tmux *밖*의 외부 CLI로 레이아웃을 처음부터 선언→생성한다. TPM 플러그인이 아니라 별도 도구이며, [3단계 세션 부트스트랩](./2026-02-21-tmux-bootstrap.md)에서 다룬다.
{: .prompt-info }

---

### 4. `jimeh/tmux-themepack`

```sh
set -g @plugin 'jimeh/tmux-themepack'
set -g @themepack 'powerline/default/cyan'
```

#### ✔ 역할

다양한 **상태바(theme)** 를 제공하는 테마 플러그인.

#### ✔ 효과

* Powerline 스타일 적용 가능
* 색상 조합을 쉽게 변경
* 테마 파일을 직접 수정할 필요 없음

---

### 5. `christoomey/vim-tmux-navigator`

```sh
set -g @plugin 'christoomey/vim-tmux-navigator'
```

#### ✔ 역할

Vim/Neovim 패널과 Tmux 패널 사이를 **Ctrl+h/j/k/l** 로 자연스럽게 이동할 수 있게 해줌.

#### ✔ 효과

* Vim 창 ↔ tmux pane 이동이 직관적
* Vim 사용자의 필수 플러그인

## ⚙ 기타 tmux 설정

### 기본 터미널 및 마우스 활성화

```sh
set -g default-terminal "tmux-256color"
set -g mouse on
```

#### 설명

* `tmux-256color`: tmux 내부 terminfo로, 256색·이탤릭·True Color를 제대로 알린다. 과거 흔히 쓰던 `screen-256color`는 더 보수적인 fallback일 뿐이라, terminfo만 있으면 `tmux-256color`가 권장값이다. ([tmux 유용한 설정 정리](./2026-02-21-tmux-tips.md)의 True Color 설정과 한 쌍)
* 만약 `tmux-256color` 적용 후 색이 깨지면 해당 terminfo가 없는 환경이다. `screen-256color`로 되돌리거나 terminfo를 설치한다.
* `mouse on`: 마우스로 패널 크기 조절, 선택, 스크롤 가능

run '~/.tmux/plugins/tpm/tpm'

## 🧩 최종 `.tmux.conf` (플러그인 설명 포함)

```tmux
# --- TPM ---
set -g @plugin 'tmux-plugins/tpm'

# --- Plugin list ---
set -g @plugin 'tmux-plugins/tmux-sensible'       # sane tmux defaults
set -g @plugin 'tmux-plugins/tmux-resurrect'      # save & restore tmux sessions
set -g @plugin 'tmux-plugins/tmux-continuum'      # auto-save & auto-restore
set -g @plugin 'jimeh/tmux-themepack'             # tmux status bar themes
set -g @plugin 'christoomey/vim-tmux-navigator'   # navigate between vim <-> tmux with Ctrl-hjkl

# --- Theme config ---
set -g @themepack 'powerline/default/cyan'

# --- Resurrect settings ---
set -g @resurrect-capture-pane-contents 'on'
set -g @continuum-restore 'on'

# --- Tmux settings ---
set -g default-terminal "tmux-256color"   # 색 깨지면 screen-256color로 fallback
set -g mouse on

# --- Initialize TPM (must be last) ---
run '~/.tmux/plugins/tpm/tpm'
```

# Appendix — .tmux.conf 실전 설정

> 기존 `tmux 유용한 설정 정리`의 본문을 통합했다. TPM과 기본 설정을 이 문서에서 함께 확인한다.

실제로 쓰는 `.tmux.conf`에서 체감이 큰 옵션만 따로 모았다. 목적은 "왜 이 옵션을 두는지"를 잊지 않게 기록하는 것이다.

> 이 글은 [tmux 로드맵](./2026-06-16-tmux-roadmap.md)의 **1단계(설정 다듬기)** 다.
{: .prompt-tip }

## 1. 기본 동작

### ESC 지연 줄이기

```tmux
set -sg escape-time 0
```

Vim/Neovim에서 ESC와 Alt 계열 입력을 구분하기 위해 tmux가 기다리는 시간을 없앤다. 반응은 빨라지지만 일부 터미널·키 조합에서 Alt/Meta 입력 판별에 영향을 줄 수 있으므로 문제가 있다면 작은 값으로 조정한다.

### True Color

먼저 tmux 안에서 사용할 terminal description을 정한다.

```tmux
set -g default-terminal "tmux-256color"
```

`tmux-256color` terminfo가 시스템에 존재하는지는 확인한다.

```bash
infocmp -x tmux-256color
```

tmux 3.2+에서는 **바깥 terminal emulator가 RGB color를 지원한다는 사실을 `terminal-features`로 알려주는 방식**이 우선이다.

예를 들어 Ghostty·xterm 계열 TERM 값에 맞춰 다음처럼 설정할 수 있다.

```tmux
set -as terminal-features ",xterm*:RGB"
```

환경에 따라 TERM 패턴은 달라질 수 있으므로 tmux 밖에서 다음을 먼저 확인한다.

```bash
echo "$TERM"
```

구버전 tmux까지 고려해야 한다면 `terminal-overrides`의 `Tc` 확장을 사용할 수 있다.

```tmux
set -as terminal-overrides ",xterm*:Tc"
```

```text
RGB
→ 공식 terminfo capability 이름

Tc
→ tmux가 제공해 온 확장 capability
```

무조건 `*256col*`에 True Color를 선언하기보다 **실제 바깥 terminal emulator의 TERM과 기능을 확인한 뒤** 설정하는 편이 안전하다.

### 마우스

```tmux
set -g mouse on
```

패널 선택·크기 조절·스크롤 등 mouse integration을 활성화한다.

## 2. 패널과 키 바인딩

### 분할 시 현재 경로 유지

```tmux
bind '"' split-window -v -c "#{pane_current_path}"
bind % split-window -h -c "#{pane_current_path}"
```

새 pane을 현재 pane의 working directory에서 시작한다.

### 패널 정보 표시

```tmux
set -g pane-border-status bottom
set -g pane-border-format " #P #{pane_current_command} "
```

pane 번호와 현재 command를 border에 표시한다.

### copy-mode에 vi 키 사용

```tmux
setw -g mode-keys vi
```

copy-mode의 key table을 vi 스타일로 사용한다.

## 3. 세션 트리 정렬

```tmux
bind s choose-tree -Zs -O name
```

`choose-tree`를 이름 기준으로 정렬해 연다. tmux 버전에 따라 option 동작이 달라질 수 있으므로 바인딩이 실패하면 현재 `tmux list-commands`와 man page를 확인한다.

## 4. TPM 플러그인

플러그인 목록·역할과 설정은 [Tmux 설정 & 플러그인 설명](./2025-11-17-tmux-tpm.md)에 따로 둔다. 이 글에서는 tmux core option만 다룬다.

## 5. 적용과 리로드

TPM을 사용한다면 초기화는 플러그인 선언 뒤에 둔다.

```tmux
run '~/.tmux/plugins/tpm/tpm'
```

현재 server에 설정을 다시 읽히려면:

```bash
tmux source-file ~/.tmux.conf
```

## 확인 순서

색이나 키 입력이 이상할 때는 설정을 더 붙이기 전에 다음 순서로 확인한다.

```text
1. tmux 밖 TERM 확인
2. tmux 안 TERM 확인
3. tmux-256color terminfo 존재 여부 확인
4. terminal-features / terminal-overrides 확인
5. 애플리케이션(Neovim 등) 설정 확인
```

터미널 기능 문제는 tmux 한 층만의 문제가 아닐 수 있으므로 **밖 terminal → tmux → 안쪽 application** 순으로 범위를 좁힌다.
