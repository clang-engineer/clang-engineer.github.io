fzf는 특정 파일이나 코드만 검색하는 프로그램이 아니라, 임의의 후보 목록을 탐색하고 선택하는 범용 CLI 도구다. 핵심은 후보를 만드는 도구와 탐색 인터페이스, 선택 결과를 소비하는 도구의 분리다.

## 전체 개념지도

```text
Provider (fd / rg / git / zoxide / ...)
    │ 후보 공급
    ▼
fzf
├─ Input        : 후보 수신·항목 경계·목록 갱신
├─ Matching     : 후보 필터링·순위
├─ Presentation : 목록·필드·레이아웃·미리보기
├─ Interaction  : 키·이벤트 → 액션
└─ Selection    : 현재 항목·다중 선택
    │ 결과 반환 또는 액션 실행
    ▼
Consumer (editor / shell / git / tmux / ...)

Integration: Shell / tmux / 외부 프로그램
```

이 지도는 기능의 관계를 나타낸다. 표현·상호작용은 매칭 이후 한 번만 실행되는 단계가 아니라 탐색 과정 전반에 작용한다. 통합 환경은 fzf의 내부 처리 단계가 아니다.

## 후보 공급과 검색의 분리

일반적인 사용에서는 외부 명령이 후보를 공급하고 fzf가 후보를 필터링한다.

```bash
fd --type f | fzf
```

fd는 파일을 찾고 fzf는 받은 경로를 탐색한다. stdin으로 후보를 공급할 수 있으며, 입력이 터미널인 경우에는 기본 후보 생성 명령을 활용할 수 있다. 기본적으로 줄바꿈이 항목 경계지만 NUL 구분도 가능하다.

Matching은 이미 공급된 후보를 좁히는 역할이다. 퍼지 매칭, 정확 매칭, 검색 문법, 정렬은 후보 생성과 별개의 관심사다.

## 표현과 상호작용

Presentation은 후보를 어떻게 표시할지 결정한다. 구분자와 필드 설정은 검색·표시에 사용할 부분을 선택하고, Preview는 현재 항목과 관련된 정보를 별도 명령으로 조회한다. 목록의 표시 형태와 실제 반환값은 구별해야 한다.

Interaction은 키 바인딩과 이벤트를 액션에 연결하는 구조다.

```text
User / State Change
        │
       Event (key / change / focus / ...)
        │
       Action
        ├─ 상태 변경
        ├─ 후보 재공급 (reload)
        ├─ 외부 명령 실행 (execute)
        └─ 선택 확정 / 종료 / 프로세스 교체 (become)
```

Preview는 별도 정보를 보여주는 기능이고 reload는 후보 목록 자체를 갱신한다. execute는 외부 명령을 실행하고, become은 fzf 프로세스를 다른 명령으로 교체한다.

## 내부 매칭과 외부 검색 엔진

```text
고정 후보 탐색
Provider ──> fzf Matching ──> Selection

동적 본문 검색
Query ──> rg ──> fzf List ──> Selection
  ▲                 │
  └── change/reload ┘
```

기본 모델에서는 후보 목록을 fzf 내부에서 검색한다. 외부 검색 모델에서는 검색어 변경 이벤트로 rg를 다시 실행하고 그 결과를 표시한다. 이때 fzf 자체 매칭을 비활성화할 수 있다. 즉, 검색 엔진과 대화형 인터페이스를 분리할 수 있다.

## 선택 결과와 실행

fzf는 선택 값을 stdout으로 반환할 수 있다. 후속 명령이 stdin을 읽는지 argv를 요구하는지에 따라 파이프, 명령 치환, xargs 등을 선택한다. 선택 이후 외부 명령 실행을 fzf 액션에 연결하는 방법도 있다.

```text
Selection
├─ stdout ──> 후속 프로그램 / 셸
├─ execute ─> 외부 명령 실행
└─ become ──> 다른 명령으로 프로세스 교체
```

현재 셸의 디렉터리 변경처럼 셸 상태에 영향을 주는 작업은 셸 함수나 통합 코드가 결과를 받아 처리해야 한다. 자세한 입출력 경계는 [파이프와 xargs](./2026-11-23-shell-pipe-stdin-argv-xargs.md)를 참고한다.

## 통합과 확장

셸 통합은 명령줄에 후보를 삽입하거나 이력을 탐색하고 디렉터리 이동을 지원한다. tmux 통합은 팝업이나 pane에서 인터페이스를 제공할 수 있고, 외부 프로그램은 자식 프로세스로 fzf를 실행해 선택 결과를 받을 수 있다.

이들은 동일한 fzf 기능을 다른 실행 맥락에 결합하는 방식이다. 특정 플러그인은 후보 생성·미리보기·키 바인딩·후속 동작을 미리 구성한 응용 도구일 수 있으며, fzf 자체의 필수 구성 요소는 아니다.
