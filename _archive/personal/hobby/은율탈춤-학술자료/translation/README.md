# Eunyul Talchum — English Translation Project

This directory contains a working English translation of the **Eunyul Talchum (은율탈춤)** performance script, prepared with the accompanying academic materials in this archive as contextual references.

## Source Materials

The principal Korean performance text is **[ 8 ] 은율탈춤의 연희본.pdf**. PDFs [1]–[7] in the parent directory are used to clarify history, performance structure, masks, costumes, props, music, dance, and cultural or ritual meaning. **[9] 영문요약.pdf** is consulted for prior English terminology but is not treated as binding translation precedent.

## Editorial Approach

This project aims for an English text that is readable to an international audience while preserving the cultural specificity of Korean mask dance drama. Terms such as *jangdan*, *bullim*, *mudang*, *gut*, and culturally specific character names are retained when a generic English substitution would erase an important distinction.

The script is not intended as an abridged adaptation. Songs, geographic catalogues, ritual passages, cries, refrains, and performance directions are to be represented rather than silently omitted.

## Romanization and Uncertainty

Romanization is used as a reading aid and to preserve Korean cultural terms. Consistency will be checked during the final editorial pass.

Where transmitted Korean wording is uncertain, archaic, dialectal, ritual, or textually variant, the translation preserves that uncertainty rather than inventing a falsely precise English equivalent.
