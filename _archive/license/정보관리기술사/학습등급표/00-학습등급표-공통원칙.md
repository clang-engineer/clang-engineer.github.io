# 정보관리기술사 학습등급표 공통 원칙

학습등급표는 **교재·기출·공식 출제기준을 바탕으로 무엇을 얼마나 우선해서 공부할지 결정하는 자료**다.

학습등급표는 개념 관계를 설명하는 문서가 아니다. 개념의 상위·하위·인접 관계와 파고들 학습 경로는 `../학습지도/`에서 다룬다.

## 1. 역할

```text
성안당 교재 목차 / 기출 / 공식 출제기준
        ↓
학습등급표
├─ 학습 대상 Topic 확인
├─ A / B / C 우선순위
├─ 선행 · 횡단 · 중복 · 세부 · 현행 · 최신 태그
├─ 회독 깊이 결정
└─ 보강·보류 대상 판단
        ↓
학습지도에서 개념 관계 확인
        ↓
세부학습에서 깊게 학습
```

## 2. A/B/C 등급

등급은 개념의 절대적 가치가 아니라 **정보관리기술사 학습에서 투입할 깊이**를 뜻한다.

| 등급 | 학습 깊이 | 완료 기준 |
|---|---|---|
| A | 답안으로 작성할 핵심 | 목적·구조·절차·비교·적용·한계를 설명한다. |
| B | 관계 이해와 대표 비교 | 역할과 주변 관계를 설명하고 핵심 차이를 비교한다. |
| C | 위치만 확인 | 명칭과 의미만 확인하고 기출 근거가 있을 때 보강한다. |

## 3. 태그

| 태그 | 의미 |
|---|---|
| `[선행]` | 다른 개념보다 먼저 이해해야 한다. |
| `[횡단]` | 여러 단계와 주제에 반복 적용된다. |
| `[중복]` | 같은 권의 다른 Topic과 내용이 겹친다. |
| `[타권중복]` | 다른 Vol.에서 더 깊게 다룬다. |
| `[세부]` | 계산·코드·도식 등 세부 실습 비중이 크다. |
| `[현행]` | 현재도 유효한지 확인이 필요한 용어·제품·표준이다. |
| `[최신]` | 최신 법령·표준·Architecture·기출 맥락으로 보강한다. |

## 4. 보정 원칙

- 성안당 목차만으로 중요도를 확정하지 않는다.
- 실제 기출과 공식 출제기준을 우선한다.
- 법령·표준·제품·기술 세대는 현행 공식 자료로 확인한다.
- 등급 변경은 가능한 한 근거를 남긴다.
- 학습등급표에서 개념 설명을 과도하게 늘리지 않는다. 설명이 필요하면 학습지도나 세부학습으로 내린다.

## 5. 회독 활용

```text
1차 회독
→ A/B/C에 따라 학습 깊이 결정

2차 회독
→ A 중심으로 세부학습 보강
→ B는 A를 이해하는 데 필요한 범위까지 확장

3차 회독
→ 기출과 답안화
→ 최신 근거로 등급 재조정
```
