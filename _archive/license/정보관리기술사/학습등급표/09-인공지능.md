# Vol. 9 인공지능 학습등급표

> 이 문서는 성안당 교재·기출·공식 출제기준을 바탕으로 **무엇을 얼마나 우선해서 공부할지** 정하는 범위·등급 자료다.
>
> 개념의 상위·하위·인접 관계를 따라 파고드는 학습은 `../학습지도/09-인공지능.md`에서 다룬다.

## 기준

정보관리기술사 단독 대비를 위한 1차 분류다. 출제 여부를 고정하지 않으며 공식 출제기준·기출을 보고 A/B/C를 다시 조정한다.

## 이 권의 역할

인공지능은 데이터나 명시적인 규칙을 이용해 예측·분류·생성·의사결정을 수행한다. 정보관리기술사에서는 모델 이름을 많이 아는 것보다, 어떤 문제와 데이터에 어떤 방법을 적용하고 잘못된 판단의 위험을 어떻게 관리하는지가 중요하다.

핵심 질문은 세 가지다.

1. 정답 데이터, 정답 없는 데이터, 행동 결과의 보상 중 무엇을 이용해 학습할 것인가?
2. 모델이 얼마나 정확하고 안정적이며 공정한지 어떻게 확인할 것인가?
3. 잘못된 판단이나 공격이 발생했을 때 누가 책임지고 어떻게 차단·복구할 것인가?

## 권장 학습 순서

전체 학습 흐름: `AI 개념·윤리 → 학습 방식과 생명주기 → 데이터 분할·평가 → 고전 ML 방법 계열 → 순차·강화·표현학습 → 신경망 → 응용·운영 통제 → (선택 보강) 생성형 AI·LLM`

### 1단계: AI 개념과 횡단 통제

`AI 개요(1~5) → 규칙·전문가 시스템(6·8) → 추천·탐색 에이전트(7~13) → 비상 중단·AI 윤리(14~17)`

### 2단계: 학습 패러다임과 평가 기반

`ML/전통 방식 비교(59~60) → 지도·비지도·강화학습(61~64) → DL 개요(65) → 데이터 분할·교차검증(111) → 평가 지표(91~93)`

### 3단계: 고전 ML 방법 계열

`탐색·최적화(18~20) · 통계·거리 기반(21~30) · 연관규칙(31~33) · 앙상블·트리·KNN(34~41) · SVM(42~43) · 베이지안(44~45) · 군집·차원축소(46~51)`

### 4단계: 순차 의사결정·강화·표현학습

`MDP(52) → Q-Learning(55) → DQN(87)`과 `HMM(53)`, `MCTS(54)`, `텍스트 표현(56~58)`을 구분한다.

### 5단계: 신경망과 표현력

`신경망 요소(67~70) → MLP·DL 파라미터(71~75) → 역전파·과적합 제어(76~80) → CNN/RNN(81~82) → LSTM/GRU(83~84)`

### 6단계: 응용과 운영 통제

`응용 분기(94~105·108) → ML 파이프라인·V 모델(100·116~117) → 배포·추론·모니터링 → 보안 위협·XAI·거버넌스(112~122)`

### 선택 보강: 생성형 AI·LLM

`Transformer·자기어텐션 → 사전학습 기반모델·LLM → Prompt·RAG·미세조정 → 평가·안전성 → 배포·모니터링·비용 관리`
