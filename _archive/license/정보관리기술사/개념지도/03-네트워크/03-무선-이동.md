# 무선·이동 개념지도

이 지도는 **유선과 달리 공유 무선 매체를 사용하는 환경에서 어떻게 충돌을 피하고, WLAN에 접속하며, 이동 중 연결을 이어가는지**를 중심으로 본다.

## 1. 유선과 무선의 매체 차이

```text
공유 Ethernet
├─ 같은 Cable을 여러 장치가 공유
└─ 충돌을 감지할 수 있음
    └─ CSMA/CD

공유 무선 Channel
├─ 같은 주파수 자원을 여러 단말이 공유
├─ 송신 중 다른 약한 신호를 듣기 어려움
└─ 충돌을 안정적으로 감지하기 어려움
    └─ CSMA/CA
```

현대 Switch 기반 Full-Duplex Ethernet에서는 Port별로 충돌 영역이 분리되므로 CSMA/CD의 실질적 필요가 크게 줄었다.

## 2. 무선은 왜 충돌 회피를 쓰는가

```text
같은 Channel을 여러 단말이 공유
  ↓
동시에 송신할 수 있음
  ↓
AP에서 Frame이 겹칠 수 있음
  ↓
송신 중 충돌 탐지가 어려움
  ↓
전송 전에 Channel을 확인하고 대기
  ↓
CSMA/CA
```

CSMA/CA의 큰 흐름은 다음 정도만 지도에 남긴다.

```text
Carrier Sense
  ↓
IFS
  ↓
Random Backoff
  ↓
전송
  ↓
ACK 확인
```

Hidden Node 문제가 있으면 RTS/CTS를 이용해 충돌 가능성을 줄일 수 있지만, 제어 Frame 비용이 추가된다.

## 3. WLAN 접속은 한 단계가 아니다

```text
AP 탐색
Beacon / Probe
  ↓
Authentication
  ↓
Association
  ↓
보안 Key 협상
  ↓
DHCP
IP / Gateway / DNS 획득
  ↓
ARP / Neighbor Discovery
  ↓
외부 Network 통신
```

따라서 `Wi-Fi 이름이 보인다`, `AP와 연결되었다`, `IP 통신이 된다`는 서로 다른 상태다.

```text
AP 발견
≠ 인증 성공
≠ Association 성공
≠ IP 설정 획득
≠ Internet 통신 성공
```

## 4. WLAN 보안의 위치

WLAN 보안은 무선 매체 접근 방식과 같은 분류축이 아니다.

```text
WLAN 연결
├─ 매체 접근
│   └─ CSMA/CA
├─ 인증·암호화
│   └─ WLAN Security
└─ Network 설정
    └─ DHCP / IP
```

매체를 어떻게 나눠 쓰는지와 누가 접속할 수 있고 Frame을 어떻게 보호하는지는 별도의 문제다.

## 5. 무선 용량과 전송 효율

학습 범위는 개별 802.11 세대를 나열하기보다 무선 환경의 제약과 이를 개선하는 방향을 본다.

```text
한정된 주파수 자원
  ↓
여러 단말과 Traffic 증가
  ↓
용량·품질 개선 필요
  ↓
MIMO 등 무선 전송 기술
```

MIMO는 WLAN뿐 아니라 이동통신에서도 무선 용량과 전송 효율을 높이는 핵심 기술 축으로 본다.

## 6. 이동성이 추가되면

```text
단말이 현재 AP / Cell에서 통신
  ↓
이동
  ↓
현재 연결 품질 저하
  ↓
다른 AP / Cell로 연결 전환 필요
  ↓
Roaming / Handover
```

Handover는 단순히 새 무선 신호를 찾는 문제가 아니라 **통신 중인 단말의 연결 연속성을 유지하면서 접속 지점을 바꾸는 문제**다.

## 7. 이동통신으로 확장

```text
무선 매체
  ↓
WLAN
공유 Channel과 근거리 접속
  ↓
이동성 요구 확대
  ↓
Handover
  ↓
이동통신 Network
  └─ 5G
```

이 흐름은 WLAN이 5G로 발전했다는 뜻이 아니다. 둘은 서로 다른 Network 체계이며, **공유 무선 자원·전송 효율·이동성**이라는 공통 문제를 기준으로 함께 학습하는 것이다.

## 8. 학습 이동 경로

```text
무선은 무엇을 공유하는가?
  ↓
왜 유선처럼 충돌을 바로 탐지하기 어려운가?
  ↓
CSMA/CA는 어떻게 충돌 가능성을 줄이는가?
  ↓
AP 발견부터 IP 통신까지 어떤 단계가 필요한가?
  ↓
무선 환경의 보안과 용량 문제는 어디서 생기는가?
  ↓
단말이 움직이면 연결을 어떻게 이어가는가?
  ↓
이동통신에서는 이 문제를 어떤 규모로 다루는가?
```

개별 802.11 세대, CSMA/CA Timer, 암호화 Handshake 상세, 세대별 이동통신 구조는 세부학습으로 내려간다.
