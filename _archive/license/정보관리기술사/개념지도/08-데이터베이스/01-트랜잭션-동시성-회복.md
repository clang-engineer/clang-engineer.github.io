# 트랜잭션 · 동시성 · 회복 개념지도

> 여러 사용자가 동시에 데이터를 바꾸고 장애까지 발생할 수 있는 환경에서 **하나의 논리적 작업과 데이터의 정확성을 어떻게 지키는가**를 보는 지도다.

```text
논리적 작업 단위
      ↓
Transaction
└─ ACID
   ├─ Atomicity
   ├─ Consistency
   ├─ Isolation
   └─ Durability
      ↓
      ├─ 여러 Transaction이 동시에 실행됨
      │        ↓
      │     동시성 문제
      │        ↓
      │     동시성 제어
      │     ├─ Serializability
      │     ├─ Lock / 2PL
      │     ├─ Isolation Level
      │     ├─ MVCC
      │     └─ Deadlock
      │
      └─ 처리 도중 장애 발생
               ↓
             회복
             ├─ Log
             ├─ Undo / Redo
             └─ Checkpoint
```

## 핵심 경계

```text
Transaction
= 보장하려는 논리적 작업 단위

동시성 제어
= 여러 Transaction 사이의 간섭을 통제

회복
= 장애로 불완전해진 상태를 정상 상태로 복원

Backup
= 별도 보존본을 이용한 데이터 복원
```

동시성 제어와 회복은 모두 Transaction의 신뢰성을 지키지만 해결하는 문제가 다르다.
