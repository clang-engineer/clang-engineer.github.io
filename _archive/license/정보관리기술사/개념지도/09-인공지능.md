# 인공지능 전체 개념지도

이 문서는 `../학습등급표/09-인공지능.md`에서 정한 학습 범위를 **개념 관계로 재배치한 최상위 탐색 지도**다.

여기서 AI 전체의 좌표를 잡은 뒤, Machine Learning·Deep Learning은 `09-인공지능-ML-DL.md`, 생성형 AI·LLM은 `09-인공지능-생성형AI-LLM.md`로 내려가 주변 개념을 더 깊게 탐색한다.

세부 동작 원리·수식·Algorithm·예제는 `../세부학습/09-인공지능/`에서 다룬다.

---

## 1. AI 전체 좌표

```text
AI
│
├─ 명시적 지식·규칙으로 판단
│   ├─ Rule 기반
│   └─ 전문가 시스템
│
├─ Data / Feedback에서 Pattern 학습
│   └─ Machine Learning
│       ├─ 지도학습
│       ├─ 비지도학습
│       ├─ 강화학습
│       ├─ 고전 ML
│       └─ Neural Network / Deep Learning
│           └─ Transformer
│               └─ Foundation Model과 연결
│
├─ 사전학습된 범용 Model 활용
│   └─ Foundation Model
│       ├─ Language → LLM
│       ├─ Vision
│       └─ Multimodal
│
├─ 응용
│   ├─ 예측 · 분류 · 군집
│   ├─ 추천
│   ├─ NLP · 음성
│   ├─ Vision / Pattern Recognition
│   ├─ 생성형 AI
│   └─ 자동화 / Agent
│
└─ 전 영역 횡단 통제
    ├─ 평가 · 검증
    ├─ Data 품질 · 개인정보
    ├─ Bias / Fairness
    ├─ XAI
    ├─ AI 보안
    └─ 윤리 · 책임 · Governance
```

핵심은 `AI = LLM`이 아니라는 것이다. LLM·RAG·Agent는 AI 전체 중 Foundation Model과 생성형 AI가 확장된 큰 가지다.

---

## 2. 어떤 방식으로 문제를 해결하는가

```text
문제
 ↓
사용 가능한 것은 무엇인가?
│
├─ 명시적인 지식·규칙
│   └─ Rule / 전문가 시스템
│
├─ Data에서 Pattern을 학습
│   └─ Machine Learning
│       ├─ 정답 있음       → 지도학습
│       ├─ 정답 없음       → 비지도학습
│       └─ 행동 결과의 보상 → 강화학습
│
└─ 이미 대규모 사전학습된 Model
    └─ Foundation Model 활용
        ├─ Prompt / Context
        ├─ RAG
        ├─ Fine-tuning
        └─ Tool / Agent
```

Machine Learning을 더 파려면 → `09-인공지능-ML-DL.md`

Foundation Model·생성형 AI·LLM을 더 파려면 → `09-인공지능-생성형AI-LLM.md`

## 3. Machine Learning에서 Deep Learning으로 내려가는 위치

```text
Machine Learning
├─ 고전 ML
│   ├─ 회귀 · 통계
│   ├─ 거리 기반
│   ├─ Tree · Ensemble
│   ├─ SVM · Bayesian
│   ├─ 군집
│   └─ 차원축소
│
└─ Neural Network / Deep Learning
    ├─ MLP / DNN
    ├─ CNN
    ├─ RNN → LSTM / GRU
    └─ Attention → Transformer
```

고전 ML의 여러 Algorithm은 하나의 발전 사슬이 아니라 문제와 Data 조건에 따라 비교·선택하는 병렬 꼭지다.

Transformer는 Deep Learning Architecture이면서 Foundation Model·LLM 영역으로 넘어가는 중요한 연결점이다.

→ `09-인공지능-ML-DL.md`

## 4. 생성형 AI와 LLM의 위치

```text
Foundation Model
├─ Language Foundation Model
│   └─ LLM
├─ Vision Foundation Model
├─ Multimodal Foundation Model
└─ Domain Foundation Model

Generative AI
├─ Text  → LLM
├─ Image → GAN / Diffusion 등
├─ Audio / Video
└─ Multimodal
```

`Foundation Model`, `Generative AI`, `LLM`, `Transformer`, `GAN`, `Diffusion`, `Multimodal`은 같은 분류축의 용어가 아니다.

```text
LLM
├─ 지시·예제     → Prompt / Few-shot
├─ 외부 지식     → RAG
├─ 행동 조정     → Fine-tuning
└─ 외부 행동     → Tool / Agent
                     ├─ MCP
                     └─ Harness
```

→ `09-인공지능-생성형AI-LLM.md`

## 5. 응용은 Model과 별개의 축이다

```text
AI 기술
 ↓
응용 문제
├─ 추천
├─ NLP / 음성 / Chatbot
├─ Vision / Pattern Recognition
├─ 예측 · 분류
├─ Text2SQL
└─ 업무 자동화
```

예를 들어 Text2SQL은 LLM 자체가 아니라 자연어를 SQL로 바꾸는 Task다. Rule, 전용 ML, LLM 등 여러 방법으로 구현할 수 있다.

## 6. 평가·운영·통제는 전 영역을 가로지른다

```text
문제 정의
 ↓
Data 준비
 ↓
Training / Model 활용
 ↓
Evaluation
 ↓
Deployment / Inference
 ↓
Monitoring
 ↓
재학습 · 사용 제한 · Rollback

[전 과정]
Data 품질 · 개인정보 · Bias / Fairness · XAI · 보안 · 책임 · Governance
```

평가와 통제는 마지막 단계의 부록이 아니라 고전 ML·Deep Learning·Foundation Model·LLM 응용 전체에 교차한다.

ML의 평가·검증 꼭지는 `09-인공지능-ML-DL.md`에서 더 내려간다.

---

## 7. 서로 다른 분류축을 구분한다

```text
[문제 해결 / 학습 방식]
Rule / 지도 / 비지도 / 강화 / 기반모델 활용

[Algorithm / Architecture]
회귀 / Tree / SVM / CNN / RNN / Transformer ...

[생성 방식]
Autoregressive / GAN / Diffusion

[Modality]
Text / Image / Audio / Video

[범용성]
Task-specific Model / Foundation Model

[활용 방식]
Prompt / RAG / Fine-tuning / Tool / Agent / MCP

[응용 Task]
추천 / Vision / Text2SQL / Chatbot ...
```

같은 축의 개념은 비교하고, 다른 축의 개념은 실제로 어떻게 조합되는지 연결해서 본다.

## 8. 이 지도를 사용하는 법

```text
학습등급표
"무엇을 얼마나 볼 것인가"
        ↓
인공지능 전체 개념지도
"어느 큰 가지에 있는가"
        ↓
┌──────────────────────────┐
│                          │
ML·DL 개념지도        생성형 AI·LLM 개념지도
"ML 쪽으로 파기"      "LLM 쪽으로 파기"
│                          │
└────────────┬─────────────┘
             ↓
          세부학습
"왜 필요하고 어떻게 동작하는가"
```

하위 지도가 또 너무 커져 한 번에 관계를 파악하기 어려워질 때만 추가 지도를 만든다. 파일 수를 늘리는 것 자체가 목적은 아니다.
