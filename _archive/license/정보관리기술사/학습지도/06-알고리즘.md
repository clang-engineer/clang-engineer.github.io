# Vol. 6 알고리즘 학습지도

> 기준: 정보관리기술사 단독 대비를 위한 1차 분류다. 알고리즘은 답안의 기술적 근거를 만드는 영역이며, 손계산·코드 추적 숙련은 별도 층으로 관리한다.

## 이 권의 역할

알고리즘은 문제를 데이터 표현, 연산 절차, 정확성, 시간·공간 비용으로 분해하여 기술 선택의 근거를 제공한다. 정보관리 답안에서는 구현 코드보다 **왜 이 구조와 알고리즘을 선택하는가**가 중심이다.

핵심 질문은 세 가지다.

1. 문제 특성과 연산에 맞는 자료구조를 어떻게 선택하는가?
2. 정확성과 시간·공간 복잡도를 어떻게 설명하고 비교하는가?
3. 탐색·정렬·Tree·Graph 원리가 DB, OS, Network, AI 답안의 근거로 어떻게 쓰이는가?

## 권 내부 큰 그림

```text
문제와 입력 규모 정의
→ 필요한 연산·제약 식별
→ Array·List·Stack·Queue·Tree·Graph로 표현
→ 탐색·정렬·순회·최적화 절차 선택
→ 정확성·종료성 검토
→ 시간·공간 복잡도와 최악/평균 비용 평가
→ 실제 저장계층·동시성·분산 비용으로 보정
→ 시스템 설계 선택의 근거로 사용
```

## 권장 학습 순서

1. `자료구조·알고리즘·Big-O`로 평가 언어를 만든다.
2. `Array/List → Stack/Queue`로 저장과 연산의 Trade-off를 익힌다.
3. `정렬 → 탐색 → Hash`로 비교·분할·분포 기반 접근을 비교한다.
4. `Tree/BST/균형 Tree/B-Tree`로 메모리와 저장장치 계층의 차이를 본다.
5. `Graph 표현 → DFS/BFS → MST`로 관계 데이터와 경로 문제를 연결한다.
6. 재귀·수식·코드 추적은 개념을 확인하는 최소 실습으로 분리한다.

손계산은 **한 번의 대표 예제로 상태 변화와 복잡도 근거를 설명하는 수준**까지 한다. 숫자만 바뀐 반복 문제, C 문법 복원, 주소값 추적은 기출 근거가 없으면 C다.

## 토픽 간 연결

```text
연속 저장 → 빠른 임의 접근, 삽입·삭제 이동 비용
비연속 연결 → 삽입·삭제 유연, 탐색·지역성 비용
LIFO/FIFO/Priority 규칙 → Stack/Queue/Heap 선택
```

```text
정렬되지 않은 Data → 선형 탐색
정렬 유지 가능 → 이진 탐색
Key 분포와 Hash 함수 활용 → 평균 O(1), 충돌 비용
동적 정렬 집합 → 균형 BST
Block I/O 중심 대용량 Index → B/B+ Tree
```

```text
관계를 Vertex·Edge로 모델링
→ 인접행렬은 빠른 Edge 확인, O(V²) 공간
→ 인접 List는 희소 Graph에 효율
→ DFS는 깊이·Backtracking, BFS는 무가중 최단 단계
→ MST는 모든 정점을 최소 총비용으로 연결
```

## 보정 기록

- 알고리즘 항목은 단독 구현보다 **DB Index, Scheduling, Network Routing, AI**의 결합문항에서 `선택 근거`를 우선 강화한다.
- 손계산은 최근 기출에서 반복된 형태만 대표 예제 하나로 보강한다.
- C/C++ 코드 재현은 의사코드나 상태 전이 설명으로 대체 가능한지 먼저 판단한다.
- 구형 압축·Tree·상호배제 구현은 개념적 기여와 현재 실무 적용을 분리한다.
- 변경 시 `기존 등급 → 새 등급`, 근거 회차, 질문 형태를 기록한다.

- `[현행]` 표기는 개념의 폐기 여부가 아니라, 현재 성능 측면에서 어떤 적용 제약이 남는지 정리한다.
- `B-tree/B+Tree`는 연산 복잡도보다 `메모리 계층(메인/디스크)` 및 동시접근 비용 연결이 핵심이다.
- `정렬`은 평균·최악보다 `입력 상태 가정`과 `재가공/추가 메모리 비용`을 함께 제시하는 형태로 압축한다.
