# Vol. 6 알고리즘 학습지도

> 기준: 정보관리기술사 단독 대비를 위한 1차 분류다. 알고리즘은 답안의 기술적 근거를 만드는 영역이며, 손계산·코드 추적 숙련은 별도 층으로 관리한다.

## 이 권의 역할

알고리즘은 문제를 풀기 위한 절차이고, 자료구조는 그 과정에서 데이터를 담는 방식이다. 같은 문제도 데이터의 양과 필요한 연산에 따라 알맞은 구조와 절차가 달라진다. 정보관리 답안에서는 코드를 외우기보다 **왜 이 자료구조와 알고리즘을 선택했는지** 설명하는 것이 중요하다.

핵심 질문은 세 가지다.

1. 데이터를 자주 조회하는지, 추가·삭제하는지에 따라 어떤 자료구조를 선택할 것인가?
2. 결과가 정확히 나오고 끝나는지, 실행시간과 메모리를 얼마나 쓰는지 어떻게 비교할 것인가?
3. 정렬·탐색·트리·그래프 원리가 데이터베이스, 운영체제, 네트워크, 인공지능에 어떻게 쓰이는가?

## 권 내부 큰 그림

`→`는 먼저 이해할 내용을, `├─`는 목적에 따라 고르는 여러 선택지를 뜻한다. 알고리즘을 고를 때는 항상 결과의 정확성, 실행시간, 메모리 사용량을 함께 살핀다.

```text
문제와 입력 규모·필요 연산·제약
├─ 자료 표현 선택
│  ├─ 순차: 배열·리스트
│  ├─ 처리 규칙: 스택·큐·Deque·Priority 큐(Heap)
│  ├─ 키 조회: 해시·BST·균형 BST
│  ├─ 계층: 트리
│  └─ 관계: 그래프
├─ 처리 절차 선택
│  ├─ 정렬
│  ├─ 탐색
│  ├─ 순회·도달성: DFS·BFS
│  └─ 연결 최적화: MST
└─ [횡단 평가] 정확성·종료성, 시간·공간·평균/최악, 입력 상태·갱신 빈도·지역성
      (선택 결과를 되돌려 재평가하는 피드백)

→ 실제 저장계층·캐시·블록 I/O·동시성·분산 비용으로 보정
→ 시스템 설계 선택의 근거로 사용
```

## 권장 학습 순서

전체 학습 흐름: `ADT·불변식·Big-O → 선형 자료구조·처리 규칙 → 재귀 기초 → 정렬·탐색 → 키 조회(해시·BST 비교) → 트리 → 균형 트리/B+ 트리 분기 → 그래프 → DFS·BFS/MST 분기 → 저장계층 비용`

아래 번호는 선행 학습 순서다. `→`는 이해 순서이지 인과 관계가 아니며, 트리·그래프처럼 **분기**로 나뉘는 부분은 두 갈래를 비교하며 학습한다.

1. `자료구조·알고리즘·Big-O`로 평가 언어를 만든다.
2. `배열/리스트 → 스택/큐/Heap`으로 저장과 처리 규칙의 상충관계를 익힌다.
3. 재귀는 종료·Call 스택·분할 개념만 트리/그래프 순회 전에 두고, 상세 실습·코드 추적은 분리한다.
4. `정렬`과 `탐색`은 이진 탐색의 **정렬 전제**에서만 연결하고, `해시·BST`는 키 조회의 병렬 선택지로 비교한다.
5. `트리 기본 → BST`를 잡은 뒤 `AVL/RB(메모리 높이 제어)`와 `B/B+ 트리(블록 I/O 절감)`를 목적별 분기로 본다.
6. `그래프 표현`을 잡은 뒤 `DFS/BFS(순회·도달성)`와 `MST(가중 무방향 연결)`를 병렬 문제군으로 연결한다.
7. 손계산·수식·코드 추적은 개념을 확인하는 최소 실습으로 분리한다.

손계산은 **한 번의 대표 예제로 상태 변화와 복잡도 근거를 설명하는 수준**까지 한다. 숫자만 바뀐 반복 문제, C 문법 복원, 주소값 추적은 기출 근거가 없으면 C다.

## 토픽 간 연결

```text
연속 저장 → 빠른 임의 접근, 삽입·삭제 이동 비용
비연속 연결 → 삽입·삭제 유연, 탐색·지역성 비용
LIFO/FIFO/Priority 규칙 → 스택/큐/Heap 선택
```

```text
정렬되지 않은 데이터 → 선형 탐색
정렬 유지 가능 → 이진 탐색
키 분포와 해시 함수 활용 → 평균 O(1), 충돌 비용
동적 정렬 집합 → 균형 BST
블록 I/O 중심 대용량 인덱스 → B/B+ 트리
```

```text
관계를 Vertex·Edge로 모델링
→ 인접행렬은 빠른 Edge 확인, O(V²) 공간
→ 인접 리스트는 희소 그래프에 효율
→ DFS는 깊이·Backtracking, BFS는 무가중 최단 단계
→ MST는 모든 정점을 최소 총비용으로 연결
```

## 1차 회독 통과 기준

첫 회독에서는 다음 관계만 설명할 수 있으면 된다.

1. 배열은 빠른 위치 접근에, 연결 리스트는 잦은 삽입·삭제에 유리하다.
2. 스택·큐·우선순위 큐는 데이터를 꺼내는 순서가 서로 다르다.
3. 이진 탐색은 정렬이 필요하고, 해시는 충돌 비용, 탐색 트리는 높이 비용이 생긴다.
4. 균형 트리는 메모리에서 높이를 줄이고, B+ 트리는 저장장치 접근 횟수를 줄이는 데 유리하다.
5. 그래프는 관계를 나타내며 DFS·BFS·MST는 서로 다른 문제를 해결한다.
6. Big-O는 입력이 커질 때 실행시간과 메모리 사용량이 얼마나 늘어나는지 비교하는 기준이다.

## 보정 기록

- 알고리즘 항목은 단독 구현보다 **DB 인덱스, Scheduling, 네트워크 Routing, AI**의 결합문항에서 `선택 근거`를 우선 강화한다.
- 손계산은 최근 기출에서 반복된 형태만 대표 예제 하나로 보강한다.
- C/C++ 코드 재현은 의사코드나 상태 전이 설명으로 대체 가능한지 먼저 판단한다.
- 구형 압축·트리·상호배제 구현은 개념적 기여와 현재 실무 적용을 분리한다.
- 변경 시 `기존 등급 → 새 등급`, 근거 회차, 질문 형태를 기록한다.

- `[현행]` 표기는 개념의 폐기 여부가 아니라, 현재 성능 측면에서 어떤 적용 제약이 남는지 정리한다.
- `B-tree/B+트리`는 연산 복잡도보다 `메모리 계층(메인/디스크)` 및 동시접근 비용 연결이 핵심이다.
- `정렬`은 평균·최악보다 `입력 상태 가정`과 `재가공/추가 메모리 비용`을 함께 제시하는 형태로 압축한다.
