# Vol. 9 인공지능 학습지도

> 기준: 정보관리기술사 단독 대비를 위한 1차 분류다. 출제 여부를 고정하지 않으며 공식 출제기준·기출을 보고 A/B/C를 다시 조정한다.

## 이 권의 역할

인공지능은 데이터나 명시적인 규칙을 이용해 예측·분류·생성·의사결정을 수행한다. 정보관리기술사에서는 모델 이름을 많이 아는 것보다, 어떤 문제와 데이터에 어떤 방법을 적용하고 잘못된 판단의 위험을 어떻게 관리하는지가 중요하다.

핵심 질문은 세 가지다.

1. 정답 데이터, 정답 없는 데이터, 행동 결과의 보상 중 무엇을 이용해 학습할 것인가?
2. 모델이 얼마나 정확하고 안정적이며 공정한지 어떻게 확인할 것인가?
3. 잘못된 판단이나 공격이 발생했을 때 누가 책임지고 어떻게 차단·복구할 것인가?

## 권 내부 큰 그림

`→`는 선택·생명주기 순서, `├─`는 병렬 분기, `[횡단]`은 전 과정에 적용하는 통제를 나타낸다. 규칙 기반은 데이터 학습을 전제하지 않는 별도 분기이며, 윤리·보안·설명가능성은 마지막 단계가 아니라 모든 단계에 교차한다.

```text
지식·의사결정 문제와 실패 비용
→ 과제 정의(예측·분류·군집·순차 의사결정·생성·지각·언어)
→ 데이터·지식·피드백 조건 확인
│  ├─ 명시적 지식      → 규칙·전문가 시스템(데이터 학습이 선행되지 않음)
│  ├─ 정답 데이터      → 지도학습
│  ├─ 정답 없이 구조   → 비지도학습
│  └─ 행동·보상 피드백 → 강화학습
→ 데이터의 형태와 문제에 맞는 방법 선택
   ├─ 고전 기계학습·신경망을 직접 학습
   └─ 사전학습된 기반모델·LLM을 활용하거나 추가 학습
→ 데이터 준비·학습·검증·보정
→ 배포·추론·모니터링
→ 문제가 생기면 사용을 제한하고 이전 모델로 되돌리거나 다시 학습

[횡단 통제: 전 과정에 교차]
데이터 품질·개인정보 보호·공정성, 보안 위협, XAI·책임·감사

[응용 분기: 문제별 적용 영역]
음성·NLP·추천·패턴인식·보안

⇒ 예측 · 생성 · 권고 · 자동화된 행동
```

인공지능은 알고리즘 이름을 모두 외우는 과목이 아니다. **왜 이 방법을 선택했는지**, 결과를 무엇으로 평가하고 운영 중 발생하는 문제를 어떻게 통제할지를 이해하는 것이 중요하다.

### 먼저 알아둘 약어

| 약어 | 원어·쉬운 뜻 |
|---|---|
| AI | Artificial Intelligence, 지식이나 데이터로 판단·예측·생성하는 인공지능 |
| ML·DL | Machine Learning·Deep Learning, 데이터에서 규칙을 학습하는 기계학습과 다층 신경망을 이용하는 딥러닝 |
| XAI | Explainable AI, 모델의 판단 근거를 사람이 이해할 수 있게 설명하는 인공지능 |
| MDP | Markov Decision Process, 상태·행동·보상·전이로 순차 의사결정을 표현하는 모델 |
| DQN | Deep Q-Network, Q-Learning의 가치함수를 심층 신경망으로 근사하는 방법 |
| CNN | Convolutional Neural Network, 공간적 특징을 뽑는 데 강한 합성곱 신경망 |
| RNN | Recurrent Neural Network, 이전 상태를 이어받아 순서가 있는 데이터를 처리하는 순환 신경망 |
| LSTM·GRU | Long Short-Term Memory·Gated Recurrent Unit, RNN의 장기 의존성 문제를 줄인 신경망 구조 |
| LLM | Large Language Model, 대규모 데이터로 사전학습해 언어를 이해·생성하는 대규모 언어모델 |
| RAG | Retrieval-Augmented Generation, 외부 자료를 검색해 생성 모델의 답변 근거로 제공하는 검색증강생성 |

## 권장 학습 순서

아래 구분은 관련 주제를 함께 공부하기 위한 권장 순서다. 실제 기술·업무의 처리 절차를 뜻하지 않으며, 선행관계가 약한 단계는 병행해도 된다.

전체 학습 흐름: `AI 개념·윤리 → 학습 방식과 생명주기 → 데이터 분할·평가 → 고전 ML 방법 계열 → 순차·강화·표현학습 → 신경망 → 응용·운영 통제 → (선택 보강) 생성형 AI·LLM`

아래 화살표는 선행 학습 순서다. `→`는 이해 순서이며, 윤리·설명가능성·보안은 처음 도입한 뒤 모든 단계에서 반복 적용하는 **횡단 통제**다.

### 1단계: AI 개념과 횡단 통제

`AI 개요(1~5) → 규칙·전문가 시스템(6·8) → 추천·탐색 에이전트(7~13) → 비상 중단·AI 윤리(14~17)`

규칙 기반은 데이터 학습을 전제하지 않는 별도 분기로 본다. 윤리·설명가능성은 모델 상세보다 통제 기준으로 먼저 잡는다.

### 2단계: 학습 패러다임과 평가 기반

`ML/전통 방식 비교(59~60) → 지도·비지도·강화학습(61~64) → DL 개요(65) → 데이터 분할·교차검증(111) → 평가 지표(91~93)`

모델 목록보다 **어떤 데이터·피드백 조건이 주어졌는가**로 패러다임을 고른다. 정확도(Accuracy)와 정밀도·재현율(Precision·Recall)·F1은 선후 관계가 아니라 과제 비용에 따라 고르는 동급 지표다.

### 3단계: 고전 ML 방법 계열

`탐색·최적화(18~20) · 통계·거리 기반(21~30) · 연관규칙(31~33) · 앙상블·트리·KNN(34~41) · SVM(42~43) · 베이지안(44~45) · 군집·차원축소(46~51)`

서로 독립된 **병렬 계열**이다. 하나의 지식 사슬로 외우지 말고, 과제 조건과 데이터 형태에 맞는 선택지로 비교한다.

### 4단계: 순차 의사결정·강화·표현학습

`MDP(52) → Q-Learning(55) → DQN(87)`과 `HMM(53)`, `탐색(MCTS: 54)`, `텍스트 표현(56~58)`은 의존 관계가 서로 다른 분리된 흐름이다. MDP→Q-Learning→DQN만 직접 의존 사슬로 연결한다.

### 5단계: 신경망과 표현력

`신경망 요소(67~70) → MLP·DL 파라미터(71~75) → 역전파·과적합 제어(76~80) → CNN/RNN(81~82) → LSTM/GRU(83~84)`

RNN→LSTM/GRU는 직접 의존으로 보고, DQN(87)은 강화학습과 네트워크의 결합 지점으로 연결한다.

### 6단계: 응용과 운영 통제

`응용 분기(94~105·108) → ML 파이프라인·V 모델(100·116~117) → 배포·추론·모니터링 → 보안 위협·XAI·거버넌스(112~122)`

실제 답안에서는 정확도뿐 아니라 위험과 책임을 함께 설명한다. 배포 뒤 데이터·성능 변화를 관찰하고 재학습·사용 제한·롤백 조건까지 제시한다.

### 선택 보강: 생성형 AI·LLM

`Transformer·자기어텐션 → 사전학습 기반모델·LLM → Prompt·RAG·미세조정 → 평가·안전성 → 배포·모니터링·비용 관리`

생성형 AI는 지도·비지도·강화학습과 나란히 놓이는 단일 학습 방식이 아니다. 사전학습된 모델을 업무에 적용하는 흐름으로 위치를 잡고, 환각·근거성·개인정보·보안·비용·책임을 함께 본다. 교재 밖 세부 내용은 별도 Markdown에서 확장한다.

## 토픽 간 연결

### 학습 설계의 핵심 인과

```text
문제와 실패 비용 확인
→ 사용할 지식·정답 데이터·보상·사전학습 모델 조건 확인
→ 규칙 기반·지도·비지도·강화학습·기반모델 활용 중 접근 방식 결정
→ 거리·트리·신경망 등 구체적인 방법 선택
→ 오차·편향·과적합·공정성 평가
→ 위험 완화와 배포 기준 결정
```

문제를 모르면 모델이 비싼 비용이 된다.

### 모델 성능과 책임

```text
정량지표: Accuracy·Precision·Recall·F1 — 과제 비용에 따라 동급으로 선택
→ 함께 확인할 운영 기준
├─ AI 보안(적대적 공격·방어)
├─ XAI·모니터링(설명성·거버넌스)
└─ 운영 정책·서비스 거부·롤백 시나리오
```

정보관리 답안에서는 성능지표만 제시하지 않고 운영 통제와 책임까지 함께 설명한다.

### 도메인 연결

```text
기획(업무 목표) → 데이터 준비·품질관리 → 학습·평가 → 배포·추론·모니터링 → 사고·보안 대응 → 개선
```

## 1단계 보강 반영(Vol.9)

### 핵심 템플릿

`문제 유형` → `학습 패러다임 선택` → `데이터/지표` → `안전성·설명성` → `운영 조치`를 항상 한 번에 답안으로 묶는다.

### Vol.8/Vol.9 연계 정리

- 데이터 파이프라인 질문은 모델 성능만 묻는 문제가 아니라 `메타데이터·품질 지표`를 먼저 확인하는 구조로 정리한다.
- 분류·추천은 과제별 Precision/Recall/F1·순위 지표를 선택하고, 군집은 내부·외부 군집 평가 지표를 구분한다. 과적합·편향은 `완화(재학습/입력 제어/검증)`로 마무리한다.

### Vol.10 연계 정리

- 클라우드 기반 AI 적용에서는 `컴퓨팅 할당`보다 `책임 경계`, `로그 보존`, `침해 대응`이 선행되어야 한다.
- Auto Scaling/관측성 항목이 나오면 `모델 성능`, `보안 대응 시간`, `SLA`를 함께 언급한다.

## 1차 회독 통과 기준

첫 회독에서는 다음 흐름만 설명할 수 있으면 된다.

1. 먼저 해결할 문제와 잘못된 판단이 가져올 피해를 정한다.
2. 사용할 수 있는 정답·데이터·보상에 따라 규칙 기반, 지도·비지도·강화학습을 선택한다.
3. 데이터를 준비하고 학습용·검증용·시험용으로 나누어 모델을 평가한다.
4. 정확도 하나만 보지 않고 오류 비용에 맞는 평가지표와 공정성·설명가능성을 확인한다.
5. 배포 후 데이터와 성능 변화를 관찰하고 필요하면 차단·이전 모델 복구·재학습을 수행한다.
6. 생성형 AI는 사전학습된 기반모델을 활용하며, Prompt·RAG·미세조정은 적용 목적과 데이터·비용·위험에 따라 선택한다.
