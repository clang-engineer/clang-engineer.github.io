# Vol. 9 인공지능 학습지도

> 기준: 정보관리기술사 단독 대비를 위한 1차 분류다. 출제 여부를 고정하지 않으며 공식 출제기준·기출을 보고 A/B/C를 다시 조정한다.

## 이 권의 역할

인공지능은 데이터로부터 의미를 추출해 예측·판단·자동화를 수행하는 방법을 제공한다. 정보관리기술사 관점에서는 `데이터 품질→학습 위험→모델 선택→운영 통제`의 연계 좌표를 만든다.

핵심 질문은 세 가지다.

1. 데이터의 패턴을 어떤 가정으로 학습할 것인지 판단하는가?
2. 학습 결과의 정확성/신뢰성/공정성/설명가능성을 어떻게 검증하는가?
3. 자동화 판단이 잘못될 때 대응 규칙과 거버넌스는 무엇인가?

## 권 내부 큰 그림

```text
지식·의사결정 문제
      ↓
규칙 기반/통계 기반·신경망 기반 학습 선택
      ↓
모델 학습·튜닝(데이터 분할·평가·보정)
      ↓
실행 시 예측·생성·권고를 수행
      ↓
오류·편향·보안 위협을 감시
      ↓
개별 도메인 AI 적용(음성·NLP·추천·보안)과 비즈니스 통제
```

AI는 모든 알고리즘을 다 외우는 과목이 아니라, **왜 그 방법을 쓰는지**와 **실무 제약에서 어떻게 관리하는지**가 중요하다.

## 권장 학습 순서

### 1단계: AI 개념과 윤리

`AI 개요(1~5) → 전문가/규칙기반(6) → 추천/탐색 에이전트(7~13) → 비상 중단 수단(kill switch)과 AI 윤리(14~17)`

윤리·설명가능성은 최신 출제기준과 공식 기출에서 반복 여부를 확인할 보정 후보이다. 모델 상세보다 통제 기준을 먼저 잡는다.

### 2단계: 고전 ML 알고리즘

`탐색·최적화(18~20) → 통계 분석/거리기반(21~30) → 연관규칙(31~33) → 앙상블·트리·KNN(34~40)`

문제의 제약과 데이터 형태를 보고 알고리즘을 고르면, 계산법은 최소화해도 된다.

### 3단계: 고전 ML 확장

`SVM(42) → 베이지안(44) → 군집·차원축소(46~51) → 순차·의사결정 모델(MDP·HMM, 52~53) → 탐색·강화학습(MCTS·Q-Learning, 54~55) → 텍스트 표현(56~58)`

특별히 확률적 결합, 강화, 표현학습이 서로 다른 리스크를 만든다.

### 4단계: DL/ML 학습 체계

`학습 패러다임(61~67) → 신경망(68~75) → 역전파/최적화/과적합 제어(76~80) → DNN/CNN/RNN/LSTM/GRU`.

과적합·학습률·하이퍼파라미터는 실제 과제에서 자주 쓰는 지표로 압축한다.

### 5단계: 운영 적용

`평가 지표(91~93) → 패턴/음성/NLP(94~105) → 운영성·보안 위협·ML 파이프라인(106~122)`

실제 답안에서는 정확도만 아니라, 위험 및 책임을 붙여 말하는 능력이 더 중요하다.

## 토픽 간 연결

### 학습 설계의 핵심 인과

```text
문제와 데이터 유형 확인
→ 지도/비지도/강화 학습 선택
→ 모델/거리/규칙/트리/신경망 중 선택
→ 오차, 편향, 과적합, 공정성 평가
→ 위험 완화와 배포 기준으로 정렬
```

문제를 모르면 모델이 비싼 비용이 된다.

### 모델 성능과 책임

```text
정확도·재현율 등 정량지표
→ Precision/Recall/F1로 오판 위험 분석
→ AI Security 취약점(Adversarial) 점검
→ XAI·모니터링으로 설명성·거버넌스 강화
→ 운영 정책·서비스 거부 시나리오 정의
```

정보관리 답안에서는 결과보다 제어가 더 중요하다.

### 도메인 연결

```text
기획(업무 목표) → 데이터 전처리/품질 → 학습/평가 → 분석·운영 → 사고·보안 대응 → 개선
```

## 1단계 보강 반영(Vol.9)

### 핵심 템플릿

`문제 유형` → `학습 패러다임 선택` → `데이터/지표` → `안전성·설명성` → `운영 조치`를 항상 한 번에 답안으로 묶는다.

### Vol.8/Vol.9 연계 정리

- 데이터 파이프라인 질문은 모델 성능만 묻는 문제가 아니라 `메타데이터·품질 지표`를 먼저 확인하는 구조로 정리한다.
- 분류·추천은 과제별 Precision/Recall/F1·순위 지표를 선택하고, 군집은 내부·외부 군집 평가 지표를 구분한다. 과적합·편향은 `완화(재학습/입력 제어/검증)`로 마무리한다.

### Vol.10 연계 정리

- 클라우드 기반 AI 적용에서는 `컴퓨팅 할당`보다 `책임 경계`, `로그 보존`, `침해 대응`이 선행되어야 한다.
- Auto Scaling/관측성 항목이 나오면 `모델 성능`, `보안 대응 시간`, `SLA`를 함께 언급한다.

## 보정 기록

- 용어보다 사례·목표 중심으로 판단해 출제되므로, 계산 과목성 토픽은 1회 대표 예시로만 보강한다.
- XAI, Data governance, Adversarial, 교차검증은 공식 기출에서 반복 여부를 확인한 뒤 우선순위를 유지하거나 조정한다.
- 규칙기반·전문가시스템은 최신 LLM 환경에서 대체되더라도 원리 비교 관점은 유지한다.
- Part2~3의 알고리즘은 수치 구현보다 응답 적합성 판정(정확도/안전성/설명성)으로 압축한다.
- 변경 시 `기존 등급 → 새 등급`, 근거 회차, 질문 형태를 기록한다.

- `XAI`/`Adversarial`/`교차검증`은 `정확도`만이 아니라 `책임 한계`와 `회귀 평가`까지 함께 제시한다.
- `LLM/딥러닝` 관련 최신 연동 항목은 단일 기술 채택보다 `감시 지표(F1·리콜·오탐/미탐), 운영 경계, 롤백 조건`으로 문장화한다.
- `규칙기반·전문가 시스템`은 배경 용어를 역사로 제한하고, 현재 시험에서 요구되는 비교는 `재학습 주기`, `편향 통제`, `권한 분리`로 정리한다.
- `[현행]`/`[최신]` 표기는 용어보다 AI 운영책임의 이행 주기(학습→배포→감사)로 정렬한다.
