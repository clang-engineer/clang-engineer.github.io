# 인공지능 학습지도

이 문서는 `../학습등급표/09-인공지능.md`에서 정한 학습 범위를 바탕으로, **하나의 개념에서 상위·하위·인접 개념으로 파고들며 학습할 수 있도록 연결하는 지도**다.

단순한 시험 범위표나 AI 분류표가 목적이 아니다. 학습할 때 `이 개념의 상위는 무엇인가`, `바로 아래에는 무엇이 있는가`, `옆의 비슷한 개념은 무엇인가`, `다음에는 무엇을 파야 하는가`를 찾는 데 사용한다.

세부 Algorithm의 내부 동작·Parameter·긴 예제는 `../세부학습/09-인공지능/`의 문서에서 다룬다.

---

## 1. 가장 먼저 볼 전체 지도: AI는 LLM보다 크다

```text
AI
├─ 명시적 지식·규칙으로 판단
│   ├─ Rule 기반
│   └─ 전문가 시스템
└─ Data / Feedback에서 Pattern 학습
    └─ Machine Learning
        ├─ 지도학습
        │   ├─ 분류
        │   └─ 회귀
        ├─ 비지도학습
        │   ├─ 군집
        │   └─ 차원축소
        └─ 강화학습
            └─ MDP → Q-Learning → DQN

Machine Learning
├─ 고전 ML
│   ├─ 회귀 · 통계 · 거리 기반
│   ├─ Tree · Ensemble · KNN
│   ├─ SVM · Bayesian
│   ├─ 연관규칙
│   └─ 군집 · 차원축소
└─ Neural Network / Deep Learning
    ├─ MLP
    ├─ CNN
    ├─ RNN → LSTM / GRU
    └─ Transformer
        └─ Foundation Model / LLM과 연결

[전 영역 횡단]
평가 · Data 품질 · 공정성 · XAI · 보안 · 윤리 · Governance
```

RAG·Agent·MCP는 이 전체 중 LLM 활용 가지에서 파고드는 개념이다.

## 2. 학습 방식: 어떤 Feedback을 가지고 있는가

```text
문제를 해결해야 함
 ↓
무엇을 이용할 수 있는가?
├─ 사람이 정의한 명시적 지식
│   └─ Rule / 전문가 시스템
├─ 입력 + 정답
│   └─ 지도학습
│       ├─ 분류
│       └─ 회귀
├─ 정답 없는 Data
│   └─ 비지도학습
│       ├─ 군집
│       └─ 차원축소
└─ 행동 결과의 보상
    └─ 강화학습
        ↓
       MDP
        ↓
    Q-Learning
        ↓
       DQN
```

`지도 → 비지도 → 강화`는 발전 순서가 아니라 학습 신호에 따른 병렬 패러다임이다. HMM과 MCTS는 같은 순차·탐색 영역에서 만날 수 있지만 `MDP → Q-Learning → DQN`의 직접 하위 단계는 아니다.

## 3. 고전 Machine Learning: 병렬 Algorithm 계열

```text
Machine Learning
├─ 회귀 · 통계 기반
│   ├─ 상관분석
│   ├─ 회귀분석
│   └─ Logistic Regression
├─ 거리 기반
│   ├─ KNN
│   ├─ Euclidean / Mahalanobis
│   └─ Jaccard / Hamming
├─ Tree 기반
│   ├─ Decision Tree
│   └─ Ensemble
│       ├─ Bagging
│       ├─ Boosting
│       └─ Random Forest
├─ 경계 기반
│   └─ SVM
├─ 확률 기반
│   └─ Bayesian
├─ Pattern / 관계 발견
│   └─ Apriori
└─ 비지도 구조 탐색
    ├─ K-Means / DBSCAN
    └─ PCA / ICA
```

이 영역은 하나의 발전 사슬이 아니다. 각 꼭지를 잡고 문제 조건·장단점·비교 대상을 옆으로 파는 영역이다.

## 5. 평가와 검증

```text
Data
 ↓
Train / Validation / Test
 ↓
Training
 ↓
Validation
│   └─ Cross Validation / K-Fold
 ↓
Test
```

분류 평가:

```text
Confusion Matrix
├─ Accuracy
├─ Precision
├─ Recall
└─ F1
```

Accuracy·Precision·Recall·F1은 발전 순서가 아니라 오류 비용에 따라 선택·비교하는 동급 지표다. 주변에는 Overfitting, Generalization, Bias, Data Leakage, Data 품질이 연결된다.

## 6. 서로 다른 분류축을 섞지 않는다

```text
[학습 방식]
지도 / 비지도 / 강화

[Architecture]
MLP / CNN / RNN / Transformer

[생성 방식]
Autoregressive / GAN / Diffusion

[Modality]
Text / Image / Audio / Video

[범용성]
Task-specific Model / Foundation Model

[활용 방식]
Prompt / RAG / Fine-tuning / Tool / Agent / MCP
```

따라서 `CNN → RNN → GAN → Transformer`, `LLM → GAN → Diffusion → Multimodal`처럼 한 줄의 발전 단계로 만들지 않는다.

## 9. LLM 활용: 무엇이 부족한가

```text
                         LLM
                          │
        ┌─────────────────┼─────────────────┐
        ↓                 ↓                 ↓
      지시·예제           외부 지식            행동
        │                 │                 │
Prompt / Few-shot         RAG          Tool Calling
                          │                 │
                     Embedding             Agent
                     Retrieval              │
                                           MCP

Model 행동 자체를 반복적으로 조정
→ Fine-tuning
```

```text
규칙·역할            → System Prompt

외부 세계에서 행동    → Tool / Agent
```

## 10. RAG: 외부 지식 가지를 따라간다

```text
RAG
├─ 사전 구축
│   └─ 문서
│       ↓
│     Chunking
│       ↓
│     Embedding Model
│       ↓
│     Chunk Vector
│       ↓
│     Vector DB
└─ 질문 시
    └─ Query
        ↓
      Query Embedding
        ↓
      Retrieval
        ├─ Keyword / BM25
        ├─ Vector Search
        │   ├─ Exact Search
        │   └─ ANN
        │       ├─ HNSW
        │       └─ IVF / IVFFlat
        └─ Hybrid Search
        ↓
      Re-ranking
        ↓
      Top-K 원문 Chunk
        ↓
      LLM Context
        ↓
      Generation
```

검색용 Vector는 원문을 압축해서 LLM에 넣기 위한 것이 아니라 관련 원문을 찾기 위한 의미적 검색 표현이다.

상세: `../세부학습/09-인공지능/임베딩-벡터검색-RAG.md`

## 11. Fine-tuning

```text
Fine-tuning
├─ [학습 신호 관점]
│   └─ SFT
│       └─ 입력-정답 Pair
└─ [Parameter 효율 관점]
    ├─ Full Fine-tuning
    └─ PEFT
        └─ LoRA

SFT + LoRA
→ 함께 사용 가능
```

Prompt·Few-shot·RAG는 주로 Inference Context를 바꾸고, Fine-tuning은 Training으로 학습 Parameter를 바꾼다.

상세: `../세부학습/09-인공지능/Fine-tuning과-PEFT-LoRA.md`

## 12. Agent · Harness · MCP

```text
사용자 목표
 ↓
LLM 판단
 ↓
Tool Call
 ↓
Tool 실행
 ↓
Observation
 ↓
Context에 반영
 ↓
LLM 재판단
 └──────── 반복
```

```text
Agent
├─ LLM
├─ Tool
├─ Observation / Context
├─ Memory
├─ Agentic RAG
└─ Runtime / Harness
    ├─ Rules / Context
    ├─ Skills
    ├─ Hooks
    ├─ Tool / Permission
    ├─ Workflow
    └─ Orchestration
```

```text
Agent / AI Client
 ↓
MCP
├─ Tools
├─ Resources
└─ Prompts
 ↓
MCP Server
 ↓
API / DB / File / 외부 System
```

MCP는 Agent 자체나 Tool 자체가 아니라 외부 기능을 발견·호출하는 공통 Protocol이다. RAG는 관련 정보를 찾는 구조이고 MCP는 그 기능을 Agent에 제공하는 연결 계층이므로 서로 경쟁 기술이 아니다.

상세: `../세부학습/09-인공지능/에이전트와-MCP.md`, `../세부학습/09-인공지능/Agent-Harness.md`

## 13. 응용 문제로 내려간다

```text
AI / ML / DL / Foundation Model
 ↓
응용
├─ 추천
├─ 음성 / NLP / Chatbot
├─ Vision / Pattern Recognition
├─ 보안
└─ 업무 자동화
```

Text2SQL 예:

```text
Text2SQL
├─ Rule / Template
├─ 전용 ML
└─ LLM 기반
    ├─ Metadata / Schema Retrieval
    ├─ Schema Linking
    ├─ SQL Generation
    └─ Validation
```

Text2SQL은 Task이고, Schema Linking은 자연어와 DB 구조를 연결하는 문제이며, RAG·LLM·Agent는 이를 구현할 때 조합할 수 있는 기술이다.

```text
 ↓

 ↓

 ↓

```

이 영역은 마지막에 한 번 보는 부록이 아니라 모든 AI 꼭지에 교차해서 연결한다.

## 15. 이 지도를 사용하는 법

예를 들어 `RAG`를 공부하기로 했다면:

```text
상위
LLM 활용
 ↓
RAG

인접
Prompt / Few-shot / Fine-tuning / Agent

하위
Chunking
 ↓
Embedding
 ↓
Retrieval
 ↓
Vector Search
 ↓
ANN
├─ HNSW
└─ IVF
```

여기서 하나를 골라 `세부학습` 문서로 내려간다.

> **학습지도는 모든 내용을 설명하는 문서가 아니라, 학습할 개념 꼭지를 놓치지 않고 주변으로 파고들 수 있게 하는 탐색망이다.**
