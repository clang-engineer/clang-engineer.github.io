# Vol. 3 네트워크 학습지도

> 기준: 정보관리기술사 단독 대비를 위한 1차 분류다. 출제 여부를 단정하지 않으며, 공식 출제기준과 최근 기출을 분석한 뒤 등급을 보정한다.

## 이 권의 역할

네트워크는 서로 떨어진 시스템 사이에서 데이터를 목적지까지 전달한다. 주소와 경로를 정하고, 손실·혼잡·지연·이동·보안 문제에 대응해 필요한 통신 품질을 유지한다.

핵심 질문은 세 가지다.

1. 데이터를 목적지까지 어떤 계층과 주소, 전달 방식으로 보내는가?
2. 손실·혼잡·지연·이동성에 어떻게 대응하여 품질을 보장하는가?
3. 물리 장비 중심 망을 어떻게 가상화·자동화하고 서비스 요구에 맞게 운영하는가?

## 권 내부 큰 그림

```text
두 시스템이 통신해야 함
→ 계층 모델로 역할과 인터페이스 분리
→ Link에서 Frame 전달, IP에서 주소와 경로 결정
→ TCP·UDP가 종단 간 전달 특성 제공
→ 손실·혼잡·지연 발생
→ 흐름·혼잡 제어와 QoS 적용
→ NMS·SNMP로 상태 관측과 운영
→ 무선·이동 환경에서는 공유 매체와 Handover 처리
→ CDN·VPN·SDN·NFV로 품질·보안·운영 유연성 확장
→ IoT·산업망은 제약과 도메인 요구를 추가
```

중심은 통신 기능을 계층별로 나누고, 목적지를 주소로 나타내며, 알맞은 경로를 선택하는 것이다. 여러 사용자가 같은 망을 공유하므로 전송 신뢰성·혼잡·품질을 관리하고 현재 상태를 관측할 수 있어야 한다.

## 권장 학습 순서

### 1단계: 통신 구조와 계층

`교환 방식(3) → OSI·TCP/IP(4·5) → PDU·SDU·SAP(6) → Ethernet(19) → VLAN(22)`

회선 대신 패킷을 나누어 보내는 이유와 계층별 책임을 먼저 잡는다. 장비·프로토콜 목록보다 캡슐화와 인접 계층 인터페이스를 이해한다.

### 2단계: 주소와 경로

`ARP(18) → IP 주소 부족·NAT(23·28) → IPv6(24·25) → Routing(32·33) → Multicast(26·27·34)`

같은 링크의 주소 해석에서 네트워크 간 경로 선택으로 확장한다. NAT는 주소 부족을 완화하지만 종단 간 연결성을 훼손하고, IPv6는 더 큰 주소 공간과 구조 개선을 제공한다.

### 3단계: 종단 간 전송과 품질

`Sliding Window(36) → TCP·UDP(37) → TCP 혼잡제어(38) → 성능 산출(9) → QoS(40~43) → QoE(42)`

신뢰성과 흐름 제어를 이해한 뒤 네트워크 전체의 혼잡 제어로 이어간다. 대역폭·지연·손실·지터와 사용자 체감 품질을 구분한다.

### 4단계: 운영과 응용 전달

`NMS·SNMP(44·45) → HTTP(47) → RTP·RTCP(49·50) → CDN(83) → VPN(88)`

망 상태를 관측한 뒤 애플리케이션별 전달 요구를 본다. 프로토콜 헤더 암기보다 요청·세션·실시간 피드백·캐시 배치의 이유를 연결한다.

### 5단계: 무선과 이동성

`WLAN(52) → CSMA/CA(21) → WLAN 보안(57) → MIMO(72) → Handover(75·76) → 5G(82)`

공유 무선 매체의 충돌 회피와 보안 문제를 먼저 이해한다. 특정 802.11 세대와 과거 이동통신 규격은 현재 아키텍처의 선행 사례로만 본다.

### 6단계: 프로그래머블 네트워크와 IoT

`SDN(103) → NFV(104) → CDN(83) → Sensor 네트워크(111) → IoT(113)`

제어와 전달의 분리, 네트워크 기능의 소프트웨어화를 통해 자동화·탄력성을 얻는 흐름을 본다. IoT는 제약 단말·다양한 링크·보안·운영 규모 문제를 추가한다.

## 토픽 간 연결

### 계층과 종단 간 전달

```text
응용 데이터 생성
→ Transport가 신뢰성·순서·포트 제공 여부 결정
→ IP가 논리 주소와 다음 경로 결정
→ Link가 같은 매체에서 Frame 전달
→ 각 계층 Header를 붙여 캡슐화
→ 목적지에서 역순으로 해제
```

계층화는 변경 영향과 상호운용성을 개선하지만 헤더·처리 비용과 계층 간 정보 단절을 만든다.

### 주소·경로와 확장성

```text
같은 Link의 IP를 MAC으로 해석
→ Router가 다른 네트워크로 전달
→ Routing Protocol이 도달 가능성과 비용을 교환
→ 주소 부족을 NAT로 완화
→ 종단 간 연결성과 운영 복잡도 문제 발생
→ IPv6로 주소 공간 확대
→ Multicast·CDN으로 다수 수신자 전달 비용 절감
```

### 품질과 운영

```text
송신 속도가 수신·망 용량을 초과
→ 큐 증가·손실·재전송
→ TCP 흐름·혼잡 제어
→ 실시간 트래픽은 지연·지터에 민감
→ 분류·표시·큐·Shaping 등 QoS 적용
→ NMS·SNMP와 Telemetry로 상태 관측
→ 사용자 체감 QoE와 서비스 목표로 보정
```

### 가상화와 서비스

```text
장비별 수동 제어의 느린 변경
→ SDN이 제어와 전달을 분리해 중앙 정책화
→ NFV가 전용 장비 기능을 SW로 실행
→ 자동화·탄력성 향상
→ 제어부 집중·가상 자원 성능·관측성 위험
→ 이중화·정책 검증·모니터링으로 통제
```

## 2단계 보강 반영(Vol.3)

### 핵심 템플릿

`통신 요구` → `주소·경로·제어` → `정책 자동화` → `운영 가시성` → `보안·회복성` 순서로 정리한다.

### Vol.3 + Vol.2 연계 정리

종단 성능은 OS의 I/O 처리와 네트워크의 지연·손실이 함께 결정한다.
- 호스트 CPU·I/O 큐와 망 큐·TCP 지표를 분리해 병목을 찾는다.
- 병목 해석은 특정 장비만이 아니라 전달 체인의 상호작용으로 본다.

### Vol.3 + Vol.10 연계 정리

SDN과 NFV는 클라우드 운영에서 `중앙 정책`, `소프트웨어화`, `회복 전략`을 동시에 다룬다.
- 제어·전달 분리는 운영 민첩도를 높이지만 제어부 장애의 영향 범위와 목표 가용성에 따라 분산·이중화·복구 방식을 설계해야 한다.
- 따라서 정책 변경은 `승인·테스트·Rollback`까지 포함해 운영 지표와 함께 제시한다.

## 1차 회독 통과 기준

첫 회독에서는 다음 흐름만 설명할 수 있으면 된다.

1. 계층마다 맡은 역할이 다르며, 데이터는 각 계층의 정보를 붙여 전달된다.
2. 링크 계층은 같은 망 안에서, IP는 서로 다른 망 사이에서 데이터를 전달한다.
3. 라우팅은 목적지까지 갈 경로를 정하고, TCP는 종단 사이의 신뢰성과 흐름을 조절한다.
4. 사용량이 용량을 넘으면 혼잡이 생기므로 혼잡 제어와 서비스 품질 관리가 필요하다.
5. 무선망은 공유 매체와 이동 문제를, SDN·NFV는 복잡한 망의 자동화 문제를 해결한다.

## A급 완료 기준

1. OSI와 TCP/IP 계층별 책임, 캡슐화, 장비·주소의 위치를 설명할 수 있는가?
2. Ethernet·ARP·IP·Routing을 연결해 한 Packet의 전달 경로를 그릴 수 있는가?
3. NAT와 IPv6가 주소 부족에 대응하는 방식과 종단 간 연결성 차이를 설명할 수 있는가?
4. TCP의 흐름 제어와 혼잡 제어를 구분하고 UDP 선택 조건을 설명할 수 있는가?
5. 대역폭·처리량·지연·손실·지터를 구분하고 QoS 조합을 설계할 수 있는가?
6. WLAN의 공유 매체·인증·암호화와 Handover 문제를 설명할 수 있는가?
7. SDN과 NFV의 역할 차이, 자동화 이점과 집중·가상화 위험을 설명할 수 있는가?
8. CDN·VPN·IoT를 기본 전달 구조와 운영·보안 요구에 연결할 수 있는가?

## 보정 기록

아직 공식 출제기준과 최근 기출을 반영하지 않은 1차 분류다.

- 특정 세대·표준은 반복 출제보다 현재 아키텍처를 설명하는 가치로 승급 여부를 판단한다.
- 5G·SDN·NFV·IoT는 최신 구조와 운영 사례를 확인해 교재 내용을 교체·보완한다.
- 망 정책·산업망 주제는 정보관리 통합형 기출에서 요구된 관점만 보강한다.
- `[현행]`/`[최신]` 표기는 용어 치환보다 적용 패턴 정렬이 우선이다.
  - `SDN`은 제어·전달 분리와 정책 자동화, `NFV`는 네트워크 기능의 소프트웨어화와 가상자원 운영 책임으로 구분한다.
  - `IoT`는 센서·네트워크·보안·운영 지표를 한 덩어리 흐름으로 답안화한다.
  - `5G`는 이동성, 지연, 대역 효율의 트레이드오프로 운영 품질 문항에 연결한다.
- 변경 시 `기존 등급 → 새 등급`, 근거 회차, 질문 형태를 기록한다.
