# 정보관리기술사 문서작성 공통 원칙

정보관리기술사 관련 문서를 새로 작성하거나 수정할 때 **가장 먼저 확인하는 진입 문서**다.

저장소 전체에 적용하는 공통 기준은 다음 두 문서에서 관리한다.

- [저장소 공통 지식 구성 원칙](../../../docs/KNOWLEDGE_ORGANIZATION.md): 개념과 지식을 어떤 단위로 묶고 나눌지 결정한다.
- [저장소 공통 문체·표기 원칙](../../../docs/WRITING_STYLE.md): 문체·용어·약어·한영 표기 기준을 정한다.

정보관리기술사 문서도 두 공통 원칙을 기본으로 적용하고, 학습등급표·개념지도·세부학습에 필요한 추가 규칙은 각 디렉터리의 작성 원칙을 따른다.

```text
정보관리기술사 문서 작업 시작
        ↓
00-문서작성-공통원칙.md
        ↓
├─ docs/KNOWLEDGE_ORGANIZATION.md
├─ docs/WRITING_STYLE.md
└─ 자료 유형별 추가 규칙
     ├─ 학습등급표 공통 원칙
     ├─ 개념지도 공통 원칙
     └─ 세부학습 작성 규칙
```

- [학습등급표 공통 원칙](학습등급표/00-학습등급표-공통원칙.md)
- [개념지도 공통 원칙](개념지도/00-개념지도-공통원칙.md)
- [세부학습 작성 규칙](세부학습/00-세부학습-작성규칙.md)

> **정보관리기술사 문서 작업은 이 문서에서 시작해 저장소 공통 원칙과 해당 자료 유형의 추가 규칙을 확인한 뒤 진행한다.**
