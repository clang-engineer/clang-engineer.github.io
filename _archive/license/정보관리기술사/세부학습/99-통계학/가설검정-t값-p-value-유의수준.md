# 가설검정과 p-value

표본을 뽑은 뒤 그 결과가 모집단에서도 성립한다고 말하려면, 먼저 무엇과 비교할지를 정해야 한다.
가설검정은 표본 결과를 귀무가설의 기준과 비교하고, 그 차이가 표본추출의 우연만으로 설명하기 어려운지 판단하는 방법이다.

> **표본 결과가 귀무가설에서 얼마나 떨어졌는지를 검정통계량으로 나타내고, 그보다 극단적인 결과가 나올 확률인 p-value를 유의수준과 비교한다.**

---

## 1. 전체에서의 위치

```text
모집단
  ↓ 일부를 추출
표본
  ├─ 기술통계: 표본 자체를 요약
  └─ 추론통계: 표본으로 모집단을 판단
       ├─ 추정: 모집단의 값과 신뢰구간을 추정
       └─ 가설검정: 모집단에 대한 주장을 검정
```

표본평균이 74라는 사실만으로는 통계적으로 유의한지 판단할 수 없다.
평균 70과 비교하는지, 두 집단의 평균 차이 0과 비교하는지에 따라 검정 결과가 달라진다.

따라서 단순한 데이터 요약에는 가설이 필요하지 않지만, **통계적 유의성을 판단하려면 비교 기준인 가설이 필요하다.**

---

## 2. 가설검정의 전체 흐름

```text
연구 질문 결정
  ↓
모집단과 표본추출 방법 결정
  ↓
귀무가설(H₀)·대립가설(H₁) 설정
  ↓
양측검정·단측검정과 유의수준(α) 결정
  ↓
표본 추출
  ↓
검정통계량(t 등) 계산
  ↓
귀무가설 아래의 분포에서 p-value 계산
  ↓
p-value와 유의수준 비교
  ↓
귀무가설 기각 또는 기각하지 못함
```

가설과 검정 방향은 원칙적으로 표본 결과를 보기 전에 정한다. 결과를 먼저 확인하고 유리한 가설이나 방향을 선택하면 우연한 결과를 유의한 것으로 오인할 가능성이 커진다.

---

## 3. 귀무가설과 대립가설

### 3.1 귀무가설

귀무가설(Null Hypothesis, H₀)은 검정의 기준이 되는 가설이다. 보통 차이·효과·관계가 없거나 모집단의 모수가 특정 값과 같다는 형태로 세운다.

```text
H₀: μ = 70
H₀: μA - μB = 0
H₀: ρ = 0
```

귀무가설은 평균에만 세우는 것이 아니다. 검정 대상에 따라 평균, 비율, 분산, 상관계수, 회귀계수, 독립성 등에 대해 세울 수 있다.

| 검정 대상 | 귀무가설의 예 |
|---|---|
| 한 집단 평균 | 모집단 평균은 70이다 |
| 두 집단 평균 | 두 모집단의 평균 차이는 0이다 |
| 적용 전·후 | 변화량의 평균은 0이다 |
| 모집단 비율 | 불량률은 5%이다 |
| 상관관계 | 모집단 상관계수는 0이다 |
| 회귀분석 | 모집단 회귀계수는 0이다 |
| 독립성 | 두 범주형 변수는 독립이다 |

### 3.2 대립가설

대립가설(Alternative Hypothesis, H₁)은 귀무가설과 대립하며 연구자가 확인하려는 주장이다.

```text
H₀: μ = 70
H₁: μ ≠ 70
```

일반적인 가설검정에서는 귀무가설을 참이라고 증명하지 않는다.

```text
p-value가 작음
→ 귀무가설 아래에서 보기 드문 표본
→ 귀무가설 기각

p-value가 큼
→ 귀무가설 아래에서도 가능한 표본
→ 귀무가설을 기각하지 못함
→ 귀무가설이 참이라고 증명한 것은 아님
```

### 3.3 왜 보통 등호가 귀무가설에 들어가는가

p-value를 계산하려면 귀무가설이 참일 때의 기준 분포가 필요하다.

```text
H₀: μ = 70
        ↓
표본 결과와 기준값 70의 차이 계산
        ↓
표준오차로 나누어 t값 계산
        ↓
귀무가설 아래의 기준 분포에서 p-value 계산
```

등호는 단순한 표기 관습이 아니라 **검정에 사용할 기준값과 기준 분포를 정하는 역할**을 한다.

#### 단측검정에서는 왜 부등호를 사용하는가

```text
H₀: μ ≤ 70
H₁: μ > 70
```

실제 기각 기준과 p-value는 대립가설과 맞닿은 경계값 μ = 70을 기준으로 계산한다.

```text
귀무가설 영역                 대립가설 영역
    μ ≤ 70          |             μ > 70
                    70
                 경계값 기준
```

| 검정 방향 | 귀무가설 | 대립가설 | 계산의 경계값 |
|---|---|---|---|
| 양측검정 | μ = 70 | μ ≠ 70 | 70 |
| 우측검정 | μ ≤ 70 | μ > 70 | 70 |
| 좌측검정 | μ ≥ 70 | μ < 70 | 70 |

## 4. 표본분포와 표준오차(SE)

같은 모집단에서 같은 크기의 표본을 반복해서 뽑으면 표본평균은 매번 조금씩 달라진다.

```text
모집단
 ↓
표본 A → 평균 68
표본 B → 평균 71
표본 C → 평균 73
표본 D → 평균 69
...
 ↓
표본평균들의 분포 = 표본분포
```

표본분포에서 **표본평균들이 얼마나 퍼져 있는지**를 나타내는 값이 표준오차(Standard Error, SE)다.

```text
표준편차 SD
= 개별 데이터들이 얼마나 퍼져 있는가

표준오차 SE
= 표본을 다시 뽑았을 때 표본평균이 얼마나 흔들리는가
```

### 4.1 편차 → 표준편차 → 표준오차

먼저 편차(Deviation)는 개별 관측값 하나가 평균에서 얼마나 떨어져 있는지를 뜻한다.

```text
데이터: 60, 70, 80
평균:   70

편차:
60 → -10
70 →   0
80 → +10
```

편차는 관측값마다 하나씩 있으므로, 데이터 전체가 얼마나 퍼져 있는지를 한 숫자로 표현하려면 이 편차들을 종합한 척도가 필요하다. 그것이 표준편차(Standard Deviation, SD)다.

```text
개별 관측값들
 ↓
각 관측값의 편차
 ↓
편차들의 전체적인 크기를 하나의 값으로 표현
 ↓
표준편차 SD
```

이제 개별 데이터가 아니라 표본평균들을 생각한다.

```text
표본 A → 평균 68
표본 B → 평균 71
표본 C → 평균 70
표본 D → 평균 72
...
```

이 표본평균들도 서로 퍼져 있다. **이 표본평균 분포의 표준편차에 특별히 붙인 이름이 표준오차(Standard Error, SE)**다.

```text
개별 데이터들의 분포
→ 그 분포의 표준편차
→ SD

표본평균들의 분포
→ 그 분포의 표준편차
→ SE
```

> **SE = 표본평균 분포의 표준편차**

따라서 SD와 SE는 전혀 다른 원리의 값이 아니다. 둘 다 분포의 퍼짐을 나타내지만 **무엇의 분포를 보고 있는지가 다르다.**

| 구분 | 무엇의 퍼짐인가 | 의미 |
|---|---|---|
| 표준편차(SD) | 개별 관측값들의 분포 | 데이터 자체의 변동성 |
| 표준오차(SE) | 표본평균들의 분포 | 표본평균이라는 추정값의 불확실성 |

#### 왜 `표본편차`나 `표본오차`라고 부르지 않는가

`표준(Standard)`은 `표본(Sample)`이라는 뜻이 아니다.

표준편차와 표준오차에서 `표준`은 **분포의 퍼짐을 표준편차 형태의 하나의 척도로 나타낸다**는 의미다. 따라서 “표본에서 계산했기 때문에 표준이라고 부른다”는 해석은 틀리다.

특히 표준오차는 이름 때문에 별도의 오차 개념처럼 보이지만, 핵심은 다음과 같다.

> **표준오차는 추정량의 표본분포가 가지는 표준편차다. 평균을 추정하는 경우에는 표본평균 분포의 표준편차다.**

즉 다음처럼 기억하면 된다.

```text
SD = 데이터 분포의 표준적인 퍼짐
SE = 표본평균 분포의 표준적인 퍼짐
```

평균의 표준오차는 모집단 표준편차 σ를 안다면 다음과 같다.

```text
SE = σ / √n
```

현실에서는 모집단 표준편차 σ를 모르는 경우가 많으므로, 한 번 뽑은 표본의 표준편차 s로 대신하여 추정한다.

```text
추정 SE = s / √n
```

### 4.2 표본 하나밖에 없는데 SE를 어떻게 구하는가

실제로 표본을 수천 번 다시 뽑아서 평균들의 분포를 직접 관측하는 것이 아니다.
**하나의 표본에서 계산한 s와 n을 이용해, 반복 표본추출을 했다면 평균이 어느 정도 흔들릴지를 통계이론으로 추정한다.**

예를 들어 한 번 뽑은 표본이 다음과 같다고 하자.

```text
표본평균 x̄ = 70
표본 표준편차 s = 20
표본크기 n = 100

SE = 20 / √100
   = 2
```

즉 이 표본 하나를 가지고도 “100명씩 다시 뽑는다면 표본평균은 대략 SE = 2 규모로 흔들리겠구나”라고 추정할 수 있다.

### 4.3 n이 커지면 왜 SE가 작아지는가

```text
n 작음
→ 표본을 다시 뽑을 때 평균이 많이 흔들림
→ SE 큼

n 큼
→ 여러 관측값의 높고 낮음이 서로 상쇄됨
→ 다시 뽑아도 평균이 비슷함
→ SE 작음
```

따라서 표본 수가 커질수록 평균 추정은 일반적으로 정밀해지고 신뢰구간도 좁아진다.

## 5. t값: 표본 결과의 위치 좌표

t값은 표본 결과가 귀무가설의 기준에서 **표준오차 몇 개만큼 떨어져 있는지** 나타낸다.

```text
t = (표본에서 관측한 값 - 귀무가설의 값) / 표준오차
```

한 집단 평균에서는 다음과 같다.

```text
t = (x̄ - μ₀) / (s / √n)
```

- x̄: 표본평균
- μ₀: 귀무가설의 평균
- s: 표본 표준편차
- n: 표본 수
- s / √n: 표본평균의 표준오차

예를 들어 표본평균 74, 귀무가설 평균 70, 표준오차 2라면:

```text
t = (74 - 70) / 2 = 2
```

즉 표본평균 74는 H₀의 기준 70에서 **표준오차 2개만큼 떨어져 있다.**

### 5.1 두 집단 평균의 차이

두 집단 평균 차이를 검정할 때 관측 대상은 각 평균이 아니라 두 평균의 차이다.

```text
H₀: μA - μB = 0

t = ((x̄A - x̄B) - 0) / √(sA²/nA + sB²/nB)
```

## 6. 왜 정규분포가 아니라 t분포인가

모집단 표준편차 σ를 안다면 z값을 사용할 수 있다.

```text
z = (x̄ - μ₀) / (σ / √n)
```

그러나 현실에서는 σ를 몰라 표본 표준편차 s로 대신하는 경우가 많다.

```text
t = (x̄ - μ₀) / (s / √n)
```

s 자체도 표본마다 달라지는 추정값이므로 추가적인 불확실성이 생긴다. 이를 반영한 것이 t분포이며, 정규분포보다 꼬리가 두껍다. 표본 수가 커지면 t분포는 정규분포에 가까워진다.

1표본 t검정의 자유도는 일반적으로 다음과 같다.

```text
df = n - 1
```

## 7. p-value: 현재 표본 결과의 희귀성

p-value는 **귀무가설이 맞다고 가정했을 때, 현재 관측한 결과와 같거나 더 극단적인 결과가 나올 확률**이다.

직관적으로는 다음처럼 기억한다.

> **p-value = 귀무가설이 맞는 세상에서 현재 표본 결과가 얼마나 희귀한가**

단, “현재 표본 그 자체가 정확히 나올 확률”이 아니라 **현재와 같거나 더 극단적인 결과의 확률**이다.

```text
표본 데이터
  ↓
t값 계산
  ↓
귀무가설 아래 분포에서 위치 확인
  ↓
현재 위치와 같거나 더 극단적인 꼬리 면적
  ↓
p-value
```

양측검정에서 관측한 t값이 2라면:

```text
p = P(T ≤ -2) + P(T ≥ 2)
```

```text
       더 극단적                       더 극단적
     ← p-value                       p-value →
────────|──────────────0──────────────|────────
       -2                            +2
```

p-value가 작다는 것은 표본 결과가 귀무가설 아래에서는 나오기 드물다는 뜻이다. 다음과 같은 뜻은 아니다.

- 귀무가설이 참일 확률
- 귀무가설이 틀릴 확률
- 결과가 우연일 확률

## 8. 유의수준과 p-value

### 8.1 유의수준 α의 직관

유의수준(Significance Level, α)은 검정 전에 미리 정하는 기각 기준이다.

```text
α = 0.05
```

직관적으로는 다음 질문에 대한 답이다.

> **귀무가설이 맞는 분포에서 어디부터 “너무 희귀하다”고 보고 기각할 것인가?**

양측검정에서 α = 0.05라면 귀무가설 아래 분포의 양쪽 꼬리 2.5%씩, 합계 5%를 기각영역으로 잡는다.

```text
          H₀와 비교적 잘 맞는 영역
                   95%
             ───────────
           /             \
──────────|───────────────|──────────
       2.5%             2.5%
        ↑                 ↑
      기각영역           기각영역

        합계 α = 5%
```

따라서 유의수준은 **“우리 분포가 아닐 구간”**이라고 외우기보다, 정확히는 **“H₀가 맞다면 잘 나오지 않을 것으로 미리 정한 극단적인 영역”**이라고 이해한다.

### 8.2 p-value와 유의수준의 차이

```text
유의수준 α
= 얼마나 희귀해야 H₀를 기각할지 미리 정한 커트라인

p-value
= 실제 표본 결과가 H₀ 아래에서 얼마나 희귀한지 계산한 값
```

예:

```text
α = 0.05
p-value = 0.03

3% < 5%
→ 미리 정한 희귀함의 한계를 넘어섬
→ H₀ 기각
```

```text
p-value < α  → H₀ 기각
p-value ≥ α → H₀를 기각하지 못함
```

---

## 9. 유의수준과 1종 오류가 연결되는 이유

`α = 1종 오류 확률`이라고 단순 암기하면 의미가 잘 안 잡힐 수 있다. 먼저 **기각영역을 정한 결과로 1종 오류 확률이 α가 된다**고 이해하는 편이 쉽다.

귀무가설이 실제로 참이라고 가정하자.

```text
H₀가 실제로 참
      ↓
그래도 표본은 매번 조금씩 다르게 나옴
      ↓
아주 드물게 표본이 α의 기각영역에 들어감
      ↓
검정 규칙에 따라 H₀를 기각
      ↓
실제로 맞는 H₀를 잘못 기각
      ↓
1종 오류
```

즉 α = 0.05라는 것은:

> **H₀가 실제로 맞더라도 표본의 우연 때문에 잘못 기각하는 경우가 장기적으로 5%가 되도록 기각영역을 정한다는 뜻이다.**

따라서 같은 α 영역을 두 관점에서 볼 수 있다.

```text
검정 기준 관점
→ H₀ 분포에서 미리 정한 기각영역의 확률 = α

오류 관점
→ H₀가 실제로 참일 때 그 영역에 떨어져 잘못 기각할 확률 = 1종 오류 확률 = α
```

---

## 10. 1종 오류·2종 오류와 검정력

가설검정은 표본으로 판단하므로 판단이 틀릴 수 있다.

| 실제 상태 | H₀ 기각 | H₀ 기각하지 못함 |
|---|---|---|
| H₀가 참 | **1종 오류(α)** | 올바른 판단 |
| H₀가 거짓 | 올바른 판단 | **2종 오류(β)** |

약효 검정으로 기억하면 쉽다.

```text
H₀: 약효가 없다

1종 오류
→ 실제 약효가 없는데 “있다”고 판단
→ 없는 걸 있다고 함
→ 성급하게 H₀를 기각

2종 오류
→ 실제 약효가 있는데 발견하지 못함
→ 있는 걸 놓침
→ H₀를 기각하지 못함
```

기억 문장:

> **1종 = 없는데 있다고 함 / 2종 = 있는데 없다고 놓침**

2종 오류의 확률을 β라고 하고, 실제 효과가 있을 때 이를 제대로 찾아낼 확률을 검정력(Power)이라고 한다.

```text
β = 실제 효과가 있는데 놓칠 확률
검정력 = 1 - β
       = 실제 효과가 있을 때 제대로 찾아낼 확률
```

## 11. SD → SE → t → p-value → α 전체 숫자 예제

다음 가설을 검정한다고 하자.

```text
H₀: μ = 70

표본을 한 번 뽑음
n = 100
표본평균 x̄ = 74
표본 표준편차 s = 20
```

### 11.1 SD: 개별 데이터의 퍼짐

```text
s = 20
```

표본에 포함된 개별 관측값들이 평균 주변에서 얼마나 퍼져 있는지를 나타낸다.

### 11.2 SE: 표본평균의 흔들림

```text
SE = s / √n
   = 20 / √100
   = 2
```

한 번의 표본만 가지고도 “100명씩 다시 뽑는다면 평균이 대략 어느 정도 흔들릴까?”를 추정한다.

### 11.3 t: H₀ 기준에서 SE 몇 개 떨어졌는가

```text
표본평균과 H₀의 차이
= 74 - 70
= 4

t = 4 / 2
  = 2
```

따라서 현재 표본평균은 H₀ 기준에서 표준오차 2개만큼 떨어져 있다.

### 11.4 p-value: 그 정도 표본 결과가 얼마나 희귀한가

자유도 99의 양측 t검정에서 t = 2이면 p-value는 약 0.048이다.

```text
p ≈ 0.048
```

이는 H₀가 맞다는 전제에서 **현재와 같거나 더 극단적인 결과가 나올 확률이 약 4.8%**라는 뜻이다.

### 11.5 α와 비교하여 결론

```text
α = 0.05
p ≈ 0.048

p < α
→ 미리 정한 기각 기준보다 더 희귀함
→ H₀ 기각
```

전체 흐름:

```text
표본 하나
 ↓
SD = 20
= 개별 데이터의 퍼짐
 ↓
SE = 20 / √100 = 2
= 표본평균의 흔들림
 ↓
표본평균 74와 H₀ 기준 70의 차이 = 4
 ↓
t = 4 / 2 = 2
= H₀에서 SE 2개만큼 떨어짐
 ↓
p ≈ 0.048
= 그 정도 이상 떨어진 표본 결과의 희귀성
 ↓
α = 0.05와 비교
 ↓
p < α
 ↓
H₀ 기각
```

만약 현실에서는 H₀가 실제로 참이었다면, 이번 표본이 우연히 기각영역에 들어가 H₀를 잘못 기각한 것이므로 **1종 오류**가 발생한 것이다.

> **SD = 데이터의 흔들림 → SE = 평균의 흔들림 → t = 기준에서 SE 몇 개 떨어졌는가 → p-value = 그 정도 결과가 얼마나 희귀한가 → α와 비교해 기각 여부 결정**

## 12. 신뢰수준과 신뢰구간

신뢰수준은 유의수준과 다음처럼 대응한다.

```text
신뢰수준 = 1 - α
유의수준 5% ↔ 신뢰수준 95%
```

신뢰수준 95%는 귀무가설이 참일 확률이 95%라는 뜻이 아니다.

평균에 대한 기본 구조는 다음과 같다.

```text
신뢰구간 = 표본평균 ± (임계값 × 표준오차)
```

표본 수가 커져 SE가 작아지면 일반적으로 신뢰구간도 좁아진다.

두 집단 평균 차이나 적용 전·후 변화량에서는 차이 없음의 기준값 0이 신뢰구간에 포함되는지 본다.

```text
[-10, -4] → 0 미포함 → 음의 방향으로 유의
[ -3,  4] → 0 포함   → 차이를 확정하기 어려움
[  2,  8] → 0 미포함 → 양의 방향으로 유의
```

양측검정에서 유의수준 5%와 95% 신뢰구간은 서로 대응한다.

```text
95% 신뢰구간에 귀무가설 기준값이 없음
→ p-value < 0.05
→ H₀ 기각

95% 신뢰구간에 귀무가설 기준값이 있음
→ p-value ≥ 0.05
→ H₀를 기각하지 못함
```

## 13. 양측검정과 단측검정

검정 방향은 대립가설이 결정한다.

| 구분 | 대립가설 | 질문 | 유의수준 5%의 위치 |
|---|---|---|---|
| 양측검정 | μ ≠ 70 | 70과 다른가 | 양쪽 꼬리에 2.5%씩 |
| 우측 단측검정 | μ > 70 | 70보다 큰가 | 오른쪽 꼬리에 5% |
| 좌측 단측검정 | μ < 70 | 70보다 작은가 | 왼쪽 꼬리에 5% |

```text
[양측]
H₀: μ = 70
H₁: μ ≠ 70

[우측]
H₀: μ ≤ 70
H₁: μ > 70

[좌측]
H₀: μ ≥ 70
H₁: μ < 70
```

## 14. 약 효과를 검정하는 표본 설계

| 보유한 데이터 | 비교 대상 | 대표 검정 | 알 수 있는 것 |
|---|---|---|---|
| 같은 환자의 적용 전·후 | 개인별 변화량 0 | 대응표본 t검정 | 평균적인 전후 변화 |
| 투약군과 대조군 | 두 집단 평균 차이 0 | 독립표본 t검정 | 두 집단의 결과 차이 |
| 투약 후 표본과 기존 기준값 | 알려진 모집단 값 | 1표본 t검정 | 기존 기준과의 차이 |
| 투약 후 표본만 있고 기준 없음 | 비교 대상 없음 | 기술통계 | 표본의 상태만 요약 |

단순한 전후 차이는 시간 경과, 자연 회복, 생활습관 변화 등의 영향을 받을 수 있다. 약의 인과적 효과를 더 명확하게 판단하려면 무작위로 나눈 투약군과 대조군을 비교하는 설계가 중요하다.

## 15. 헷갈리기 쉬운 경계

| 잘못된 해석 | 정확한 해석 |
|---|---|
| p-value는 귀무가설이 참일 확률이다 | H₀가 참일 때 현재와 같거나 더 극단적인 결과가 나올 확률이다 |
| p-value가 크면 귀무가설이 참이다 | 귀무가설을 기각할 증거가 부족하다 |
| p-value는 현재 표본 그 자체가 나올 확률이다 | 현재와 같거나 더 극단적인 결과가 나올 확률이다 |
| 유의수준은 표본에서 계산되는 값이다 | 검정 전에 미리 정하는 기각 기준이다 |
| 유의수준 5%는 귀무가설이 틀릴 확률이다 | H₀가 참일 때 잘못 기각할 1종 오류 확률을 5%로 통제한다 |
| `표준`은 `표본`이라는 뜻이다 | Standard와 Sample은 다른 말이며, 표준편차·표준오차의 `표준`은 분포의 퍼짐을 나타내는 표준편차 형태의 척도라는 의미다 |
| SE는 여러 표본을 실제로 뽑아야만 계산한다 | 보통 한 표본의 s와 n으로 s / √n을 이용해 추정한다 |
| SD와 SE는 같은 퍼짐이다 | SD는 개별 데이터, SE는 표본평균의 흔들림이다 |
| 신뢰수준 95%는 귀무가설을 95% 믿는다는 뜻이다 | 신뢰구간 생성 절차가 장기적으로 참값을 95% 포함한다는 뜻이다 |
| 통계적으로 유의하면 효과가 크다 | 효과크기는 별도로 봐야 한다 |

## 16. 기억 흐름

```text
무엇을 알고 싶은가
  ↓
비교 기준을 H₀로 설정
  ↓
표본 하나에서 SD와 SE 계산
  ↓
표본 결과와 H₀ 기준의 차이를 SE로 나눔
  ↓
t값 = H₀에서 SE 몇 개 떨어졌는가
  ↓
p-value = 그 정도 이상 극단적인 결과의 희귀성
  ↓
α = 미리 정한 기각영역의 확률
  ↓
p-value < α이면 H₀ 기각
  ↓
판단 오류 가능
├─ 1종 오류 α: 참인 H₀를 잘못 기각
└─ 2종 오류 β: 거짓인 H₀를 기각하지 못함
```

핵심 문장:

1. **가설은 무엇과 비교할지를 정한다.**
2. **SD는 개별 데이터의 퍼짐, SE는 표본평균 분포의 표준편차다.**
3. **t값은 표본 결과가 H₀ 기준에서 SE 몇 개만큼 떨어졌는지를 나타낸다.**
4. **p-value는 H₀ 아래에서 현재와 같거나 더 극단적인 결과가 얼마나 희귀한지 나타낸다.**
5. **유의수준 α는 미리 정한 기각영역이며, H₀가 참일 때 그 영역에 들어가 잘못 기각할 확률이 1종 오류 α다.**
6. **2종 오류 β는 실제 효과가 있는데 놓치는 것이며, 검정력은 1 - β다.**
