# 가설검정과 p-value

표본을 뽑은 뒤 그 결과가 모집단에서도 성립한다고 말하려면, 먼저 무엇과 비교할지를 정해야 한다.
가설검정은 표본 결과를 귀무가설의 기준과 비교하고, 그 차이가 표본추출의 우연만으로 설명하기 어려운지 판단하는 방법이다.

> **표본 결과가 귀무가설에서 얼마나 떨어졌는지를 검정통계량으로 나타내고, 그보다 극단적인 결과가 나올 확률인 p-value를 유의수준과 비교한다.**

---

## 1. 전체에서의 위치

```text
모집단
  ↓ 일부를 추출
표본
  ├─ 기술통계: 표본 자체를 요약
  └─ 추론통계: 표본으로 모집단을 판단
       ├─ 추정: 모집단의 값과 신뢰구간을 추정
       └─ 가설검정: 모집단에 대한 주장을 검정
```

표본평균이 74라는 사실만으로는 통계적으로 유의한지 판단할 수 없다.
평균 70과 비교하는지, 두 집단의 평균 차이 0과 비교하는지에 따라 검정 결과가 달라진다.

따라서 단순한 데이터 요약에는 가설이 필요하지 않지만, **통계적 유의성을 판단하려면 비교 기준인 가설이 필요하다.**

---

## 2. 가설검정의 전체 흐름

```text
연구 질문 결정
  ↓
모집단과 표본추출 방법 결정
  ↓
귀무가설(H₀)·대립가설(H₁) 설정
  ↓
양측검정·단측검정과 유의수준(α) 결정
  ↓
표본 추출
  ↓
검정통계량(t 등) 계산
  ↓
귀무가설 아래의 분포에서 p-value 계산
  ↓
p-value와 유의수준 비교
  ↓
귀무가설 기각 또는 기각하지 못함
```

가설과 검정 방향은 원칙적으로 표본 결과를 보기 전에 정한다. 결과를 먼저 확인하고 유리한 가설이나 방향을 선택하면 우연한 결과를 유의한 것으로 오인할 가능성이 커진다.

---

## 3. 귀무가설과 대립가설

### 3.1 귀무가설

귀무가설(Null Hypothesis, H₀)은 검정의 기준이 되는 가설이다. 보통 차이·효과·관계가 없거나 모집단의 모수가 특정 값과 같다는 형태로 세운다.

```text
H₀: μ = 70
H₀: μA - μB = 0
H₀: ρ = 0
```

귀무가설은 평균에만 세우는 것이 아니다. 검정 대상에 따라 평균, 비율, 분산, 상관계수, 회귀계수, 독립성 등에 대해 세울 수 있다.

| 검정 대상 | 귀무가설의 예 |
|---|---|
| 한 집단 평균 | 모집단 평균은 70이다 |
| 두 집단 평균 | 두 모집단의 평균 차이는 0이다 |
| 적용 전·후 | 변화량의 평균은 0이다 |
| 모집단 비율 | 불량률은 5%이다 |
| 상관관계 | 모집단 상관계수는 0이다 |
| 회귀분석 | 모집단 회귀계수는 0이다 |
| 독립성 | 두 범주형 변수는 독립이다 |

### 3.2 대립가설

대립가설(Alternative Hypothesis, H₁)은 귀무가설과 대립하며 연구자가 확인하려는 주장이다.

```text
H₀: μ = 70
H₁: μ ≠ 70
```

일반적인 가설검정에서는 귀무가설을 참이라고 증명하지 않는다.

```text
p-value가 작음
→ 귀무가설 아래에서 보기 드문 표본
→ 귀무가설 기각

p-value가 큼
→ 귀무가설 아래에서도 가능한 표본
→ 귀무가설을 기각하지 못함
→ 귀무가설이 참이라고 증명한 것은 아님
```

### 3.3 왜 보통 등호가 귀무가설에 들어가는가

p-value를 계산하려면 귀무가설이 참일 때의 기준 분포가 필요하다.

```text
H₀: μ = 70
        ↓
표본 결과와 기준값 70의 차이 계산
        ↓
표준오차로 나누어 t값 계산
        ↓
귀무가설 아래의 기준 분포에서 p-value 계산
```

등호는 단순한 표기 관습이 아니라 **검정에 사용할 기준값과 기준 분포를 정하는 역할**을 한다.

#### 단측검정에서는 왜 부등호를 사용하는가

평균이 70보다 큰지 검정한다면 다음과 같다.

```text
H₀: μ ≤ 70
H₁: μ > 70
```

실제 기각 기준과 p-value는 대립가설과 맞닿은 경계값 μ = 70을 기준으로 계산한다.

```text
귀무가설 영역                 대립가설 영역
    μ ≤ 70          |             μ > 70
                    70
                 경계값 기준
```

| 검정 방향 | 귀무가설 | 대립가설 | 계산의 경계값 |
|---|---|---|---|
| 양측검정 | μ = 70 | μ ≠ 70 | 70 |
| 우측검정 | μ ≤ 70 | μ > 70 | 70 |
| 좌측검정 | μ ≥ 70 | μ < 70 | 70 |

> **등호는 귀무가설 쪽에 포함되며, 단측검정에서도 실제 계산은 등호가 성립하는 경계값을 기준으로 수행한다.**

## 4. t값: 표본 결과의 위치 좌표

t값은 표본 결과가 귀무가설의 기준에서 **표준오차 몇 개만큼 떨어져 있는지** 나타낸다.

```text
t = (표본에서 관측한 값 - 귀무가설의 값) / 표준오차
```

- 부호: 차이가 나타난 방향
- 절댓값: 귀무가설에서 떨어진 정도
- t = 0: 표본 결과가 귀무가설의 기준과 일치

### 4.1 한 집단 평균

```text
t = (x̄ - μ₀) / (s / √n)
```

- x̄: 표본평균
- μ₀: 귀무가설의 평균
- s: 표본 표준편차
- n: 표본 수
- s / √n: 표본평균의 표준오차

예를 들어 표본평균 74, 귀무가설 평균 70, 표준오차 2라면 다음과 같다.

```text
t = (74 - 70) / 2 = 2
```

이는 표본평균이 귀무가설의 평균보다 오른쪽으로 표준오차 2개만큼 떨어져 있다는 뜻이다.

### 4.2 두 집단 평균의 차이

두 집단의 평균에 차이가 있는지 검정한다면 관측값은 각 평균이 아니라 **두 표본평균의 차이**다.

```text
H₀: μA - μB = 0
```

Welch t검정의 기본 형태는 다음과 같다.

```text
t = ((x̄A - x̄B) - 0) / √(sA²/nA + sB²/nB)
```

예를 들어 A 집단 평균 80, B 집단 평균 74이고 두 평균 차이의 표준오차가 약 2.83이라면 다음과 같다.

```text
t = 6 / 2.83 ≈ 2.12
```

관측된 평균 차이 6이 귀무가설의 차이 0에서 표준오차 약 2.12개만큼 떨어져 있다는 뜻이다.

## 5. 왜 정규분포가 아니라 t분포인가

모집단 표준편차 σ를 안다면 z값을 사용할 수 있다.

```text
z = (x̄ - μ₀) / (σ / √n)
```

그러나 현실에서는 모집단 표준편차를 모르는 경우가 많아 표본 표준편차 s로 대신한다.

```text
t = (x̄ - μ₀) / (s / √n)
```

s도 표본마다 달라지므로 분모에 추가적인 불확실성이 생긴다. 이를 반영한 t분포는 정규분포보다 꼬리가 두껍다. 표본 수가 커질수록 t분포는 정규분포에 가까워진다.

1표본 t검정의 자유도는 일반적으로 다음과 같다.

```text
df = n - 1
```

## 6. p-value: t값 바깥의 꼬리 면적

p-value는 **귀무가설이 맞다고 가정했을 때, 관측된 검정통계량과 같거나 더 극단적인 결과가 나올 확률**이다.

```text
표본 데이터
  ↓
t값 계산
  ↓
해당 자유도의 t분포에서 위치 확인
  ↓
그 위치와 같거나 더 극단적인 꼬리 면적
  ↓
p-value
```

t값의 절댓값이 커질수록 귀무가설의 중심에서 멀어지고 p-value는 작아진다.

```text
|t| 증가 → p-value 감소
```

### 6.1 왜 바깥쪽 꼬리 면적을 계산하는가

p-value가 묻는 질문은 다음과 같다.

> 귀무가설이 맞을 때, 현재 관측한 결과와 같거나 그보다 더 극단적으로 벗어난 결과가 나올 확률은 얼마인가?

따라서 관측한 t값과 0 사이의 안쪽 면적이 아니라, 관측한 t값에서 더 멀어지는 바깥쪽 꼬리 면적을 계산한다.

양측검정에서 관측한 t값이 2라면:

```text
p = P(T ≤ -2) + P(T ≥ 2)
```

```text
       더 극단적                       더 극단적
     ← p-value                       p-value →
────────|──────────────0──────────────|────────
       -2                            +2
```

단측검정은 대립가설이 지정한 한쪽 꼬리만 계산한다.

```text
H₁: μ > 70, 관측 t = 2
→ p = P(T ≥ 2)
```

p-value가 작다는 것은 표본 결과가 귀무가설 아래에서는 나오기 드물다는 뜻이다. 다음과 같은 뜻은 아니다.

- 귀무가설이 참일 확률
- 귀무가설이 틀릴 확률
- 결과가 우연일 확률

## 7. 유의수준과 p-value

### 7.1 유의수준

유의수준(Significance Level, α)은 검정 전에 미리 정하는 기각 기준이다. 일반적으로 5%를 많이 사용한다.

```text
α = 0.05
```

이는 귀무가설이 실제로 참인데도 귀무가설을 잘못 기각하는 제1종 오류를 장기적으로 5%까지 허용한다는 뜻이다.

```text
P(H₀ 기각 | H₀ 참) = α
```

### 7.2 p-value와 비교

```text
p-value < α
→ 귀무가설 기각

p-value ≥ α
→ 귀무가설을 기각하지 못함
```

| p-value | α = 0.05에서 판단 |
|---:|---|
| 0.03 | 귀무가설 기각 |
| 0.08 | 귀무가설을 기각하지 못함 |

---

## 8. 신뢰수준과 신뢰구간

신뢰수준은 유의수준과 다음처럼 대응한다.

```text
신뢰수준 = 1 - α
유의수준 5% ↔ 신뢰수준 95%
```

신뢰수준 95%는 귀무가설이 참일 확률이 95%라는 뜻이 아니다.

### 8.1 신뢰수준으로 신뢰구간을 만드는 과정

```text
신뢰수준 선택
  ↓
해당 분포의 임계값 결정
  ↓
표본으로 표준오차 계산
  ↓
오차범위 = 임계값 × 표준오차
  ↓
신뢰구간 = 표본추정치 ± 오차범위
```

평균에 대한 기본 구조는 다음과 같다.

```text
신뢰구간 = 표본평균 ± (임계값 × 표준오차)
```

### 8.2 신뢰수준이 높아지면 구간이 넓어지는 이유

표본평균이 70이고 표준오차가 2라면:

| 신뢰수준 | 임계값 | 신뢰구간 |
|---:|---:|---|
| 90% | 약 1.645 | 약 [66.71, 73.29] |
| 95% | 약 1.960 | 약 [66.08, 73.92] |
| 99% | 약 2.576 | 약 [64.85, 75.15] |

같은 표본이라도 더 높은 신뢰수준을 요구하면 더 넓은 범위를 잡아야 한다.

### 8.3 신뢰구간을 실제로 읽는 방법

신뢰구간은 표본 데이터 자체가 들어가는 범위가 아니라, 표본으로 추정한 **모집단 모수의 범위**다.

```text
표본평균 = 70
95% 신뢰구간 = [66, 74]
```

실무적으로는 “전체 모집단의 실제 평균이 66~74 사이에 있다고 95% 신뢰한다”라고 읽는다.

정확한 빈도주의 의미는 다음과 같다.

> 같은 방식으로 표본을 반복 추출해 신뢰구간을 만들면, 그 구간 중 장기적으로 약 95%가 모집단의 실제 값을 포함한다.

### 8.4 평균 차이의 신뢰구간과 0

두 집단 평균 차이나 적용 전·후 변화량에서는 **차이 없음의 기준값 0**이 신뢰구간에 포함되는지 본다.

```text
[-10, -4] → 0 미포함 → 음의 방향으로 유의
[ -3,  4] → 0 포함   → 차이를 확정하기 어려움
[  2,  8] → 0 미포함 → 양의 방향으로 유의
```

귀무가설의 기준값은 검정 대상에 따라 달라질 수 있다.

- 평균 차이·회귀계수·상관계수: 일반적으로 0
- 두 비율의 비(Risk Ratio 등): 일반적으로 1
- 한 집단 평균: 귀무가설에서 정한 평균 μ₀

양측검정에서 유의수준 5%와 95% 신뢰구간은 서로 대응한다.

```text
95% 신뢰구간에 귀무가설 기준값이 없음
→ p-value < 0.05
→ 귀무가설 기각

95% 신뢰구간에 귀무가설 기준값이 있음
→ p-value ≥ 0.05
→ 귀무가설을 기각하지 못함
```

## 9. 양측검정과 단측검정

검정 방향은 대립가설이 결정한다.

| 구분 | 대립가설 | 질문 | 유의수준 5%의 위치 |
|---|---|---|---|
| 양측검정 | μ ≠ 70 | 70과 다른가 | 양쪽 꼬리에 2.5%씩 |
| 우측 단측검정 | μ > 70 | 70보다 큰가 | 오른쪽 꼬리에 5% |
| 좌측 단측검정 | μ < 70 | 70보다 작은가 | 왼쪽 꼬리에 5% |

### 9.1 양측검정

```text
H₀: μ = 70
H₁: μ ≠ 70
```

기준보다 큰 경우와 작은 경우를 모두 검정한다.

### 9.2 단측검정

우측검정:

```text
H₀: μ ≤ 70
H₁: μ > 70
```

좌측검정:

```text
H₀: μ ≥ 70
H₁: μ < 70
```

같은 방향과 같은 t값이라면 단측 p-value는 일반적으로 양측 p-value의 절반이다. 대신 반대 방향으로 큰 차이가 발생해도 해당 단측 대립가설을 지지하지 않는다.

## 10. 약 효과를 검정하는 표본 설계

약의 효과를 확인할 때 적용 전·후 표본이 반드시 있어야 하는 것은 아니다. 어떤 비교 기준을 마련했는지에 따라 검정 방법이 달라진다.

| 보유한 데이터 | 비교 대상 | 대표 검정 | 알 수 있는 것 |
|---|---|---|---|
| 같은 환자의 적용 전·후 | 개인별 변화량 0 | 대응표본 t검정 | 평균적인 전후 변화 |
| 투약군과 대조군 | 두 집단 평균 차이 0 | 독립표본 t검정 | 두 집단의 결과 차이 |
| 투약 후 표본과 기존 기준값 | 알려진 모집단 값 | 1표본 t검정 | 기존 기준과의 차이 |
| 투약 후 표본만 있고 기준 없음 | 비교 대상 없음 | 기술통계 | 표본의 상태만 요약 |

### 10.1 같은 사람의 적용 전·후

```text
di = 적용 후_i - 적용 전_i

H₀: μd = 0
H₁: μd ≠ 0

t = d̄ / (sd / √n)
```

이는 전·후 표본을 서로 독립된 두 집단으로 보는 것이 아니라, 같은 사람 안에서 발생한 변화량의 평균이 0인지 검정하는 것이다.

### 10.2 투약군과 대조군

```text
H₀: μ투약군 - μ대조군 = 0
H₁: μ투약군 - μ대조군 ≠ 0
```

단순한 전후 차이는 시간 경과, 자연 회복, 생활습관 변화 등의 영향을 받을 수 있다. 약의 인과적 효과를 더 명확하게 판단하려면 무작위로 나눈 투약군과 대조군을 비교하는 설계가 중요하다.

## 11. 헷갈리기 쉬운 경계

| 잘못된 해석 | 정확한 해석 |
|---|---|
| p-value는 귀무가설이 참일 확률이다 | 귀무가설이 참일 때 현재와 같거나 더 극단적인 결과가 나올 확률이다 |
| p-value가 크면 귀무가설이 참이다 | 귀무가설을 기각할 증거가 부족하다 |
| 신뢰수준 95%는 귀무가설을 95% 믿는다는 뜻이다 | 신뢰구간 생성 절차가 장기적으로 참값을 95% 포함한다는 뜻이다 |
| 유의수준 5%는 귀무가설이 틀릴 확률이다 | 귀무가설이 참인데 잘못 기각하는 제1종 오류의 허용 기준이다 |
| 표본평균만 보면 유의성을 알 수 있다 | 귀무가설의 기준과 표준오차가 함께 필요하다 |
| 통계적으로 유의하면 효과가 크다 | 효과크기는 별도로 봐야 한다 |
| 유의한 전후 차이는 반드시 처치의 효과다 | 다른 원인을 통제해야 인과효과를 판단할 수 있다 |

## 12. 기억 흐름

```text
무엇을 알고 싶은가
  ↓
비교 기준을 귀무가설로 설정
  ↓
표본 결과와 기준의 차이 계산
  ↓
차이를 표준오차로 나눔
  ↓
t값 = 분포 위의 위치
  ↓
p-value = 그 위치보다 극단적인 꼬리 면적
  ↓
유의수준 = 미리 정한 커트라인
  ↓
p-value < 유의수준이면 귀무가설 기각
```

다음 네 문장으로 핵심을 인출할 수 있다.

1. **가설은 무엇과 비교할지를 정한다.**
2. **t값은 표본 결과가 기준에서 표준오차 몇 개만큼 떨어졌는지를 나타낸다.**
3. **p-value는 귀무가설 아래에서 그 정도 이상으로 극단적인 결과가 나올 확률이다.**
4. **유의수준은 미리 정한 기준이며 p-value가 그보다 작으면 귀무가설을 기각한다.**
