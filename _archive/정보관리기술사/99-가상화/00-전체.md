# 가상화 전체 개념지도

가상화(Virtualization)는 **물리 자원이나 실행환경을 추상화하여 논리적 자원·환경으로 제공하는 기술**이다. 이 지도는 그중 시스템·실행환경 가상화를 중심으로 다룬다. 클라우드 자체와 동의어가 아니며 온프레미스에서도 사용한다.

## 1. 전체 조망

```text
가상화 — 물리 자원과 실행환경을 분리·격리
│
├─ [1. 시스템 · 서버 가상화]
│  └─ Hypervisor/VMM · VM/Guest OS · Full/Para
├─ [2. OS 수준 격리]
│  └─ Container · Namespace · cgroup
├─ [3. 데스크톱 · 사용자 환경]
│  └─ SBC/RDS · VDI · CCI · Thin/Zero Client
└─ [4. 저장 자원 추상화]
   └─ Storage Pool · Logical Volume (LVM: PV → VG → LV)

[핵심 비교] VM은 Guest OS 경계, Container는 OS 커널 공유
[서비스 연결] Cloud Computing · DaaS
```

시스템·OS 수준 가상화와 Desktop 활용을 이 지도의 중심으로 둔다. 저장 자원 추상화는 핵심 관계만 표시하고 **RAID·Partition·LVM의 상세 관계는 저장장치 개념지도에서 학습**한다. 네트워크 가상화는 관련 학습 지도와 연결한다.

## 2. 주요 인출 축

### 시스템 가상화와 OS 수준 가상화

```text
VM → 가상 하드웨어 + 독립 Guest Kernel
Container → Host Kernel 공유 + 프로세스 격리
```

→ [가상화 구조와 VM·Container](가상화-구조와-VM-컨테이너.md)

### 데스크톱 가상화와 원격 접속

```text
중앙 업무환경 제공 → VDI / RDS / CCI
클라우드 서비스 제공 모델 → DaaS
접속 단말 유형 → Thin / Zero Client
```

→ [데스크톱 가상화 — 제공 구조와 접속 단말](데스크톱-가상화-구조와-접속-단말.md)

### 스토리지 가상화와 논리 볼륨

```text
물리 저장 자원 → 추상화·풀링 → 논리 볼륨 제공
LVM 예시: PV(관리 자원) → VG(자원 풀) → LV(논리 볼륨)
```

RAID는 데이터 배치·보호, Partition은 개별 Disk의 영역 분할, LVM은 저장공간의 통합·논리적 할당을 담당한다. 서로 같은 분류축이 아니며 함께 구성할 수 있다.

→ [I/O와 저장장치 개념지도 — RAID·Partition·LVM](../01-컴퓨터-구조/03-IO-저장장치.md)

## 3. 다른 주제와의 관계

- **운영체제:** 프로세스·메모리·Namespace·cgroup 등 실행·격리 원리
- **네트워크 가상화:** 물리 네트워크 위 논리망 구성(예: VLAN·Overlay). SDN은 제어 구조, NFV는 네트워크 기능의 소프트웨어화로 서로 구분한다. → [네트워크 개념지도](../03-네트워크/00-전체.md)
- **스토리지 가상화:** 물리 저장 자원을 논리적 볼륨·풀 등으로 추상화한다. DAS·NAS·SAN은 가상화 방식이 아니라 연결·접근 구조다. → [I/O와 저장장치 개념지도](../01-컴퓨터-구조/03-IO-저장장치.md)
- **클라우드:** 가상화 등 기반 기술을 활용해 자원을 On-Demand 서비스로 제공

→ [클라우드 전체 개념지도](../10-클라우드/00-전체.md)
