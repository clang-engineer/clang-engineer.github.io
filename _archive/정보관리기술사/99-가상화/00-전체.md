# 가상화 전체 개념지도

가상화(Virtualization)는 **물리 자원과 실제 실행환경을 추상화·격리하여 논리적 자원으로 제공하는 기술**이다. 클라우드 자체와 동의어가 아니며 온프레미스에서도 사용한다.

## 1. 전체 조망

```text
Virtualization — 무엇을 추상화·격리할까?
│
├─ 시스템·서버 — 독립된 컴퓨터 환경을 어떻게 만들까?
│  ├─ Hypervisor / VMM → VM / Guest OS
│  └─ Full / Para Virtualization
│
├─ OS 수준 — 프로세스 실행환경을 어떻게 격리할까?
│  └─ Container → Namespace / cgroup
│
└─ 활용 — 사용자에게 어떤 환경을 제공할까?
   └─ Desktop Virtualization → VDI / RDS / CCI
      └─ 접속 단말: Thin / Zero Client

[서비스 활용] Cloud Computing / DaaS
```

시스템·OS 수준 가상화와 Desktop 활용을 이 지도의 중심으로 둔다. 네트워크·스토리지의 자원 추상화도 가상화의 적용 분야지만, **여기서는 하위 유형으로 상세 전개하지 않고 관련 학습 지도와 연결**한다.

## 2. 주요 인출 축

### 시스템 가상화와 OS 수준 가상화

```text
VM → 가상 하드웨어 + 독립 Guest Kernel
Container → Host Kernel 공유 + 프로세스 격리
```

→ [가상화 구조와 VM·Container](가상화-구조와-VM-컨테이너.md)

### 데스크톱 가상화와 원격 접속

```text
중앙 업무환경 제공 → VDI / RDS / CCI
클라우드 서비스 제공 모델 → DaaS
접속 단말 유형 → Thin / Zero Client
```

→ [데스크톱 가상화·VDI·RDS·CCI·DaaS](데스크톱-가상화-VDI-RDS-CCI-DaaS.md)
→ [VDI·Thin·Zero Client](VDI-Thin-Zero-Client.md)

## 3. 다른 주제와의 관계

- **운영체제:** 프로세스·메모리·Namespace·cgroup 등 실행·격리 원리
- **네트워크 가상화:** 물리 네트워크 위 논리망 구성(예: VLAN·Overlay). SDN은 제어 구조, NFV는 네트워크 기능의 소프트웨어화로 서로 구분한다. → [네트워크 개념지도](../03-네트워크/00-전체.md)
- **스토리지 가상화:** 물리 저장 자원을 논리적 볼륨·풀 등으로 추상화한다. DAS·NAS·SAN은 가상화 방식이 아니라 연결·접근 구조다. → [I/O와 저장장치 개념지도](../01-컴퓨터-구조/03-IO-저장장치.md)
- **클라우드:** 가상화 등 기반 기술을 활용해 자원을 On-Demand 서비스로 제공

→ [클라우드 전체 개념지도](../10-클라우드/00-전체.md)
