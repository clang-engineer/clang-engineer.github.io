# 정보관리기술사 문서작성 공통 원칙

정보관리기술사 관련 문서를 새로 작성하거나 수정할 때 **가장 먼저 확인하는 진입 문서**다.

이 문서는 저장소 공통 원칙을 다시 설명하지 않는다. 정보관리기술사 문서는 저장소 공통 원칙을 그대로 상속하고, 이 영역에만 필요한 학습 규칙은 자료 유형별 문서에서 추가한다.

## 1. 저장소 공통 원칙

다음 문서는 정보관리기술사 문서에도 기본으로 적용한다.

- [문서 유형별 작성 원칙](../../../docs/DOCUMENT_TYPES.md): 문서 목적과 유형별 설명 구조
- [저장소 공통 지식 구성 원칙](../../../docs/KNOWLEDGE_ORGANIZATION.md): 지식을 어떤 단위와 깊이로 묶고 나눌지
- [저장소 공통 문체·표기 원칙](../../../docs/WRITING_STYLE.md): 문체·용어·약어·한영 표기
- [링크 작성 원칙](../../../docs/LINKING_POLICY.md): Markdown·Wiki Link 등 문서 연결 방식

공통 원칙과 기술사 전용 원칙이 같은 내용을 반복한다면 **저장소 공통 원칙을 정본으로 삼고 기술사 문서에서는 중복 설명하지 않는다.**

## 2. 정보관리기술사 전용 규칙

기술사 영역에서만 필요한 학습 목적·우선순위·인출·시험 수준의 깊이 같은 규칙은 자료 유형별 문서에서 관리한다.

```text
정보관리기술사 문서 작업 시작
        ↓
저장소 공통 원칙
        ↓
자료 유형별 추가 규칙
├─ 학습등급표
│  → 교재·기출·공식 출제기준으로 무엇을 얼마나 우선해서 공부할지 판단
├─ 개념지도
│  → 큰 그림·관계·학습 경로·인출 좌표
└─ 세부학습
   → 필요한 개념의 원리·동작·경계를 기술사 수준까지 깊게 이해
```

- [학습등급표 공통 원칙](../학습등급표/00-학습등급표-공통원칙.md)
- [개념지도 공통 원칙](00-개념지도-공통원칙.md)
- [세부학습 작성 규칙](00-세부학습-작성규칙.md)

## 3. 학습·백지 복습·개념지도 검증의 역할을 구분한다

**최종 목표는 정보관리기술사 합격**이다. 지식의 구조는 컴퓨터공학의 실제 개념·원리·관계로 잡되, 학습 범위·우선순위·깊이는 기술사 출제기준·기출·학습등급표와 교재를 참고해 결정한다. 교재 목차를 개념지도 구조로 그대로 옮기지 않는다.

```text
정보관리기술사 합격 목표
       │
       ├─ 학습 범위·깊이 → 출제기준 / 기출 / 학습등급표 / 교재
       └─ 지식 구조     → 컴퓨터공학 핵심 개념·관계
                              ↓
                        학습과 이해
                              ↓
                  빈 노트에 자유롭게 복원
                     (자료를 보지 않음)
                              ↓
                      개념지도와 대조
                    ├─ 누락·오개념 점검
                    └─ 핵심 관계 복원
                              ↓
                   부족한 부분만 세부학습
                              ↓
                       재인출·보정
```

### 백지 복습은 문답식 퀴즈와 다르다

- **학습:** 정한 시험 범위 안에서 핵심 구조·원리·비교·Trade-off를 이해한다.
- **백지 복습:** 교재·개념지도·힌트 없이 빈 노트에 학습한 내용을 **큰 구조부터 기억나는 만큼 스스로 작성**한다. 교재 번호순 복원을 강제하지 않는다.
- **검증:** 작성이 끝난 뒤 개념지도를 펼쳐 큰 가지·개념의 위치·인과·비교 관계·핵심 누락을 대조한다.
- **보완:** 개념지도로 이해가 복원되지 않는 부분만 해당 세부학습으로 내려간다. 이해 부족과 단순 기억 누락을 구분한다.
- **재복습:** 보완한 내용을 다음 백지 복습에서 다시 인출한다.

대화 중 한 문제씩 묻는 **구술 문답**은 학습 확인을 위한 보조 방식이지, 빈 노트 전체 복원을 대체하지 않는다. 백지 복습을 시작할 때 정답 구조나 세부 질문을 미리 보여 주지 않는다.

### 개념지도는 백지 복습 이후의 대조 기준서다

개념지도는 **컴퓨터공학 지식 체계로 구조화한, 기술사 시험 대비용 인출·검증 자료**다. 교재 항목을 빠짐없이 나열하는 요약본도, 세부학습을 압축 복제한 문서도 아니다.

- 상위 지도: 핵심 개념군의 위치·관계·주요 비교축을 복원한다.
- 하위 지도: 부족한 개념군의 원리·경계·선택 기준을 좁혀 본다.
- 세부학습: 지도만으로 복원되지 않는 동작·예제·Trade-off를 이해한다.
- 교재·학습등급표: 시험 대비 학습 범위와 누락을 **별도로 점검**한다. 개념지도의 Node 수를 교재 문항 수에 맞추지 않는다.

**학습 중**에는 필요에 따라 개념지도로 위치를 확인하고 세부학습으로 내려갈 수 있다. 그러나 **백지 복습 중**에는 자료를 보지 않고 먼저 작성한 다음 대조한다. 두 상황을 혼동하지 않는다.

자료의 완성도는 문서 수나 교재 목차 재현율이 아니라, **기술사에 필요한 지식이 적정 깊이로 선별되고, 백지 복습 후 핵심 구조와 답안 논리를 복원할 수 있는가**로 판단한다. 교재에 없더라도 구조상 필요한 핵심 개념은 포함할 수 있지만, 시험 목표와 무관한 세부 지식 확장은 억제한다.

## 4. 백지 복습 세션 운영

이 절은 위의 **백지 복습 원칙을 대화 세션에 적용하는 절차**다. 설명식 강의나 구술 퀴즈를 기본 진행 방식으로 삼지 않는다.

```text
현재 복습 대상 확인 (A·B급, 성안당 순서로 진입)
       ↓
사용자가 자료·힌트 없이 기억나는 내용을 자유롭게 복원
       ↓
복원이 끝났다는 신호를 받은 뒤 개념지도·교재와 대조
       ↓
핵심 누락·오개념·관계만 피드백
       ↓
사용자가 요청한 부분만 설명·보완
       ↓
사용자가 '다음'을 요청할 때 다음 미복습 개념군
```

- **시작:** Topic명만 안내하고 정의·구조·정답 키워드·유도 질문을 먼저 제시하지 않는다.
- **복원:** 사용자가 기억나는 내용을 말하거나 작성하는 동안 답을 미리 공개하지 않는다. 중간 질문이 있으면 그 질문에만 답하고, 사용자의 복원을 대신하지 않는다.
- **검증:** 사용자가 복원을 마쳤다고 하면 개념지도와 학습 범위를 대조해 잘한 점, 핵심 누락, 오개념, 중요한 관계를 간결하게 짚는다. 단순 기억 누락과 이해 부족을 구분한다.
- **진행:** A·B급 복습에서는 성안당 교재 순서대로 진입하되, **다음 대상으로 이동하는 것은 사용자가 명시적으로 요청할 때만** 한다. 이는 백지 복습의 자유로운 작성 순서를 제한하지 않는다.
- **등급별 깊이:** A급은 원리·구조·동작·비교·장단점까지 설명할 수준으로, B급은 핵심 개념과 관련 A급과의 관계·차이를 설명할 수준으로 복습한다. C급은 전체 구조에서 위치와 의미를 확인하되 독립적인 심화 복습을 기본으로 하지 않는다.
- **연결 복습:** 같은 원리·원인과 대응·비교축으로 자연스럽게 연결되는 유사 Topic은 **하나의 개념군으로 묶어 복원**한다. 단순히 관련 있다는 이유만으로 묶거나 교재 번호를 기계적으로 합치지 않는다.
- **중복 최소화:** 먼저 등장한 Topic에서 공통 구조를 충분히 복습했다면 이후 유사 Topic에서는 **새로운 관점·누락된 핵심만 보완**한다. 통합했다고 개별 A·B급 Topic의 핵심 범위가 빠지지 않았는지 학습등급표로 점검한다.
- **복습 단위:** 개념군이 너무 커져 자유로운 인출이 어려우면 작은 단위로 나눈다. 구조화의 목적은 문서나 암기량 확대가 아니라 **이해한 개념 사이의 관계를 쉽게 떠올리는 것**이다.
- **보완:** 필요한 경우에만 설명식 학습으로 전환한다. 대화 내용을 모두 문서로 옮기지 않고, 중요한 구조 보정은 [개념지도 공통 원칙](00-개념지도-공통원칙.md)에 따라 반영한다.

## 5. 원칙 문서 관리 기준

- 새 규칙이 생기면 먼저 기존 공통 원칙 또는 자료 유형별 원칙에 넣을 수 있는지 확인한다.
- 저장소 전체에 적용되는 규칙은 `docs/`에서 관리하고 기술사 영역에 복사하지 않는다.
- 기술사 전체에만 적용되는 규칙은 이 문서에 둔다.
- 학습등급표·개념지도·세부학습 중 하나에만 적용되는 규칙은 해당 자료 유형의 원칙에 둔다.
- 같은 규칙을 여러 파일에서 독립적으로 유지하지 않는다. 필요한 경우 상위 원칙을 링크한다.

> **정보관리기술사 원칙 문서는 공통 원칙을 복제하는 계층이 아니라, 기술사 학습에 필요한 차이만 추가하는 계층으로 유지한다.**
