# 정보관리기술사 문서작성 공통 원칙

정보관리기술사 관련 문서를 새로 작성하거나 수정할 때 **가장 먼저 확인하는 진입 문서**다.

이 문서는 저장소 공통 원칙을 다시 설명하지 않는다. 정보관리기술사 문서는 저장소 공통 원칙을 그대로 상속하고, 이 영역에만 필요한 학습 규칙은 자료 유형별 문서에서 추가한다.

## 1. 저장소 공통 원칙

다음 문서는 정보관리기술사 문서에도 기본으로 적용한다.

- [문서 유형별 작성 원칙](../../../docs/DOCUMENT_TYPES.md): 문서 목적과 유형별 설명 구조
- [저장소 공통 지식 구성 원칙](../../../docs/KNOWLEDGE_ORGANIZATION.md): 지식을 어떤 단위와 깊이로 묶고 나눌지
- [저장소 공통 문체·표기 원칙](../../../docs/WRITING_STYLE.md): 문체·용어·약어·한영 표기
- [링크 작성 원칙](../../../docs/LINKING_POLICY.md): Markdown·Wiki Link 등 문서 연결 방식

공통 원칙과 기술사 전용 원칙이 같은 내용을 반복한다면 **저장소 공통 원칙을 정본으로 삼고 기술사 문서에서는 중복 설명하지 않는다.**

## 2. 정보관리기술사 전용 규칙

기술사 영역에서만 필요한 학습 목적·우선순위·인출·시험 수준의 깊이 같은 규칙은 자료 유형별 문서에서 관리한다.

```text
정보관리기술사 문서 작업 시작
        ↓
저장소 공통 원칙
        ↓
자료 유형별 추가 규칙
├─ 학습등급표
│  → 무엇을 얼마나 우선해서 공부할지
├─ 개념지도
│  → 큰 그림·관계·학습 경로·인출 좌표
└─ 세부학습
   → 필요한 개념을 기술사 수준까지 깊게 이해
```

- [학습등급표 공통 원칙](../학습등급표/00-학습등급표-공통원칙.md)
- [개념지도 공통 원칙](00-개념지도-공통원칙.md)
- [세부학습 작성 규칙](00-세부학습-작성규칙.md)

## 3. 개념지도에서 부족한 이해를 찾아 세부학습으로 내려간다

기술사 학습은 과목별 개념지도를 먼저 탐색하고, **지도만으로 이해가 부족한 Node·관계·경계를 발견했을 때 필요한 부분만 세부학습으로 Zoom-in**하는 방식으로 진행한다.

```text
과목별 개념지도
= 전체 위치·관계 파악
        ↓
부족한 이해 발견
        ↓
필요한 부분만 세부학습
= 원리·동작·경계 이해
        ↓
새 관계·의존성 발견
        ↓
개념지도 보정
        ↺
```

따라서 세부학습 문서는 교재 목차를 따라 기계적으로 만드는 것이 아니라 **개념지도를 탐색하면서 실제로 더 깊은 이해가 필요한 지점에서 생성·보강**한다.

반대로 **개념지도만으로 위치·관계·핵심 의미가 충분히 이해되는 Node는 별도 세부학습 문서를 만들 필요가 없다.** 세부학습 File이 없는 Topic을 곧바로 학습 누락으로 판단하지 않는다.

```text
개념지도 Node
  ↓
지도만으로 필요한 이해가 충분한가?
  ├─ Yes → 여기서 학습 종료
  └─ No  → 세부학습으로 Zoom-in
```

자료의 완성도는 세부학습 File 수가 아니라 **개념지도를 따라갈 때 필요한 이해가 복원되고, 부족한 지점에 충분한 Zoom-in 자료가 있는가**로 판단한다.

세부학습은 기술사 학습범위를 계속 확장하는 장치가 아니다. **정한 범위 안에서 이해가 부족한 부분만 깊게 본다.** 범위를 넘어서는 전문 세부는 상위 개념과의 위치를 아는 데 도움이 될 때 이름과 연결점만 남길 수 있다.

하위 개념지도도 필수 단계가 아니다. 전체 지도와 세부학습 사이에서 관계를 한 번 더 묶어 볼 때 이해가 분명해지는 경우에만 둔다.
## 4. 원칙 문서 관리 기준

- 새 규칙이 생기면 먼저 기존 공통 원칙 또는 자료 유형별 원칙에 넣을 수 있는지 확인한다.
- 저장소 전체에 적용되는 규칙은 `docs/`에서 관리하고 기술사 영역에 복사하지 않는다.
- 기술사 전체에만 적용되는 규칙은 이 문서에 둔다.
- 학습등급표·개념지도·세부학습 중 하나에만 적용되는 규칙은 해당 자료 유형의 원칙에 둔다.
- 같은 규칙을 여러 파일에서 독립적으로 유지하지 않는다. 필요한 경우 상위 원칙을 링크한다.

> **정보관리기술사 원칙 문서는 공통 원칙을 복제하는 계층이 아니라, 기술사 학습에 필요한 차이만 추가하는 계층으로 유지한다.**
