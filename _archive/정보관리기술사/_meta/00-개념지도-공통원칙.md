# 정보관리기술사 개념지도 공통 원칙

[기술사 문서작성 공통 원칙](00-문서작성-공통원칙.md)과 저장소 [지식 구성](../../../docs/KNOWLEDGE_ORGANIZATION.md)·[문체](../../../docs/WRITING_STYLE.md) 원칙을 먼저 적용한다.

**핵심 기준:** 거시적 구분자로 백지에서 개념을 구체화할 수 있고, 기억나지 않을 때는 **ASCII와 본문만 읽어도 핵심 구조·원리·관계를 다시 이해할 수 있어야 한다.**

## 1. 지도별 역할과 깊이

```text
00 전체 지도 → 영역의 큰 개념군·관계·대표 인출 단서
       ↓ 필요한 곳만
01~ 하위 지도 → 개념군 내부의 원리·분류·경계·비교
       ↓ 지도만으로 이해가 복원되지 않을 때
세부학습 → 상세 동작·예제·계산·Trade-off
```

개념지도는 교재 목차의 축약본도 세부학습의 복제본도 아니다. **목차보다 깊고 세부학습보다 얕게** 구성한다. 교재·기출·학습등급표는 학습 우선순위와 누락 점검에 활용하며, Topic 수와 Node 수를 맞추지 않는다. 교재에 없더라도 구조상 필요한 개념은 포함할 수 있다.

전체 지도는 과목 전체의 위치·관계, 하위 지도는 해당 주제의 원리와 판단 기준에 집중한다. 전체 지도는 빠르게 훑을 수 있게 하고, 하위 지도는 기억 복원에 필요한 설명을 충분히 남긴다. **짧게 만드는 것 자체가 목표는 아니다.**

## 2. 거시적 구분자 → ASCII → 본문

- **거시적 구분자:** 사고의 범위를 나누는 짧은 개념명·관점명이다. 질문·답안 순서를 강제하지 않는다.
- **ASCII:** 핵심 개념의 포함·병렬·인과·비교·의존 관계와 대표 분류를 보여준다. 큰 꼭지를 먼저 식별할 수 있어야 한다.
- **본문:** ASCII만으로 복원하기 어려운 **등장 배경, 왜 필요한지, 핵심 동작, 개념 간 차이·경계, 적용 조건·한계**를 설명한다. 정의나 약어만 나열하지 않는다.
- **세부학습:** 지도의 설명으로도 이해가 부족할 때만 연결한다.

```text
큰 개념군
├─ 관점 A → 대표 기술·핵심 구분
├─ 관점 B → 대표 기술·핵심 구분
└─ 관점 C → 대표 기술·핵심 구분
```

관점은 가급적 짧은 명사구로 쓰고, 모든 가지를 긴 질문형으로 만들지 않는다. 대표 비교축(예: Dense/Sparse, Routing/Forwarding)은 복습의 중요한 인출 단서라면 ASCII에 직접 드러낸다. 낯선 약어는 첫 등장 시 최소 의미를 풀어준다.

## 3. 구조화와 분량 판단

- 교재 번호나 이름의 유사성이 아니라 **실제 개념 관계**로 묶는다. 순서가 아닌 병렬 개념에 억지 화살표를 사용하지 않는다.
- 전체 지도에는 큰 가지와 대표 Node를 우선 배치한다. 하위 분류는 중요한 경계·비교축을 복원하는 데 필요할 때만 한 단계 더 펼친다.
- 반복되는 분류, 단순 기술 목록, 수식·헤더·타이머·설정·코드 등의 상세는 하위 지도나 세부학습으로 내린다. 단, 핵심 원리를 이해하는 데 필수라면 간단한 예시는 본문에 둔다.
- 하위 지도는 **한 번 더 묶을 때 관계가 더 명확해지는 경우**에만 만든다. 파일 길이나 교재 Chapter 수만으로 분리하지 않는다.
- 여러 영역에 걸친 개념은 각 지도에 필요한 연결만 남기고, 상세 설명은 가장 자연스러운 한 문서가 중심 소유한다.

파일명 관례: `00-*` 전체 지도, `01-*` 이후 정규 가지, `99-*` 중요한 횡단·보강 지도. `99-*`를 기타 지식 모음으로 사용하거나 별도의 반복적 스토리학습 문서를 만들지 않는다.

## 4. 학습 경로와 링크

원칙적인 탐색은 **전체 지도 → 하위 지도 → 세부학습**이다. 하위 지도끼리 직접 학습 링크망을 만들지 않고, 경계만 언급하거나 세부학습의 중심 문서로 연결한다(상위 전체 지도로 돌아가는 링크는 허용).

존재하는 세부학습 문서가 있다면 관련 Node 가까이에 링크를 두고 **왜 보는지·무엇을 이해할지** 짧게 밝힌다. 선행 관계가 실제로 있을 때만 순서를 지정하며 빈 링크는 만들지 않는다.

## 5. 작성·수정 후 점검

1. **백지 인출:** 제목·거시적 구분자만 보고 학습한 개념을 자유롭게 구체화할 수 있는가?
2. **기억 복원:** 잊은 상태에서 ASCII와 본문을 읽고 핵심 원리·관계를 다시 이해할 수 있는가?
3. **구조 정확성:** 핵심 분류·비교축이 보이고, 포함·병렬·인과·순서를 혼동하지 않는가?
4. **깊이 적절성:** 필수 설명은 충분하고 반복·세부 나열은 없는가? 시험 범위와 관계없는 확장은 억제했는가?
5. **학습 연결:** 필요한 세부학습으로 내려갈 수 있고 다른 문서와 설명이 중복되지 않는가?

세 항목 중 하나라도 부족하면 단순히 Keyword를 늘리기보다 **구분·관계·설명 밀도**를 먼저 조정한다.
