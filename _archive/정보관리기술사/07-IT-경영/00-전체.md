# IT 경영 전체 개념지도

> IT 경영은 **사업 목표를 IT 투자·구축·운영·성과로 연결하고, 그 과정의 책임·위험·비용·품질을 통제하는 체계**다.

이 문서는 성안당 Vol.7과 학습등급표를 범위의 뼈대로 삼되, 교재 목차를 그대로 옮기지 않고 **전략 → 과제 선택 → 실행 → 운영 → 성과 확인**의 흐름과 횡단 통제로 재구성한다.

## 1. IT 경영 전체 좌표

```text
사업 목표 · 외부 환경
        ↓
전략 / Capability
        ↓
EA
현재 구조 ↔ 목표 구조
        ↓
ISP
정보화 과제 · 실행계획
        ↓
투자 판단
├─ ROI / TCO
├─ Business Case
└─ PPM
        ↓
프로그램 · 프로젝트 실행
├─ BPR / PI / BPM
├─ ERP / SCM / CRM
├─ RFP / SOW / Outsourcing
└─ EAI / API / Platform
        ↓
서비스 운영
├─ SLA / SLM
└─ ITSM / ITIL
        ↓
성과 확인
├─ KPI / BSC
└─ 감리 / 감사 / 품질
        ↺

[전 과정 횡단]
IT Governance · Risk · Compliance · Data Governance
```

중심은 기술 도입 자체가 아니라 **왜 투자하고, 무엇을 우선하며, 누가 책임지고, 어떤 성과를 확인할 것인가**다.

## 2. 어디를 파고들 것인가

### 전략 · EA · ISP

```text
사업 전략
  ↓
EA
├─ As-Is
├─ To-Be
└─ Architecture Principle
  ↓
ISP
├─ 정보화 과제
├─ 우선순위
└─ 실행 Roadmap
```

EA는 전사 구조와 원칙을 정리하고, ISP는 그 구조와 사업 목표를 실제 정보화 과제와 실행계획으로 연결한다.

### 투자 · Portfolio

```text
후보 과제
  ↓
비용 · 기대효과 · Risk
  ↓
ROI / TCO / Business Case
  ↓
PPM
  ↓
예산 · 인력 · 우선순위 배분
```

모든 과제를 수행할 수 없으므로 개별 투자타당성과 Portfolio 수준의 우선순위를 구분한다.

### 업무 개선 · 구축 · 연계

```text
업무 자체 개선
├─ BPR
├─ PI
└─ BPM

정보 System 구축
├─ ERP
├─ SCM
└─ CRM

System 간 연결
├─ EAI
└─ API / Platform
```

BPR·PI·BPM은 업무 프로세스 개선 축이고, ERP·SCM·CRM은 전사 업무 통합 사례, EAI·API는 System 연계 축으로 구분한다.

### 조달 · Outsourcing · Service Management

```text
필요한 외부 수행 범위 정의
      ↓
RFP / SOW
      ↓
계약 · Outsourcing
      ↓
SLA
      ↓
SLM / ITSM
      ↓
지속 개선
```

RFP·SOW는 구축 범위와 책임을 정하고, SLA·SLM·ITSM은 운영 단계에서 서비스 수준과 개선 책임을 관리한다.

### 업무연속성 · DR

```text
중단 Risk
├─ Risk Assessment
└─ BIA
    ↓
복구 우선순위
├─ RTO
└─ RPO
    ↓
BCP / DR / HA / Backup
    ↓
훈련 · Test · 개선
```

대표 비교·분류 축:
- Risk Assessment ↔ BIA
- RTO ↔ RPO
- BCP ↔ DR
- HA ↔ Backup / Recovery

### Governance · 성과 · 독립 검증

```text
의사결정과 책임
→ IT Governance

법 · 규정 · 계약 준수
→ Compliance

성과 측정
→ KPI / BSC

독립적 적정성 확인
→ 감리 / 감사

Data 책임
→ Data Governance
```

이 축들은 마지막 단계가 아니라 전략·투자·구축·운영 전 과정에 적용된다.

## 3. 탐색 방식

```text
성안당 문제·학습등급표
        ↓
IT 경영 전체 개념지도
"사업 목표가 어떻게 IT 실행과 성과로 연결되는가"
        ↓
필요한 세부학습
"기법·비교·책임·Trade-off는 무엇인가"
```

경영 유행어나 제품명보다 **전략 정렬, 투자 판단, 책임 경계, 서비스 운영, 연속성, 성과와 검증**이라는 반복되는 답안 축을 우선 인출한다.
