# IT 경영 전체 개념지도

> IT 경영은 **사업 목표를 IT 투자·구축·운영·성과로 연결하고, 그 과정의 책임·위험·비용·품질을 통제하는 체계**다.

이 지도는 **전략 → 과제 선택 → 실행 → 운영 → 성과 확인**이라는 대표 경영 흐름과, 전 과정을 가로지르는 관리 관점을 구분한다. EA·ISP·BPR 등은 필요에 따라 병행·반복되며, 아래 화살표가 모든 조직의 필수 수행 순서를 뜻하지는 않는다. 교재는 학습 보완에 활용한다.

## 1. IT 경영 전체 좌표

```text
IT 경영 — 사업 목표를 IT 투자·실행·성과로 연결
│
├─ [1. 전략 · 계획]
│  └─ Capability · EA · ISP
│              ↓ 우선순위·가치 판단
├─ [2. 투자 · 포트폴리오]
│  └─ ROI · TCO · Business Case · PPM
│              ↓ 과제 실행
├─ [3. 프로젝트 · 업무 혁신]
│  └─ PM · BPR/PI/BPM · ERP/SCM/CRM · RFP/SOW
│              ↓ 서비스 전환
├─ [4. 서비스 운영]
│  └─ SLA/SLM · ITSM/ITIL
│              ↓ 성과 확인
└─ [5. 성과 · 개선]
   └─ KPI/BSC · 감리 · 감사 · 품질
                └─ 전략·투자 재검토

[전 과정] IT Governance · Risk · Compliance · Data Governance
```

중심은 기술 도입 자체가 아니라 **왜 투자하고, 무엇을 우선하며, 누가 책임지고, 어떤 성과를 확인할 것인가**다. 성과 확인은 마지막에 보고서를 내고 끝내는 단계가 아니라, **결과를 전략과 다음 투자·자원 배분 판단으로 되돌리는 Feedback**이다.

## 2. 어디를 파고들 것인가

### 전략 · EA · ISP

```text
사업 전략
  ↓
EA
├─ As-Is
├─ To-Be
└─ Architecture Principle
  ↓
ISP
├─ 정보화 과제
├─ 우선순위
└─ 실행 Roadmap
```

EA는 전사 구조와 원칙을 정리하고, ISP는 사업 목표를 정보화 과제와 실행계획으로 구체화한다. **EA → ISP는 가능한 연계 예시이지 항상 고정된 선후 단계는 아니다.**

### 투자 · Portfolio

```text
후보 과제
  ↓
비용 · 기대효과 · Risk
  ↓
ROI / TCO / Business Case
  ↓
PPM
  ↓
예산 · 인력 · 우선순위 배분
```

모든 과제를 수행할 수 없으므로 개별 투자타당성과 Portfolio 수준의 우선순위를 구분한다.

### 업무 개선 · 구축 · 연계

```text
업무 자체 개선
├─ BPR
├─ PI
└─ BPM

정보 System 구축
├─ ERP
├─ SCM
└─ CRM

System 간 연결
├─ EAI
└─ API / Platform
```

BPR·PI·BPM은 업무 프로세스 개선 축이고, ERP·SCM·CRM은 전사 업무 통합 사례, EAI·API는 System 연계 축으로 구분한다.

### 조달 · Outsourcing · Service Management

```text
필요한 외부 수행 범위 정의
      ↓
RFP / SOW
      ↓
계약 · Outsourcing
      ↓
SLA
      ↓
SLM / ITSM
      ↓
지속 개선
```

RFP·SOW는 구축 범위와 책임을 정하고, SLA·SLM·ITSM은 운영 단계에서 서비스 수준과 개선 책임을 관리한다.

### 업무연속성 · DR

```text
중단 Risk
├─ Risk Assessment
└─ BIA
    ↓
복구 우선순위
├─ RTO
└─ RPO
    ↓
BCP / DR / HA / Backup
    ↓
훈련 · Test · 개선
```

대표 비교·분류 축:
- Risk Assessment ↔ BIA
- RTO ↔ RPO
- BCP ↔ DR
- HA ↔ Backup / Recovery

### Governance · 성과 · 독립 검증

```text
의사결정과 책임
→ IT Governance

법 · 규정 · 계약 준수
→ Compliance

성과 측정
→ KPI / BSC

독립적 적정성 확인
→ 감리 / 감사

Data 책임
→ Data Governance
```

이 축들은 마지막 단계가 아니라 전략·투자·구축·운영 전 과정에 적용된다.
