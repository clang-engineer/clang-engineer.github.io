# 인공지능 세부학습 권장 읽기 순서

이 문서는 `09-인공지능`의 상세 문서를 처음부터 읽을 때 길을 잃지 않도록 **권장 학습 순서**만 간단히 안내한다.

전체 개념의 관계를 다시 확인하고 싶을 때는 [`00-전체.md`](00-전체.md)로 돌아간다.

여기서 아래 번호는 **학습할 때의 권장 탐색 순서**다. Prompt, RAG, Fine-tuning, Agent 같은 활용 기술이 서로의 필수 다음 단계이거나 하나의 발전 계보라는 뜻은 아니다.

## 왜 이 순서인가

처음부터 RAG나 Agent로 들어가면 각각이 별개의 AI 기술처럼 보이기 쉽다. 먼저 AI 전체에서 LLM의 위치를 잡고, Foundation Model을 이해한 뒤 LLM 자체의 동작으로 내려가는 편이 좋다.

특히 다음 세 문서는 연속해서 읽는 것을 권장한다.

```text
LLM의-동작원리.md
        ↓
"Transformer 내부에서 무엇이 일어나는가?"

LLM-추론과-Token-생성.md
        ↓
"Transformer의 결과가 실제 다음 Token으로 어떻게 바뀌는가?"

LLM-내부운영과-GPU-메모리.md
        ↓
"이 거대한 계산을 실제 Hardware에서 어떻게 실행하는가?"
```

이 세 문서를 읽으면 다음 흐름이 연결된다.

```text
Token
 ↓
Embedding
 ↓
Transformer / Attention
 ↓
문맥화된 Hidden Vector
 ↓
LM Head
 ↓
Logit
 ↓
Softmax
 ↓
Decoding
 ↓
다음 Token
 ↓
KV Cache를 이용해 반복 생성
 ↓
이를 빠르게 처리하기 위한 GPU / VRAM
```

그 뒤에는 **이미 만들어진 LLM을 어떻게 활용할지 서로 다른 질문으로 갈라진다.**

```text
                           LLM
                            │
       ┌────────────────────┼────────────────────┐
       │                    │                    │
       ▼                    ▼                    ▼
   지시·Context          외부 지식               행동
Prompt / Few-shot          RAG            Tool / Agent / MCP

Model의 반복 행동 자체를 바꿔야 함
→ Fine-tuning

실제 업무 문제에 적용
→ Text2SQL 등
```

따라서 6~10번 문서는 학습 편의를 위해 순서를 정했지만 **Prompt → RAG → Fine-tuning → Agent가 하나의 필수 발전 단계인 것은 아니다.** 실제 시스템에서는 목적에 따라 독립적으로 선택하거나 함께 조합할 수 있다.

`에이전트와-MCP.md`를 먼저 읽고 `Agent-Harness.md`를 읽는 이유는, Harness를 별도의 새로운 AI Algorithm으로 오해하지 않기 위해서다. 먼저 Agent의 핵심인 `LLM → Tool → Observation → LLM` 반복 Loop를 이해한 뒤, 그 Agent를 어떤 Rule·Skill·Hook·Workflow·권한·Orchestration으로 운용할 것인지 보는 것이 자연스럽다.

평가·검증은 마지막에 한 번만 수행하는 단계가 아니다. Model, Prompt, RAG, Fine-tuning, Agent, 실제 Application이 바뀔 때마다 품질과 안전성을 확인해야 하므로 `99-AI-평가-Golden-Set과-Red-Teaming.md`는 **전 학습 흐름을 가로지르는 횡단축**으로 본다.

## 읽는 방법

모든 내용을 한 번에 암기하려 하지 않는다.

```text
1. 이 문서에서 다음에 읽을 파일 확인
2. 상세 문서 읽기
3. 이해되지 않는 부분은 원리까지 확인
4. 다시 인공지능 전체 개념지도로 돌아오기
5. 전체 지도에서 방금 배운 개념의 위치 확인
6. 다음 문서로 이동
7. 주요 변경점마다 평가·검증 축도 함께 확인
```

즉 [`00-전체.md`](00-전체.md)는 **개념의 위치를 확인하는 지도**, 이 문서는 **실제로 걸어갈 순서를 알려주는 경로 안내**로 사용한다.
