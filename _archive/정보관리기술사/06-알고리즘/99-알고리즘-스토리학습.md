# 알고리즘 스토리 학습 — 배송 문제를 어떻게 풀 것인가

> [알고리즘 전체 개념지도](00-전체.md)의 자료구조·분석·설계 전략·대표 문제 유형을 하나의 배송 서비스 사례로 이해한다. **자료구조는 데이터 표현, 알고리즘은 처리 절차, 복잡도는 비용 평가**라는 역할을 구분한다.

## 1. 문제가 주어졌다 — 어떤 데이터 구조가 필요할까?

유통회사가 수많은 주문을 관리한다. 주문번호로 빨리 찾고 싶고, 긴급 주문을 먼저 처리하고 싶으며, 배송지 간 연결도 표현해야 한다.

**질문: 모든 데이터를 배열 하나에 저장하면 안 될까?**

가능한 경우도 있지만 필요한 연산의 비용이 달라진다. Array는 인덱스 접근, Linked List는 연결 구조, Hash는 키 기반 접근, Heap은 우선순위 처리, Tree는 계층·정렬 관계, Graph는 지점 간 연결을 표현한다.

**질문: 자료구조를 정하면 알고리즘도 자동으로 결정될까?**

아니다. 같은 데이터라도 어떤 작업을 하느냐에 따라 다른 처리 절차가 필요하다. 자료구조와 알고리즘은 별개이면서 서로 영향을 준다. [자료구조 지도](01-자료구조.md)에서 더 본다.

## 2. 주문이 100배 늘었다 — Big-O는 왜 필요할까?

주문 100건을 처리할 때는 문제가 없었는데 100만 건에서는 느려진다.

**질문: 작은 입력에서 빨랐다는 사실만으로 큰 입력에서도 빠를까?**

아니다. 시간·공간 복잡도는 입력 크기에 따라 필요한 자원이 어떻게 증가하는지 본다. Big-O는 대표적인 점근적 상한 표현이다. 실제 시간은 상수항·하드웨어·데이터 특성에도 영향을 받는다.

**질문: 시간만 빠르면 메모리는 무한히 써도 될까?**

아니다. 시간·공간 Trade-off가 있다. [알고리즘 분석 지도](02-알고리즘-분석.md)를 참고한다.

## 3. 배송 계획을 세운다 — 어떤 해결 전략을 택할까?

배송 경로 후보가 많다. 모든 경우를 살피면 정확한 답을 찾을 수 있지만 비용이 커진다.

**질문: Brute Force 외에 어떤 사고 방식이 있을까?**

Divide & Conquer는 문제를 나눠 해결하고 결합한다. Greedy는 매 단계 국소적으로 유리한 선택을 한다. Dynamic Programming(DP)은 겹치는 부분문제의 결과를 재사용한다. Backtracking은 불가능한 후보를 가지치기하며 탐색한다.

**질문: Greedy는 항상 최적해를 보장할까?**

아니다. 탐욕적 선택이 전체 최적해로 이어지는 성질이 필요한 문제에서만 보장된다. DP도 모든 문제에 적용되는 만능 해결책은 아니다.

**질문: Recursion도 Greedy·DP와 같은 설계 전략일까?**

재귀는 자기 자신을 호출해 문제를 분해·표현하는 방식이며 Call Stack을 사용한다. Greedy·DP와 함께 쓸 수 있으므로 단순히 동급 전략으로 나열하지 않는다.

## 4. 고객 주문을 빠르게 찾는다 — 정렬과 탐색

주문번호 목록에서 하나를 찾아야 한다.

**질문: 정렬되지 않은 데이터에도 이진 탐색을 바로 적용할 수 있을까?**

일반적인 이진 탐색은 정렬된 데이터가 필요하다. 순차 탐색, 이진 탐색, Hash 기반 탐색은 데이터의 정렬 여부·접근 패턴·갱신 비용에 따라 선택한다.

**질문: 정렬 알고리즘 중 하나가 모든 경우에 최고일까?**

아니다. Bubble·Selection·Insertion, Merge·Quick·Heap·Radix는 시간·공간·안정성·입력 특성에서 차이가 있다. [정렬·탐색 지도](03-정렬-탐색.md)에서 선택 기준을 복원한다.

## 5. 배송지들이 연결돼 있다 — Tree와 Graph

물류센터와 배송지 사이에 도로가 연결돼 있다.

**질문: 연결된 지점을 모두 방문하는 문제와 가장 짧은 경로를 찾는 문제는 같을까?**

아니다. DFS/BFS는 탐색·순회, 최단경로 알고리즘은 경로 비용 최소화, MST는 모든 정점을 연결하는 총비용 최소화에 초점을 둔다. Kruskal·Prim은 MST의 대표 알고리즘이다.

**질문: Tree와 Graph는 알고리즘일까 자료구조일까?**

둘은 관계를 표현하는 자료구조이고, 그 위에서 탐색·최적화 알고리즘이 실행된다. [Tree·Graph 지도](04-트리-그래프.md)에서 구분한다.
