# 알고리즘 전체 개념지도

알고리즘은 **문제를 계산 가능한 절차로 표현하고, 그 과정에서 사용할 데이터 구조와 처리 비용을 함께 판단하는 영역**으로 본다.

## 1. 가장 먼저 잡을 큰 그림

```text
알고리즘 — 문제를 표현하고 해결 방법을 선택·평가
│
├─ [1. 데이터 표현]
│  └─ 자료구조 · Array · List · Tree · Graph
├─ [2. 효율 분석]
│  └─ Time/Space Complexity · Big-O
├─ [3. 문제 해결 전략]
│  └─ Brute Force · Divide & Conquer · Greedy
│     DP · Backtracking · Recursion
└─ [4. 대표 문제 유형]
   └─ Sorting · Search · Hashing · Tree/Graph 탐색

문제 특성 ↔ 자료구조·전략 선택
선택한 해법 → 정확성·복잡도 평가
```

여기서 중요한 것은 개별 Algorithm 이름보다 **문제 표현 → 해결 전략·처리 절차 → 비용 판단**의 관계다. Recursion은 문제 해결 전략들과 함께 활용하는 구현·문제 분해 방식이므로 Greedy·DP와 동급의 전략으로 단정하지 않는다.

```text
문제
  ↓
데이터를 어떤 구조로 표현할 것인가?
  ↓
자료구조
  ↓
그 구조에서 어떤 절차로 처리할 것인가?
  ↓
알고리즘
  ↓
그 처리에는 시간과 공간이 얼마나 필요한가?
  ↓
복잡도 분석
```

자료구조와 알고리즘은 별개의 암기 영역이 아니다. 같은 문제라도 데이터를 어떤 구조로 표현하는지에 따라 사용할 수 있는 연산과 비용이 달라진다.

## 2. 전체 좌표

```text
알고리즘
│
├─ 데이터 표현
│   ├─ Array / Linked List
│   ├─ Stack / Queue / Heap
│   └─ Tree / Graph / Hash
│
├─ 비용 판단
│   └─ Time / Space Complexity · Big-O
│
├─ 문제 해결 전략
│   ├─ Brute Force / Divide & Conquer
│   ├─ Greedy / Dynamic Programming
│   └─ Backtracking
│
├─ 대표 처리 문제
│   ├─ Sorting
│   │   ├─ Bubble / Selection / Insertion
│   │   ├─ Merge / Quick
│   │   ├─ Heap
│   │   └─ Radix
│   └─ Search
│       ├─ Sequential
│       ├─ Binary / Interpolation
│       └─ Hashing
│
├─ 관계 구조 위의 Algorithm
│   ├─ Tree
│   │   ├─ Traversal
│   │   ├─ BST / AVL
│   │   └─ B-Tree / B+Tree 계열
│   └─ Graph
│       ├─ DFS / BFS
│       └─ MST → Kruskal / Prim
│
└─ 횡단 문제분해 방식
    └─ Recursion ↔ Call Stack
```

Tree와 Graph는 자료구조이면서 동시에 Traversal·Search Algorithm이 동작하는 기반이므로 여러 가지에 걸쳐 나타날 수 있다.

문제 해결 전략은 Sorting·Graph처럼 특정 문제 종류가 아니라, **여러 문제에 적용하는 알고리즘 설계 관점**이다. 기존 자료구조·정렬·탐색 가지와 같은 층위로 혼동하지 않는다.

## 3. 큰 학습 가지

| 학습 가지 | 복습할 질문 |
|---|---|
| [자료구조](01-자료구조.md) | 데이터를 어떤 형태로 표현하고 어떤 연산을 지원하는가? |
| [알고리즘 분석](02-알고리즘-분석.md) | 입력 크기에 따라 시간·공간 비용은 어떻게 증가하는가? |
| [정렬 · 탐색](03-정렬-탐색.md) | 데이터 상태에 따라 어떤 처리 방식을 선택하는가? |
| [Tree · Graph](04-트리-그래프.md) | 계층·연결 관계를 어떻게 표현하고 탐색하는가? |

Recursion은 별도 하위 지도를 만들지 않는다. **같은 형태의 작은 문제로 분해하는 방식**과 **호출 상태가 Stack에 쌓이는 실행 특성**을 연결하는 횡단 Node로 두고, 필요하면 세부학습으로 직접 내려간다.

## 4. 문제 해결의 연결

```text
문제 정의
   ├─ Data 표현 → 자료구조
   └─ 해결 절차 → Algorithm
           │
           ▼
     시간·공간 Complexity
           │
      ┌────┴────┐
      ▼         ▼
 정렬·탐색    Tree·Graph 위의 탐색
```
