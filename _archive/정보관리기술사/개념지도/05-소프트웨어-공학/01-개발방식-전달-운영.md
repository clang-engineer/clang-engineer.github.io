# 개발 방식 · 전달 · 운영 개념지도

> 요구의 불확실성과 위험에 맞춰 **얼마나 자주 만들고 확인하며, 변경을 어떻게 실행 환경까지 안전하게 전달할 것인가**를 보는 지도다.

```text
불확실성 · 변경 · 위험
        ↓
Feedback 주기를 어떻게 잡을까?
        ↓
생명주기 모델
├─ Waterfall
├─ Iterative / Incremental
└─ Spiral

짧은 Feedback을 중심으로 개발
├─ Agile
│   ├─ Scrum
│   ├─ XP
│   └─ Kanban
└─ TDD
        ↓
변경을 반복 검증
CI · 자동 Build · 자동 Test
        ↓
Release
= 제공할 변경 단위 확정
        ↓
Deployment
= 실행 환경에 실제 적용
        ↓
운영
        ↓
DevOps
= 개발 · 전달 · 운영의 협업과 Feedback 연결
```

`Agile`, `Scrum`, `CI`, `DevOps`를 하나의 발전 순서로 보지 않는다. 서로 역할과 범위가 다르며 실제 개발 환경에서 조합된다.
