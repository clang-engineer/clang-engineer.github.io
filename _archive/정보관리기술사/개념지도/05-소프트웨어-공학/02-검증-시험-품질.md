# 검증 · 시험 · 품질 개념지도

> 품질을 마지막 시험에서 확인하는 것이 아니라 **요구부터 설계·구현·시험까지 어떻게 만들고 확인하는가**를 보는 지도다.

```text
품질 목표
  ↓
품질 요구
  ↓
설계 · 구현에 반영
  ↓
정적 확인
├─ Review
└─ Inspection
  ↓
V&V
├─ Verification
│   └─ 명세대로 만들었는가?
└─ Validation
    └─ 실제 사용자 목적에 맞는가?
  ↓
Test
├─ Test Level
│   └─ Unit · Integration · System · Acceptance
└─ Test Technique
    └─ Black-box · White-box 등
  ↓
결함 · Coverage · 품질 지표
  ↓
원인 분석 · 개선
```

`Test Level`과 `Test Technique`은 다른 분류축이다. `Coverage` 역시 시험 수행 정도를 보여주는 지표이지 요구 충족이나 결함 부재 자체를 증명하지 않는다.

품질 특성을 정리하는 대표적인 기준 좌표로 `ISO/IEC 25010`을 함께 본다.
