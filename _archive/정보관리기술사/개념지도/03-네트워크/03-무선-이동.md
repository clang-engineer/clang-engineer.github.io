# 무선·이동 개념지도

이 지도는 **Cable 대신 공유 무선 자원을 사용할 때 무엇이 달라지고, Wi-Fi에 어떻게 접속하며, 이동 중 연결을 어떻게 이어가는지**를 함께 본다.

먼저 다음 질문을 잡는다.

```text
여러 단말이 같은 무선 자원을 같이 쓰면 충돌을 어떻게 피하지?
  ↓
CSMA/CA

Wi-Fi에 연결된다는 건 실제로 어떤 단계를 거치지?
  ↓
AP 탐색 / 인증 / Association / IP 설정

단말이 움직이면 연결을 어떻게 이어가지?
  ↓
Roaming / Handover
```

이 질문 아래에서 무선 전송·보안·이동성의 핵심 Node를 연결한다.

## 1. 유선과 무선은 매체를 공유하는 방식이 다르다

```text
공유 Ethernet
├─ 같은 Cable을 여러 장치가 공유
└─ 충돌을 감지할 수 있음
    └─ CSMA/CD

공유 무선 Channel
├─ 같은 주파수 자원을 여러 단말이 공유
├─ 송신 중 다른 약한 신호를 듣기 어려움
└─ 충돌을 안정적으로 감지하기 어려움
    └─ CSMA/CA
```

현대 Switch 기반 Full-Duplex Ethernet에서는 Port별로 충돌 영역이 분리되므로 CSMA/CD의 실질적 필요가 크게 줄었다.

## 2. 무선은 충돌을 감지하기보다 피하려고 한다

```text
같은 Channel을 여러 단말이 공유
  ↓
동시에 송신할 수 있음
  ↓
AP에서 Frame이 겹칠 수 있음
  ↓
송신 중 충돌 탐지가 어려움
  ↓
전송 전에 Channel을 확인하고 대기
  ↓
CSMA/CA
```

복습할 핵심 흐름은 이 정도다.

```text
Carrier Sense
  ↓
IFS
  ↓
Random Backoff
  ↓
전송
  ↓
ACK 확인
```

Hidden Node 문제가 있으면 RTS/CTS로 충돌 가능성을 줄일 수 있지만 제어 Frame 비용이 추가된다.

## 3. Wi-Fi 연결은 한 번에 끝나는 동작이 아니다

```text
AP 탐색
Beacon / Probe
  ↓
Authentication
  ↓
Association
  ↓
보안 Key 협상
  ↓
DHCP
IP / Gateway / DNS 획득
  ↓
ARP / Neighbor Discovery
  ↓
외부 Network 통신
```

따라서 다음 상태를 구분한다.

```text
AP 발견
≠ 인증 성공
≠ Association 성공
≠ IP 설정 획득
≠ Internet 통신 성공
```

이 구분은 장애 위치를 떠올릴 때도 중요한 복습 단서다.

## 4. 매체 접근·보안·Network 설정은 서로 다른 축이다

```text
WLAN 연결
├─ 매체 접근
│   └─ CSMA/CA
├─ 인증·암호화
│   └─ WLAN Security
└─ Network 설정
    └─ DHCP / IP
```

`CSMA/CA → 보안 → DHCP`를 하나의 기술 발전 순서로 보지 않는다. 실제 접속 과정에서 함께 필요하지만 해결하는 문제가 다르다.

## 5. 무선은 한정된 주파수 자원을 효율적으로 써야 한다

```text
한정된 주파수 자원
  ↓
여러 단말과 Traffic 증가
  ↓
용량·전송 효율 개선 필요
  ↓
MIMO 등 무선 전송 기술
```

MIMO는 WLAN뿐 아니라 이동통신에서도 무선 용량과 전송 효율을 높이는 핵심 기술 축으로 본다.

## 6. 이동성이 추가되면 접속 지점을 바꿔야 한다

```text
현재 AP / Cell에서 통신
  ↓
이동
  ↓
현재 연결 품질 저하
  ↓
다른 AP / Cell로 연결 전환 필요
  ↓
Roaming / Handover
```

Handover는 단순히 새 신호를 찾는 것이 아니라 **통신 중인 단말의 연결 연속성을 유지하면서 접속 지점을 바꾸는 문제**다.

## 7. WLAN과 이동통신은 같은 계보가 아니라 공통 문제를 공유한다

```text
공유 무선 자원
├─ WLAN
│   └─ 근거리 접속 / AP
└─ 이동통신
    └─ 넓은 영역 / Cell / 이동성
```

공통으로 연결해서 볼 문제는 다음이다.

```text
무선 자원 공유
├─ 충돌·간섭
├─ 전송 효율
├─ 보안
└─ 이동성
```

따라서 `WLAN → 5G`를 발전 순서로 보지 않는다.

## 8. 복습용 핵심 좌표

```text
무선 매체 접근
├─ CSMA/CD ↔ CSMA/CA
└─ CSMA/CA
    ├─ Carrier Sense
    ├─ IFS
    ├─ Random Backoff
    ├─ ACK
    └─ Hidden Node → RTS/CTS

WLAN 접속
├─ Beacon / Probe
├─ Authentication
├─ Association
├─ Security
└─ DHCP / IP

무선 효율
└─ MIMO

이동성
├─ Roaming
└─ Handover
    └─ 이동통신 / 5G와 연결
```

이 Node를 보고 접속 단계와 각 기술이 해결하는 문제를 떠올릴 수 있으면 된다. 개별 802.11 세대, CSMA/CA Timer, 암호화 Handshake 상세, 세대별 이동통신 구조는 세부학습으로 내려간다.
