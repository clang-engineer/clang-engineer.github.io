# 컴퓨터 구조 전체 개념지도

이 문서는 `../../학습등급표/01-컴퓨터-구조.md`에서 정한 학습 범위를 **개념 관계로 재배치한 최상위 탐색 지도**다.

컴퓨터 구조는 프로그램의 명령과 데이터가 실제 하드웨어에서 어떻게 처리되고, CPU·메모리·I/O의 속도와 용량 한계를 어떤 구조로 완화하는지를 본다.

여기서는 세부 기술을 모두 펼치기보다 **어느 큰 학습 가지를 파고들 것인지**를 먼저 잡는다. 각 가지의 관계는 하위 개념지도에서 더 펼치고, 동작 원리·수식·예제는 `../../세부학습/01-컴퓨터-구조/`에서 다룬다.

## 먼저 알아둘 용어

전체 지도를 읽는 데 필요한 낯선 약어만 먼저 잡는다.

```text
ISA(Instruction Set Architecture)
= CPU가 이해하는 명령과 레지스터 등의 약속

MMU(Memory Management Unit)
= 가상주소를 물리주소로 변환하는 하드웨어

TLB(Translation Lookaside Buffer)
= 최근 주소 변환 결과를 빠르게 찾기 위한 Cache

DMA(Direct Memory Access)
= CPU의 반복 개입을 줄이고 장치와 메모리 사이의 데이터 전송을 지원하는 방식

FTL(Flash Translation Layer)
= SSD의 논리 Block 주소를 Flash의 실제 물리 위치와 연결하는 계층

CPI(Cycles Per Instruction)
= 명령 하나를 처리하는 데 필요한 평균 Clock Cycle 수

MTBF / MTTR
= 고장 사이의 평균 시간 / 장애 후 평균 복구 시간
```

## 1. 컴퓨터 구조 전체 좌표

```text
컴퓨터 구조
│
├─ 명령 실행과 CPU 병렬성
│   ├─ 컴퓨터 구성 / 폰노이만 구조
│   ├─ ISA / 명령어 사이클
│   ├─ 파이프라이닝 / 해저드
│   └─ 병렬성 확대와 한계
│
├─ 메모리 계층과 가상 메모리
│   ├─ 지역성 / 캐시
│   ├─ Paging / Segmentation
│   └─ 가상 메모리 / MMU / TLB
│
├─ I/O와 저장장치
│   ├─ Interrupt / DMA
│   ├─ RAID
│   └─ SSD / FTL
│
└─ 성능과 신뢰성
    ├─ 처리량 / 응답시간 / CPI
    ├─ Amdahl 법칙 / SPEC
    └─ MTBF / MTTR / Watchdog
```

이 네 가지는 교재 Part를 그대로 옮긴 것이 아니라, **정보관리기술사 관점에서 함께 이해할 가치가 있는 큰 학습 가지**로 묶은 것이다.

## 2. 어디를 파고들 것인가

### 명령 실행과 CPU 병렬성

CPU가 명령을 어떻게 실행하고, 처리량을 높이기 위해 병렬성을 어떤 수준에서 확대하는지 본다.

```text
명령 실행
  ↓
파이프라이닝
  ↓
해저드
  ↓
명령·Core·Thread 수준 병렬성 확대
  ↓
Amdahl 법칙으로 한계 확인
```

→ [[01-명령실행-CPU-병렬성|명령 실행과 CPU 병렬성 개념지도]]

### 메모리 계층과 가상 메모리

메모리에서는 `속도`, `배치`, `주소 공간`이라는 서로 다른 문제를 구분한다.

```text
CPU-RAM 속도 격차 → 캐시
연속 배치 제약     → Paging / Segmentation
주소 공간 분리     → 가상 메모리
```

→ [[02-메모리-계층-가상메모리|메모리 계층과 가상 메모리 개념지도]]

### I/O와 저장장치

CPU가 느린 장치와 협업하는 방법과 지속 저장장치의 성능·가용성 문제를 본다.

```text
CPU 대기·개입 축소 → Interrupt / DMA
지속 저장           → RAID / SSD / FTL
```

→ [[03-IO-저장장치|I/O와 저장장치 개념지도]]

### 성능과 신뢰성

구조를 개선한 뒤 실제 효과와 한계, 장애 대응까지 시스템 수준에서 판단한다.

```text
측정
  ↓
병목 식별
  ↓
개선
  ↓
Amdahl 법칙으로 한계 확인
  ↓
MTBF / MTTR / Watchdog으로 신뢰성·가용성 검토
```

→ [[04-성능-신뢰성|성능과 신뢰성 개념지도]]
