# 통계학 전체 지도

통계학의 개별 개념을 외우기 전에, 각 개념이 전체에서 어디에 위치하는지 잡기 위한 문서다.

핵심 구조는 다음과 같다.

```text
통계학
├─ 기술통계
│   ├─ 대표값: 평균, 중앙값, 최빈값
│   └─ 산포도: 분산, 표준편차 등
│
└─ 추론통계
    ├─ 추정
    │   ├─ 점추정
    │   └─ 구간추정 → 신뢰수준, 신뢰구간
    │
    └─ 가설검정
        ├─ 귀무가설(H₀) / 대립가설(H₁)
        ├─ 유의수준(α)
        ├─ 검정통계량(t, z, χ², F 등)
        ├─ p-value
        └─ 주요 검정: t 검정, χ² 검정, F 검정, ANOVA 등
```

확률과 확률분포는 추론통계의 계산 기반으로 사용된다.

---

## 1. 표본을 얻은 뒤 무엇을 하는가

```text
모집단
  ↓ 일부를 추출
표본
  │
  ├─ 표본 자체를 알고 싶다
  │    → 기술통계
  │
  └─ 표본으로 모집단을 알고 싶다
       → 추론통계
       │
       ├─ 모집단의 값이 얼마인가?
       │    → 추정
       │
       └─ 모집단에 대한 주장을 검토하고 싶은가?
            → 가설검정
```

이 구분은 모든 분석이 반드시 셋 중 하나만 수행된다는 뜻이 아니라, **표본을 이용하는 통계 분석의 목적을 크게 분류한 것**이다.

실제 분석에서는 다음처럼 함께 사용하기도 한다.

```text
표본 추출
  ↓
기술통계로 데이터 파악
  ↓
추정으로 모집단 모수 추정
  ↓
필요하면 가설검정
```

---

## 2. 기술통계

기술통계(Descriptive Statistics)는 **현재 가지고 있는 데이터 자체를 요약하고 설명**한다.

예를 들어 환자 100명의 혈압을 조사했다면 다음과 같은 질문에 답한다.

- 평균 혈압은 얼마인가?
- 중앙값은 얼마인가?
- 데이터가 얼마나 퍼져 있는가?
- 각 범주의 비율은 얼마인가?

```text
환자 100명의 평균 혈압 = 130
```

이 결과만으로 전체 환자의 평균 혈압이 130이라고 주장하는 것은 아니다.

---

## 3. 추론통계

추론통계(Inferential Statistics)는 **표본을 이용하여 모집단에 대해 판단**한다.

```text
모집단
  ↓ 표본추출
표본
  ↓
모집단에 대해 추론
```

추론통계의 대표적인 두 방향이 **추정과 가설검정**이다.

### 3.1 추정

질문의 형태는 다음과 같다.

> 모집단의 값은 얼마인가?

예를 들어 표본을 이용하여 전체 환자의 평균 혈압을 추정한다.

```text
표본평균 = 130
→ 모집단 평균의 추정값 = 130
→ 95% 신뢰구간 = 예: 127 ~ 133
```

- 점추정: 모집단의 값을 하나의 값으로 추정
- 구간추정: 모집단의 값이 있을 것으로 보는 범위를 제시
- 신뢰수준과 신뢰구간이 여기에서 등장한다.

### 3.2 가설검정

질문의 형태는 다음과 같다.

> 모집단에 대한 특정 주장이 표본 결과와 충돌하는가?

예를 들어 다음과 같은 귀무가설을 세울 수 있다.

```text
H₀: μ = 120
```

표본 결과를 이용하여 검정통계량을 계산하고, p-value를 유의수준과 비교하여 귀무가설을 기각할지 판단한다.

가설검정의 세부 내용은 `가설검정-t값-p-value-유의수준.md`에서 정리한다.

## 4. 추정과 가설검정의 관계

추정과 가설검정은 완전히 독립된 세계가 아니다. 같은 모집단 모수를 서로 다른 관점에서 바라보는 경우가 많다.

```text
추정
→ 모집단의 값이 어디쯤 있는가?

가설검정
→ 특정 값이라는 주장이 표본과 충돌하는가?
```

예를 들어 두 집단의 평균 차이를 분석할 때 95% 신뢰구간에 0이 포함되는지 확인하는 것과, 양측검정에서 다음 가설을 유의수준 0.05로 검정하는 것은 서로 연결되어 있다.

```text
H₀: μA - μB = 0
```

---

## 5. 각종 분석기법은 이 지도 어디에 있는가

회귀분석, ANOVA 등의 분석기법이 위 구조와 별도로 존재하는 것은 아니다.

예를 들어 ANOVA는 여러 집단의 평균이 동일하다는 귀무가설을 검정하는 **가설검정 방법**이다.

회귀분석에서는 회귀계수를 추정할 수 있으며, 동시에 해당 회귀계수가 0인지 가설검정을 수행할 수도 있다.

따라서 개별 분석기법을 공부할 때는 다음을 먼저 확인한다.

```text
1. 무엇을 분석하는가?
2. 표본만 설명하는가, 모집단까지 추론하는가?
3. 추론한다면 값을 추정하는가, 주장을 검정하는가?
4. 어떤 모수와 검정통계량을 사용하는가?
```

## 한 줄 정리

> **통계학은 데이터를 요약하는 기술통계와 표본으로 모집단을 판단하는 추론통계로 크게 볼 수 있으며, 추론통계의 대표적인 두 목적이 추정과 가설검정이다.**
