# 표준편차와 표준오차

표준편차(Standard Deviation, SD)와 표준오차(Standard Error, SE)는 이름이 비슷하지만 **무엇의 퍼짐을 보는지**가 다르다.

핵심은 다음 두 문장이다.

> **표준편차(SD) = 개별 데이터들의 대표적인 퍼짐**
>
> **표준오차(SE) = 표본평균이라는 추정값의 대표적인 흔들림**

---

## 1. 편차와 표준편차

편차(Deviation)는 개별 관측값이 평균에서 얼마나 떨어져 있는지를 나타낸다.

```text
데이터: 60, 70, 80
평균:   70

편차:
60 - 70 = -10
70 - 70 =   0
80 - 70 = +10
```

편차는 관측값마다 하나씩 존재한다. 따라서 데이터 전체의 퍼짐을 하나의 숫자로 나타내기 위해 편차들을 종합한 값이 필요하다.

표본 표준편차는 다음과 같다.

```text
s = √[ Σ(xᵢ - x̄)² / (n - 1) ]
```

계산 흐름은 다음과 같다.

```text
데이터
 ↓
평균 x̄ 계산
 ↓
각 값 - 평균 = 편차
 ↓
편차를 제곱
 ↓
모두 더함
 ↓
n - 1로 나눔 = 표본분산
 ↓
제곱근
 ↓
표본 표준편차 s
```

즉 표준편차는 **각각의 편차가 대체로 어느 정도 크기로 퍼져 있는지를 하나의 값으로 나타낸 것**이라고 직관적으로 이해할 수 있다.

---

## 2. 왜 `표준`이라고 하는가

`표준(Standard)`은 `표본(Sample)`이라는 뜻이 아니다.

표본에서 계산했기 때문에 `표준`이라는 이름이 붙은 것이 아니다. 모집단에도 표준편차가 있고 표본에도 표준편차가 있다.

```text
모집단 표준편차 = σ
표본 표준편차   = s
```

`표준 = 대표값`이 정확한 수학적 정의는 아니지만, 이름을 이해하기 위한 직관으로는 다음처럼 생각하면 쉽다.

```text
여러 편차
→ 대체로 어느 정도 크기로 퍼져 있는가?
→ 대표적인 흔들림 크기
→ 표준편차 SD
```

즉 **여러 편차를 종합하여 분포의 퍼짐을 하나의 표준적인 크기로 표현한 척도**라고 이해한다.

---

## 3. 표준오차(SE)

같은 모집단에서 같은 크기의 표본을 반복해서 뽑으면 표본평균은 매번 조금씩 달라진다.

```text
모집단 평균 μ = 70

표본 A → 평균 68
표본 B → 평균 71
표본 C → 평균 73
표본 D → 평균 69
...
```

이 표본평균들을 모아서 만든 분포가 표본분포다.

```text
표본 A 평균 ┐
표본 B 평균 │
표본 C 평균 ├→ 표본평균들의 분포 = 표본분포
표본 D 평균 │
...         ┘
```

이 **표본평균 분포의 표준편차**에 특별히 붙인 이름이 표준오차다.

> **SE = 표본평균 분포의 표준편차**

따라서 SD와 SE를 다음처럼 비교할 수 있다.

| 구분 | 무엇의 퍼짐인가 | 의미 |
|---|---|---|
| 표준편차(SD) | 개별 관측값들의 분포 | 데이터 자체의 변동성 |
| 표준오차(SE) | 표본평균들의 분포 | 추정값의 불확실성 |

직관적으로는 다음과 같다.

```text
각 데이터의 편차들
→ 대표적인 흔들림
→ 표준편차 SD

각 표본평균의 오차들
→ 대표적인 흔들림
→ 표준오차 SE
```

---

## 4. 표본 하나로 SE를 어떻게 계산하는가

실제로 표본을 수천 번 뽑아서 표본평균들의 분포를 직접 만드는 것은 아니다.

모집단 표준편차 σ를 알고 있다면 평균의 표준오차는 다음과 같다.

```text
SE = σ / √n
```

현실에서는 σ를 모르는 경우가 많기 때문에 한 번 뽑은 표본의 표준편차 s로 대신 추정한다.

```text
추정 SE = s / √n
```

예를 들어:

```text
표본평균 x̄ = 70
표본 표준편차 s = 20
표본크기 n = 100

SE = 20 / √100
   = 20 / 10
   = 2
```

즉 표본 하나만 가지고도 **같은 방식으로 100명씩 다시 뽑는다면 표본평균이 어느 정도 흔들릴지** 추정할 수 있다.

---

## 5. 왜 SE는 √n으로 나누는가

공식으로 보면 이유가 명확하다.

서로 독립인 관측값 X₁, X₂, ..., Xₙ이 있고 각 관측값의 분산이 σ²라고 하자.

표본평균은 다음과 같다.

```text
x̄ = (X₁ + X₂ + ... + Xₙ) / n
```

독립인 값들의 합에서는 분산이 더해진다.

```text
Var(X₁ + X₂ + ... + Xₙ)
= Var(X₁) + Var(X₂) + ... + Var(Xₙ)
= σ² + σ² + ... + σ²
= nσ²
```

분산에는 다음 성질이 있다.

```text
Var(aX) = a² Var(X)
```

평균은 합에 1/n을 곱한 것이므로:

```text
Var(x̄)
= Var((X₁ + ... + Xₙ) / n)
= (1/n²) × Var(X₁ + ... + Xₙ)
= (1/n²) × nσ²
= σ² / n
```

즉 표본평균의 분산은 원래 관측값의 분산보다 1/n로 작아진다.

그런데 표준오차는 **분산이 아니라 표본평균 분포의 표준편차**다. 표준편차는 분산의 제곱근이므로:

```text
SE
= √Var(x̄)
= √(σ² / n)
= σ / √n
```

따라서 √n은 임의로 붙인 보정값이 아니라 다음 과정에서 자연스럽게 나온다.

```text
개별 데이터의 분산 = σ²
        ↓ n개를 평균
평균의 분산 = σ² / n
        ↓ 제곱근
평균의 표준편차 = σ / √n
        ↓
표준오차 SE
```

> **평균을 n개 내면 분산은 1/n로 감소하고, 표준오차는 그 분산의 제곱근이므로 1/√n로 감소한다.**

예를 들어 표본 수를 4배로 늘리면 SE는 절반이 된다.

```text
n → 4n
√n → 2√n

SE = σ / √n
→ σ / (2√n)
→ 기존 SE의 1/2
```

## 6. 가설검정과 연결

가설검정에서 t값은 표본 결과가 귀무가설의 기준에서 **표준오차 몇 개만큼 떨어져 있는지** 나타낸다.

```text
t = (표본평균 - H₀의 평균) / SE
```

따라서 흐름은 다음과 같다.

```text
개별 데이터
 ↓
표준편차 SD
= 데이터 자체의 퍼짐
 ↓
표본크기 n을 반영
 ↓
표준오차 SE = SD / √n
= 표본평균의 흔들림
 ↓
t값
= H₀ 기준에서 SE 몇 개 떨어졌는가
 ↓
p-value
= 그 정도 이상 극단적인 표본 결과의 희귀성
```

---

## 한 줄 정리

> **SD는 데이터의 흔들림, SE는 평균의 흔들림이며, 평균의 분산이 σ²/n이기 때문에 SE는 σ/√n이 된다.**
