# 정보관리기술사 전체 학습등급표

이 문서는 성안당 10권의 학습 대상을 **A/B/C 등급과 태그로 관리하기 위한 전체 안내표**다.

개념 간 상위·하위·인접 관계와 전 권 연결은 `../개념지도/`에서 다루고, 실제 상세 학습은 `../세부학습/`에서 다룬다.

구체적인 등급·태그 기준은 [학습등급표 공통원칙](00-학습등급표-공통원칙.md)을 따른다.

## 자료 흐름

```text
성안당 교재 · 기출 · 공식 출제기준
        ↓
학습등급표
= 무엇을 얼마나 우선해서 볼지 결정
        ↓
개념지도
= 상위·하위·인접 관계를 따라 학습 꼭지 탐색
        ↓
세부학습
= 선택한 개념의 원리와 경계를 깊게 이해
```

## A/B/C 등급

| 등급 | 학습 깊이 | 완료 기준 |
|---|---|---|
| A | 답안으로 작성할 핵심 | 목적·구조·절차·비교·적용·한계를 설명한다. |
| B | 관계 이해와 대표 비교 | 역할과 주변 관계를 설명하고 핵심 차이를 비교한다. |
| C | 위치만 확인 | 명칭과 의미를 확인하고 기출 근거가 있을 때 보강한다. |

등급은 출제빈도를 단정하는 순위가 아니라 **현재 학습에서 투입할 깊이**다. 실제 기출과 최신 공식 출제기준을 확인하면서 조정한다.

## 태그

| 태그 | 의미 |
|---|---|
| `[선행]` | 다른 핵심 개념을 이해하기 전에 필요한 개념 |
| `[횡단]` | 여러 단계·영역에 반복 적용되는 개념 |
| `[중복]` | 같은 권의 다른 Topic과 내용이 겹침 |
| `[타권중복]` | 다른 Vol.에서 더 깊게 다룸 |
| `[세부]` | 계산·코드·규격 등 세부 비중이 큼 |
| `[현행]` | 현재 유효성을 확인해야 하는 용어·표준·제품 |
| `[최신]` | 최신 법령·표준·Architecture·기출 맥락 보강 필요 |

## 회독 활용

```text
1차
→ A/B/C로 학습 깊이 결정
→ A의 핵심 목적과 위치 우선

2차
→ A 중심 세부학습 확장
→ B는 A와 연결되는 범위까지

3차
→ 기출과 답안화
→ 근거에 따라 등급·태그 보정
```

권 전체의 관계나 특정 개념에서 다음에 무엇을 파야 하는지는 등급표에 중복해서 적지 않고 `../개념지도/`에서 관리한다.
