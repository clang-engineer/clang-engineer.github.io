# 세부학습 수식·특수기호 표기 규칙

이 문서는 `세부학습/00-세부학습-작성규칙.md`의 보조 원칙이다.

세부학습 문서는 모바일 GitHub 앱, Obsidian, Terminal, 일반 Markdown Viewer 등 여러 환경에서 읽는 것을 전제로 한다. 따라서 수식과 특수기호는 **렌더러 의존성을 최소화하고, 원문만 보아도 의미가 유지되는 표기**를 우선한다.

## 1. 기본 원칙

> **LaTeX보다 Unicode + 일반 Text 표기를 우선한다.**

다음처럼 특정 수식 렌더러가 있어야 읽히는 표기는 세부학습 문서에서 가급적 사용하지 않는다.

```text
지양
\(H_0:\mu=70\)
\[
H_0:\mu=70
\]
\alpha, \ge, \le, \frac, \sqrt, \text
```

다음처럼 Markdown 자체와 Unicode만으로 읽히는 표기를 우선한다.

```text
권장
H₀: μ = 70
H₁: μ ≠ 70
α = 0.05
p-value ≥ 0.05
x̄, μ, σ, ρ, √n
```

## 2. 긴 수식은 Text 코드블록을 사용한다

복잡한 식을 본문에 억지로 넣기보다 `text` 코드블록으로 분리한다.

```text
t = (x̄ - μ₀) / (s / √n)
```

```text
t = ((x̄A - x̄B) - 0) / √(sA²/nA + sB²/nB)
```

이 방식은 수식 렌더링을 지원하지 않는 Viewer에서도 형태와 의미가 유지된다.

## 3. Unicode 기호를 우선한다

자주 사용하는 기호는 가능한 범위에서 실제 Unicode 문자를 사용한다.

| 의미 | 권장 표기 |
|---|---|
| 귀무가설 | H₀ |
| 대립가설 | H₁ |
| 모집단 평균 | μ |
| 귀무가설 평균 | μ₀ |
| 표본평균 | x̄ |
| 모집단 표준편차 | σ |
| 상관계수 | ρ |
| 유의수준 | α |
| 같지 않음 | ≠ |
| 이상 | ≥ |
| 이하 | ≤ |
| 근사 | ≈ |
| 제곱근 | √ |
| 제곱 | ² |
| 곱셈 | × |
| 양방향 대응 | ↔ |

단, Unicode 첨자나 기호가 오히려 읽기 어렵다면 일반 Text를 사용해도 된다.

```text
μ투약군 - μ대조군 = 0
```

처럼 의미가 바로 보이는 표기를 우선한다.

## 4. 수학적 엄밀성보다 가독성을 버리지 않는다

세부학습 문서의 목적은 논문용 수식 조판이 아니라 **나중에 다시 읽었을 때 이해를 복원하는 것**이다.

따라서 다음 순서를 따른다.

```text
1. 여러 Viewer에서 깨지지 않는가?
2. 수식의 의미가 바로 보이는가?
3. 원래 개념의 정확성을 유지하는가?
4. 그 다음에 표기의 미려함을 고려한다.
```

복잡한 수식이 학습에 꼭 필요하지 않다면 기호만 남기지 말고 자연어 설명을 함께 적는다.

```text
t값
= 관측값과 귀무가설 기준값의 차이
  / 그 차이의 표준오차
```

## 5. 작성 후 확인

수식이나 특수기호가 들어간 문서는 작성 후 다음 문자열이 남아 있는지 확인한다.

```text
\(
\)
\[
\]
\mu
\alpha
\frac
\sqrt
\text
\ge
\le
\ne
```

위 표기가 의도하지 않게 남아 있다면 Unicode 또는 Text 표현으로 바꾼다.

> **세부학습 문서는 특정 Markdown 수식 Engine이 없어도 핵심 내용을 읽을 수 있어야 한다.**
