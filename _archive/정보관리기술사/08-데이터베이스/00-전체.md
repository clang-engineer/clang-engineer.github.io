# 데이터베이스 개념지도

> 데이터베이스는 **업무 데이터를 공통 구조로 관리하고, 정확성·동시성·장애·성능·확장 문제를 해결하면서 안전하게 활용하는 체계**다.

이 문서는 데이터베이스 영역의 큰 학습 가지와 연결점을 잡는 전체 지도다. 내부 관계를 더 촘촘히 볼 필요가 있는 부분만 하위 개념지도로 내려간다.

## 1. 데이터베이스 전체 좌표

```text
현실의 업무
  ↓
데이터 모델링
  ↓
Schema · Key · 무결성
  ↓
정규화 / 반정규화
  ↓
관계형 모델 · SQL
  ↓
  ├────────────────┬────────────────┐
  ▼                ▼                ▼
신뢰성             성능             확장
Transaction        Optimizer        Replication
동시성 · 회복      Index            Sharding
                   Partition        분산 DB

[별도 활용 축]
OLTP ↔ DW / OLAP / BI

[전 영역 관리 축]
보안 · 품질 · 표준 · Metadata · Governance
```

처음에는 **업무를 데이터 구조로 옮기는 기반**을 잡고, 그 위에서 `신뢰성 · 성능 · 확장`이라는 서로 다른 시스템 문제를 본다. 세 가지는 발전 단계가 아니라 같은 데이터 시스템을 보는 서로 다른 문제 축이다.

`분석 활용`은 운영 DB의 다음 단계가 아니라 목적이 다른 활용 축이고, `보안 · 품질 · 표준 · Metadata · Governance`는 구조화부터 활용까지 전체를 가로지른다.

## 2. 어디를 파고들 것인가

### 데이터 구조화 · 관계형 모델

```text
현실의 업무 → 모델링 → Schema / Key / 무결성
                         ↓
                  정규화 / 반정규화
                         ↓
                  관계형 모델 / SQL
```

업무 의미를 데이터 구조로 옮기고 중복·무결성·변경 비용을 조절하는 기반 축이다. 현재는 별도 하위 지도 없이 필요한 세부학습으로 바로 내려간다.

### Transaction · 동시성 · 회복

```text
Transaction
├─ 동시 실행 문제 → 동시성 제어
└─ 장애 문제     → 회복
```

동시 실행과 격리의 내부 원리는 세부학습으로 바로 내려간다.

→ [[트랜잭션-동시성-격리수준-Lock-MVCC|Transaction · 동시성 · 격리수준 · Lock · MVCC]]

### Index · 질의최적화

```text
Query
 ↓
Optimizer
 ↓
Access Path / Join / Execution Plan
 ↓
실행 · 측정 · Tuning
```

처리 비용을 줄이기 위해 DBMS가 실행 방법을 선택하고 Index가 어떤 접근 경로를 제공하는지 본다.

- [[질의최적화와-JOIN-실행전략|질의최적화 · JOIN 실행전략]]
- [[탐색트리와-DB인덱스-BTree-BPlusTree-BStarTree-TTree|탐색 Tree · DB Index]]

### 분산 · 확장

```text
단일 DB 한계
  ↓
Replication / Sharding
  ↓
분산 DB
  ↓
일관성 · 가용성 · 운영 복잡성
```

용량·처리량·가용성 한계를 넘으면서 새로 생기는 분산 문제를 본다.

- [[분산-데이터베이스-CAP-PACELC-NoSQL|분산 DB · CAP · PACELC · NoSQL]]
- [[샤딩-분산트랜잭션-합의|Sharding · 분산 Transaction · 합의]]

### 분석 활용 · 전 영역 관리

```text
운영 활용 → OLTP
분석 활용 → DW / OLAP / BI

전체를 가로지름
→ 보안 · 품질 · 표준 · Metadata · Governance
```

현재는 별도 하위 지도 없이 필요한 세부학습으로 바로 내려간다.

## 3. 탐색 원칙

```text
학습등급표
"무엇을 얼마나 볼 것인가"
        ↓
데이터베이스 전체 개념지도
"지금 어떤 문제 축을 보는가"
        ↓
필요한 세부학습
"원리·기법·Trade-off는 무엇인가"
```

현재 데이터베이스 영역은 별도의 하위 개념지도를 두지 않는다. `00-전체`에서 위치와 관계를 잡은 뒤 필요한 세부학습으로 바로 내려간다.
