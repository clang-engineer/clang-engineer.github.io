# 네트워크 전체 개념지도

네트워크는 **떨어진 시스템의 응용 프로그램 사이에 데이터를 전달**하기 위한 구조다. 비트를 전송하고, 링크와 네트워크를 연결하고, 목적지 프로세스까지 전달한다. 그 과정에서 **신뢰성·품질·보안·운영** 문제를 해결한다.

> **학습 기준:** 컴퓨터공학의 큰 구조·원리·관계를 먼저 인출한다. [성안당 Vol.3 학습등급표](../학습등급표/03-네트워크.md)는 범위 점검과 기술사 복습 깊이 조절에 사용하며, 교재 목차나 A/B/C 등급으로 지도의 뼈대를 결정하지 않는다.

## 1. 전체 조망

```text
네트워크 — 떨어진 응용 프로그램 사이의 데이터 전달
│
├─ ① 통신 기반 — 신호·매체·전송 자원
│   ├─ 통신 형태 → 전달 대상(Casting) · 방향(Duplex)
│   └─ 부호화/변조 · 다중화 · 교환 방식
│
├─ ② 통신 구조 — 계층별 역할과 데이터 전달
│   ├─ 계층 모델 → OSI / TCP-IP · 캡슐화
│   ├─ 링크 전달 → MAC / ARP / Switch / VLAN
│   ├─ 네트워크 전달 → IP / Subnet / Gateway / Routing
│   └─ 종단 통신·응용 → Port / TCP·UDP / Socket / DNS·HTTP
│
├─ ③ 통신 신뢰성·품질·운영 — 전달 과정의 제어·관측
│   └─ 오류/흐름/혼잡 제어 · QoS/QoE · NMS/SNMP
│
└─ ④ 통신 환경·확장 — 다양한 제약과 망 설계
    ├─ 무선·이동 → WLAN / MIMO / Handover
    ├─ 보안·격리 → 인증·암호화 / VPN
    ├─ 망 구성·제어·가상화 → Topology / SDN / NFV
    └─ 제약 단말 → IoT
```

①은 데이터 전달의 기반, ②는 **계층별 역할과 전달 범위**, ③은 전달 과정의 **횡단 문제**, ④는 **환경·설계 관점**이다. 이 네 가지는 실행 순서나 기술 발전 단계가 아니다. ②의 계층별 분기도 실제 패킷이 이동하는 시간 순서가 아니라 기능과 책임의 구분이다.

## 주요 약어 — 전체 지도를 읽는 최소 기준

| 약어 | 원어 | 의미 |
|---|---|---|
| OSI | Open Systems Interconnection | 계층별 통신 기능을 나누는 참조 모델 |
| TCP/IP | Transmission Control Protocol / Internet Protocol | 인터넷 통신의 대표 프로토콜 체계 |
| MAC | Media Access Control | 링크 계층의 주소·매체 접근 |
| ARP | Address Resolution Protocol | IPv4 주소에 대응하는 MAC 주소 확인 |
| VLAN | Virtual Local Area Network | 논리적 L2 네트워크 분리 |
| QoS / QoE | Quality of Service / Quality of Experience | 기술적 서비스 품질 / 사용자 체감 품질 |
| NMS / SNMP | Network Management System / Simple Network Management Protocol | 네트워크 관리 시스템 / 관리 정보 교환 프로토콜 |
| WLAN / MIMO | Wireless Local Area Network / Multiple-Input Multiple-Output | 무선 LAN / 다중 안테나 기술 |
| VPN / SDN / NFV | Virtual Private Network / Software-Defined Networking / Network Functions Virtualization | 논리적 사설 연결 / 소프트웨어 중심 제어 / 네트워크 기능 가상화 |
| IoT | Internet of Things | 사물인터넷 |

## 2. 계층별 전달 역할

```text
Application ─ 서비스의 요청·응답 의미      HTTP 등
     ↓
Transport   ─ 종단 간 전달 특성·Port      TCP / UDP
     ↓
Network     ─ IP 목적지·다음 경로         IP / Routing
     ↓
Link        ─ 현재 링크의 Frame 전달      MAC / Ethernet / WLAN
     ↓
Physical    ─ 비트를 물리 신호로 전달     전기 / 광 / 무선
```

송신 측은 계층별 제어 정보를 붙여 **캡슐화**, 수신 측은 **역캡슐화**한다. 계층 모델은 역할과 인터페이스를 구분하는 좌표다.

## 3. 핵심 개념군과 비교 축

### 통신 기반 — 통신 형태와 전송 자원의 이용

**연결 복습:** Topic 01 Casting Mode(B) · 02 Simplex·Half·Full Duplex(B) · 03 Packet·Virtual Circuit·Datagram(A).

```text
통신 형태
├─ 전달 대상(Casting)
│  ├─ Unicast   — 특정 수신자 하나
│  ├─ Broadcast — 같은 브로드캐스트 영역의 전체
│  └─ Multicast — 지정된 수신 그룹
└─ 통신 방향
   ├─ Simplex     — 한 방향으로만
   ├─ Half Duplex — 양방향, 번갈아
   └─ Full Duplex — 양방향, 동시에

교환 방식
├─ 회선 교환 — 통신 전 채널 자원 확보
├─ 메시지 교환 — 메시지 전체를 저장·전달 [보충]
└─ 패킷 교환 — 패킷 단위로 자원 공유
   ├─ 가상회선 — 논리적 전달 경로 사전 설정
   └─ 데이터그램 — 패킷별 독립 전달
```

가상회선의 **논리적 경로 설정**은 대역폭 **예약**과 다르다. 변조·다중화·채널 용량은 물리 전송의 한계와 효율을 다루는 별도 축이다.

### 통신 구조 — 계층과 링크·네트워크 전달

```text
같은 L2 영역 → Switch / MAC / ARP / VLAN
                     ↓ 다른 Subnet이면 Gateway
다른 네트워크 → IP / Prefix / Routing / Forwarding
                     └─ 주소 운영 → DHCP / NAT / IPv6
```

VLAN은 L2 브로드캐스트 영역을, Subnet은 L3 주소 범위를 구분한다. Routing은 경로 선택, Forwarding은 실제 전달이다.

→ [네트워크 전달 구조 개념지도](01-네트워크-전달-구조.md): 계층화·캡슐화부터 L2/L3 전달, 주소·라우팅까지 연결해 복원한다.

### 종단 통신·응용 — 호스트에서 프로세스로 (통신 구조의 연장)

```text
IP 목적지 Host
    ↓
Port / TCP·UDP — 종단 간 전달 특성
    ↓
Socket API — 응용과 OS의 접점
    ↓
HTTP / RTP·RTCP — 서비스별 통신
CDN — 콘텐츠 배치·전달 최적화 [별도 축]
```

TCP의 종단 간 연결은 네트워크 내부의 가상회선 설정이 아니다.

→ [전송·품질·운영 개념지도](02-전송-품질-운영.md): TCP/UDP와 제어·품질의 관계를 복원한다.  
→ [서비스·가상화·제약환경 개념지도](04-서비스-가상화-제약환경.md): 서비스 전달과 확장 기술을 구분한다.  
→ [Socket·Server I/O 보충학습](_보충학습/Socket-서버-IO.md): OS·응용 구현 경계가 필요할 때만 내려간다.

### 통신 신뢰성·품질·운영 — 전달 과정의 제어

```text
오류·손실 대응 → 오류 제어
수신자 처리 한계 → 흐름 제어
망의 수용 한계 → 혼잡 제어
서비스별 품질 요구 → QoS / QoE
장비 상태 관측·관리 → NMS / SNMP
```

흐름 제어는 수신자의 처리 능력을, 혼잡 제어는 네트워크의 수용 능력을 고려한다. QoS는 네트워크 품질, QoE는 사용자 체감 품질의 관점이다.

→ [전송·품질·운영 개념지도](02-전송-품질-운영.md): 제어 방식·품질·관측의 비교 기준을 복원한다.

### 통신 환경·확장 — 무선과 이동성

```text
무선 채널 공유 → 간섭·매체 접근 → WLAN / CSMA/CA
전송 효율 향상 → MIMO 등
접속점 변경 → Roaming / Handover / 이동통신
```

WLAN과 이동통신은 같은 발전 단계가 아니라 무선 자원·보안·이동성 문제를 서로 다른 환경에서 다룬다.

→ [무선·이동 개념지도](03-무선-이동.md): 공유 매체, 무선 접속, 이동 중 연결 유지로 확대한다.

### 통신 환경·확장 — 보안·망 구성·제어·가상화·제약 환경

```text
통신 보호·격리 → 인증·암호화 / VPN
제어·정책 자동화 → SDN (Control / Data Plane)
네트워크 기능 SW화 → NFV
망 연결 구조 → Topology / 3-Tier / Spine-Leaf
제약 단말 연결 → Sensor Network / IoT
```

Topology는 연결 형태, VPN은 논리적 사설 연결, SDN은 제어 구조, NFV는 네트워크 기능 구현을 다룬다. 서로 동의어이거나 하나의 순차 발전 과정이 아니다.

→ [서비스·가상화·제약환경 개념지도](04-서비스-가상화-제약환경.md): 서로 다른 확장 요구와 Trade-off를 구분한다.  
→ [보안 전체 개념지도](../04-보안/00-전체.md): 인증·암호화·통제의 일반 원리.  
→ [가상화 전체 개념지도](../99-가상화/00-전체.md): 논리망 구성과 SDN/NFV의 차이.

## 4. 빠른 복습 좌표

| 큰 질문 | 떠올릴 핵심 관계 |
|---|---|
| 누구에게, 어느 방향으로 보내는가? | Unicast·Broadcast·Multicast / Simplex·Half·Full Duplex |
| 통신 자원을 어떻게 이용하는가? | 회선 교환 ↔ 패킷 교환 / 가상회선 ↔ 데이터그램 |
| 역할을 왜 나누는가? | 계층화 · 인터페이스 · 캡슐화 |
| 계층별로 어디까지 전달하는가? | MAC·VLAN ↔ IP·Subnet·Routing ↔ Port·TCP/UDP |
| 어느 프로그램까지 전달하는가? | Port · TCP/UDP · Socket |
| 통신을 어떻게 안정적으로 유지하는가? | 오류 ↔ 흐름 ↔ 혼잡 / QoS·QoE / NMS |
| 다른 환경으로 어떻게 확장되는가? | 무선·이동 / 보안·VPN / SDN·NFV / IoT |

**복습 경로:** 전체 지도로 위치·관계를 떠올린 뒤 [성안당 Vol.3 학습등급표](../학습등급표/03-네트워크.md)의 A급 중심으로 책순 회독한다. 막히는 개념만 해당 하위 지도와 세부학습으로 내려간다. **전체 지도는 거시적 인출, 하위 지도는 내부 관계·비교, 세부학습은 필요한 동작·예제**를 맡는다.
