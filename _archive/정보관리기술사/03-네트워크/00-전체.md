# 네트워크 전체 개념지도

**핵심 질문: 시스템 간 데이터를 어떻게 전달하고, 망을 구성하며, 안정적으로 운영하는가?**

## 0. 전체 구조

```text
네트워크
│
├─ ① 통신 기반 — 어떤 방식으로 보내는가?
│  ├─ 전달 대상 → Casting
│  ├─ 통신 방향 → Duplex
│  ├─ 신호 표현 → 부호화 / 변조
│  ├─ 자원 공유 → 다중화
│  └─ 교환 방식 → 회선 교환 / 패킷 교환
│
├─ ② 전달 구조 — 어떻게 목적지에 도달하는가?
│  ├─ 계층화 → OSI / TCP-IP / 캡슐화
│  ├─ 링크 계층 → Ethernet / MAC / ARP / VLAN
│  ├─ 인터넷 계층 → IP / Subnet / DHCP / Routing
│  ├─ 전송 계층 → Port / TCP·UDP
│  └─ 응용 계층 → Socket / HTTP · L4/L7 분산
│
├─ ③ 망 구성·설계 — 어떻게 연결하고 배치하는가?
│  ├─ 연결 형태 → Star / Ring / Mesh
│  └─ 아키텍처 → 3-Tier / Spine-Leaf
│
├─ ④ 제어·품질·운영 — 어떻게 안정적으로 관리하는가?
│  ├─ 전송 제어 → 오류 / 흐름 / 혼잡
│  ├─ 품질 → NP / QoS / QoE
│  └─ 운영 → NMS / SNMP
│
└─ ⑤ 환경·확장 — 환경과 요구에 어떻게 대응하는가?
   ├─ 무선·이동 → WLAN / MIMO / Handover
   ├─ 보안·격리 → VPN
   ├─ 망 제어·기능 가상화 → SDN / NFV
   └─ 제약 단말 → IoT
```

다섯 축은 시간 순서가 아니라 문제를 보는 관점이다.

## 1. 통신 기반 — 어떤 방식으로 보내는가?

```text
통신 기반
├─ 전달 대상 → Unicast / Broadcast / Multicast
├─ 통신 방향 → Simplex / Half / Full Duplex
├─ 신호 표현 → 부호화 / 변조
├─ 자원 공유 → 다중화
└─ 교환 방식 → 회선 교환 / 패킷 교환
```

전달 대상은 누구에게 보내는가, 통신 방향은 어느 방향으로 보내는가의 구분이다. 회선 교환은 자원을 미리 확보하고 패킷 교환은 패킷 단위로 자원을 공유한다. 패킷 교환의 가상회선은 논리 경로 설정이지 대역폭 예약 자체가 아니다.

## 2. 전달 구조 — 어떻게 목적지에 도달하는가?

```text
Application — 서비스 의미 (HTTP)
      ↓
Transport   — 종단·Port (TCP / UDP)
      ↓
Network     — 목적지 IP·경로
      ↓
Link        — 현재 링크의 Frame·MAC
      ↓
Physical    — 비트·신호
```

OSI(Open Systems Interconnection)는 참조 모델이고 TCP/IP(Transmission Control Protocol / Internet Protocol)는 인터넷 프로토콜 체계다. UDP(User Datagram Protocol)는 데이터그램 전송 프로토콜이다. 송신 측은 캡슐화, 수신 측은 역캡슐화를 수행한다.

MAC(Media Access Control)은 현재 링크 전달, ARP(Address Resolution Protocol)는 IPv4 주소에 대응하는 링크 주소 확인에 쓰인다. VLAN(Virtual Local Area Network)은 L2 전달 범위, Subnet은 L3 주소 범위를 구분한다. Routing은 경로 선택, Forwarding은 실제 패킷 전달이다.

→ [네트워크 전달 구조](01-네트워크-전달-구조.md): 계층·링크·주소·라우팅·종단 통신

## 3. 망 구성·설계 — 어떻게 연결하고 배치하는가?

- **Topology:** Star / Ring / Mesh — 장치 간 연결 형태
- **3-Tier:** Core / Distribution / Access — 계층별 역할 배치
- **Spine-Leaf:** Leaf가 Spine들과 연결되는 구조 — 일반적인 Leaf 간 경로는 Leaf → Spine → Leaf

## 4. 제어·품질·운영 — 어떻게 안정적으로 관리하는가?

오류 제어는 손실·오류, 흐름 제어는 수신자 처리 능력, 혼잡 제어는 네트워크 수용 능력에 대응한다.

NP(Network Performance)는 네트워크 성능, QoS(Quality of Service)는 서비스 품질과 관리 정책, QoE(Quality of Experience)는 사용자 체감 품질이다. NMS(Network Management System)는 망 관리 시스템이며 SNMP(Simple Network Management Protocol)는 대표 관리 정보 교환 프로토콜이다.

→ [제어·품질·운영](02-전송-품질-운영.md): 전송 제어·품질·관측

## 5. 환경·확장 — 환경과 요구에 어떻게 대응하는가?

무선·이동에서는 WLAN(Wireless Local Area Network), MIMO(Multiple-Input Multiple-Output), Handover를 다룬다.

→ [무선·이동](03-무선-이동.md): 공유 무선 자원·접속·이동성

VPN(Virtual Private Network)은 보안·격리, SDN(Software-Defined Networking)은 제어 구조의 소프트웨어화, NFV(Network Functions Virtualization)는 네트워크 기능의 소프트웨어 구현, IoT(Internet of Things)는 제약 단말 등 연결 환경을 다룬다.

→ [서비스·가상화·제약환경](04-서비스-가상화-제약환경.md): 응용·망 제어·제약 단말
