# 네트워크 전체 개념지도

**핵심 질문: 떨어진 응용 프로그램 사이에 데이터를 어떻게 전달하고, 품질과 운영을 어떻게 보장하는가?**

## 0. 전체 구조 — 다섯 가지 관점

```text
네트워크 — 시스템 간 데이터 전달
│
├─ ① 통신 기반 — 무엇을, 어떤 매체와 방식으로 보내는가?
│  └─ Casting / Duplex · 부호화·변조 · 다중화 · 교환
│
├─ ② 통신 구조 — 누가 어디까지 전달하는가?
│  ├─ 계층화 → OSI(Open Systems Interconnection) / TCP(Transmission Control Protocol)-IP(Internet Protocol) / 캡슐화
│  ├─ 링크 → MAC(Media Access Control) / ARP(Address Resolution Protocol) / L2 Switch / VLAN(Virtual Local Area Network)
│  ├─ 네트워크 → IP / Subnet / DHCP / Routing · L3 Switch
│  └─ 종단·응용 → Port / TCP·UDP(User Datagram Protocol) / Socket / HTTP · L4/L7 분산
│
├─ ③ 신뢰성·품질·운영 — 어떻게 제어하고 관측하는가?
│  └─ 오류·흐름·혼잡 제어 / QoS(Quality of Service)·QoE(Quality of Experience) / NMS(Network Management System)·SNMP(Simple Network Management Protocol)
│
├─ ④ 망 구성·설계 — 장비와 링크를 어떻게 배치하는가?
│  ├─ 연결 형태 → Star / Ring / Mesh
│  └─ 아키텍처 → 3-Tier / Spine-Leaf
│
└─ ⑤ 환경·확장 — 조건이 달라지면 무엇이 필요한가?
   ├─ 무선·이동 → WLAN(Wireless Local Area Network) / MIMO(Multiple-Input Multiple-Output) / Handover
   ├─ 보안·격리 → VPN(Virtual Private Network)
   ├─ 망 제어·기능 가상화 → SDN(Software-Defined Networking) / NFV(Network Functions Virtualization)
   └─ 제약 단말 → IoT(Internet of Things)
```

**다섯 축은 시간 순서가 아니라 문제를 보는 관점**이다. 통신 구조 안의 계층도 기능과 책임의 구분이다.

## 1. 전달을 보는 기본 좌표

```text
Application — 서비스 의미 (HTTP)
      ↓
Transport   — 종단·Port (TCP / UDP)
      ↓
Network     — 목적지 IP·경로
      ↓
Link        — 현재 링크의 Frame·MAC
      ↓
Physical    — 비트·신호
```

송신 측은 계층별 제어 정보를 붙이는 **캡슐화**, 수신 측은 **역캡슐화**를 수행한다.

## 2. 서로 혼동하지 않을 기준

- **전달 대상 vs 방향:** Unicast·Broadcast·Multicast는 누구에게, Simplex·Half·Full Duplex는 어느 방향으로 보내는가.
- **회선 vs 패킷 교환:** 자원을 미리 확보하는가, 패킷 단위로 공유하는가. 패킷 교환의 가상회선은 논리 경로 설정이지 대역폭 예약 자체가 아니다.
- **VLAN vs Subnet:** L2 프레임 전달 범위 vs L3 IP 주소 범위.
- **Routing vs Forwarding:** 경로 선택 vs 결정된 경로에 따른 실제 패킷 전달.
- **오류 vs 흐름 vs 혼잡 제어:** 손실·오류 대응 vs 수신자 처리 능력 vs 네트워크 수용 능력.
- **QoS vs QoE:** 네트워크의 기술적 품질·정책 vs 사용자 체감 품질.
- **SDN vs NFV:** 제어 구조의 소프트웨어화 vs 네트워크 기능의 소프트웨어 구현.

## 3. 망 구성 — 전달 원리와 별도의 설계 축

- **Topology:** Star / Ring / Mesh — 장치 간 연결 형태
- **3-Tier:** Core / Distribution / Access — 계층별 역할 배치
- **Spine-Leaf:** Leaf가 Spine들과 연결되는 구조 — 일반적인 Leaf 간 경로는 Leaf → Spine → Leaf
