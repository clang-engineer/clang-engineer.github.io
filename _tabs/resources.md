개발할 때 다시 찾아볼 사이트를 모았습니다. 설치 방법은 각 사이트의 공식 안내로 연결합니다.

## 테마

### 여러 도구의 색감 통일하기

에디터와 터미널 등 여러 도구에 같은 색상 체계를 적용할 때 찾아볼 사이트입니다. 각 사이트에서 사용하는 도구의 지원 여부와 미리보기를 확인할 수 있습니다.

| 사이트 | 색감 | 제공 범위 |
| --- | --- | --- |
| [Dracula](https://draculatheme.com/) | 어두운 배경에 보라·분홍 계열 강조색 | 에디터·터미널 등 다양한 앱용 Dracula 테마 |
| [Catppuccin](https://catppuccin.com/ports/) | 부드러운 파스텔 계열 | 앱·개발 도구·웹사이트용 테마 |
| [Rosé Pine](https://rosepinetheme.com/themes/) | 차분한 장미색·소나무색 계열 | 여러 앱과 개발 도구용 테마 |
| [Nord](https://www.nordtheme.com/ports/) | 청회색·푸른색 계열 | 에디터·터미널·라이브러리용 테마 |

### 여러 테마를 탐색하거나 생성하기

하나의 테마를 여러 도구에 적용하는 대신, 다양한 색상 조합을 둘러보거나 직접 고를 때 유용합니다.

| 사이트 | 용도 |
| --- | --- |
| [Gogh](https://gogh.website/) | 여러 터미널용 컬러 테마를 탐색하고 적용 |
| [themer](https://themer.dev/) | 색상 조합을 선택·조정해 에디터·터미널·다른 앱용 테마와 배경화면 생성 |

지원 도구와 설치 방법은 바뀔 수 있으므로 적용 전 공식 페이지에서 확인합니다.
