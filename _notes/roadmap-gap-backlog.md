# 로드맵 학습 갭 백로그 (재방문 콘텐츠 계획)

목적: 방문자가 로드맵을 따라 학습하다 **막히는 지점**을 새 글로 메워, 이탈 대신 체류·재방문으로 잇는다.
출처: 2026-07-04 로드맵 3차 검토(학습 완결성)에서 각 에이전트가 뽑은 글감. "막히는 지점 = 리텐션 기회".

원칙:
- 글을 **실제로 쓴 순간에만** 해당 로드맵의 "경계 공백" 문구를 내부 링크로 전환한다. 빈 "곧 예정" 약속을 남기지 않는다.
- 우선순위 = (막히는 학습자 수 × 이탈 위험). 입문 초반 전제 공백일수록 높다.
